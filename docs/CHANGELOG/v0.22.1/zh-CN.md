Open Design 0.22.1 在 0.22.0 的基础上，让支持的设计任务更容易开始，也让运行出错后的恢复路径更清楚。

## 🔁 改进

- 🧭 **支持的设计任务默认使用 OD Next。** 使用支持的 Agent 创建原型、幻灯片、营销设计和 Hyperframes 视频时，默认启用 OD Next。你仍可在「设置 → Open Design 实验室 → Design Harness」中关闭，之前明确关闭的选择也会保留。（#7876）
- 🧰 **让设计过程更专注。** OD Next 精简工具使用指引，明确完成任务的要求，并按当前运行所属的工作区加载媒体技能。（#7804）

> 📥 **下载：**[Open Design 下载页面](https://open-design.ai/download/)。

## 🐛 修复

### 💬 对话与恢复

- 🛟 **运行失败后，仍有可用的下一步。** 返回对话时保留失败卡片，呈现超时和重试信息；当前聊天无法切换到 Cloud 执行时，仍可使用「重试」。（#7871、#7884、#7897）感谢 @lefarcen。
- 🔑 **API Key 无效时，直接指向解决办法。** 使用自己的 API Key 遇到鉴权错误时，会显示对应说明，并可直接前往模型设置。（#7893）感谢 @lefarcen。
- 🗺️ **运行和预览问题有更清楚的说明。** 模型不可用、能力不支持、超时、缺少预览文件和地区限制等情况，都会给出更具体的提示。（#7887）感谢 @lefarcen。
- 📝 **发送失败，也不会丢掉已填的答案。** 澄清表单的答案未能启动运行时，会保留在对话中，点击「重试」即可重新发送相同答案，内部路由文本保持隐藏。（#7900）感谢 @lefarcen。
- 📜 **回复持续生成时，聊天继续跟随。** 浏览器自动调整滚动位置时，不再悄悄关闭自动跟随；你主动向上滚动时，仍可停留并阅读之前的消息。（#7898）感谢 @lefarcen。

### 🎨 设计与交付

- 💬 **打招呼，就得到正常回复。** OD Next 不再为问候或不需要设计的请求凭空生成网站；已有可读原因的受阻结果，也不会重复显示失败卡片。（#7725）
- ✅ **在网页交付成功前，检查语法问题。** 对符合条件的网页交付物检查 HTML 及相关脚本语法；明确可修复的问题无需新增 Agent 轮次即可修复，仍有错误或检查不完整时，不会将本次交付报告为成功。（#7801）感谢 @lbjzz-hash。
- 🧩 **继续使用刚刚收集的需求。** 官方 Codex 插件确认需求时，能够接受收集需求步骤返回的工作流标识，同时继续拒绝不匹配的标识。（#7779）感谢 @taljeon。

### 🗂️ 工作区与设置

- 🔗 **引用当前工作区中的项目。** 项目引用列表按当前工作区展示项目，切换工作区后会刷新。（#7701）
- 🤖 **看清本地 CLI 实际用了哪个模型。** 连接测试会显示滚动别名最终解析到的模型，方便核对配置是否生效。（#6386）感谢 @MumuTW。
- 🇫🇷 **更一致的法语指引。** 更新设置、故障恢复等界面文案及核心文档的法语表达。（#7753、#7754）感谢 @davezfr。
- 🌍 **社交链接提示跟随你的语言。** 导航中的提示文案支持本地化，并适配从右到左的布局。（#7665）

### 🖥️ 安装与 Docker

- 🖼️ **在 Docker 中浏览内置插件预览。** Docker 安装恢复提供插件海报和悬停预览短片。（#7028）感谢 @jiulongche。
- 📁 **选择下载位置时，尊重已有内容。** 判断能否接管下载目录时，不再把名称类似系统杂项的目录或符号链接误当作可忽略的普通文件。（#7718）感谢 @mikemikimike。

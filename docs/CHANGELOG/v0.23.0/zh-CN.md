### 🌟 Codename: *新首页，连贯的对话*

🧵 **74 个 PR · 8 位贡献者** — **Open Design 0.23.0 换了新的首页，也让一次 Agent 对话真正成为一段连续的工作。** 过去，一次重启、一次澄清、一次重试，或一组拥挤的结果卡片，都可能让人丢失线索；现在，工作本身、它的证据和下一步操作会始终留在一起。🚀

## 🔥 亮点

- 🏠 **全新的首页与项目入口。** 重做了首页、顶部入口栏、全部项目列表和项目聊天页，新建项目和回到已有项目的路径更直接，窄窗口下也不再挤在一起。 (#8209) 感谢 @Siri-Ray。

- 🧠 **澄清问题可以经得起真实使用场景。** 让 Open Design 继续任务，恰好在它需要你回答时重启，再回来补充答案：OD Next 仍能继续，而不会悄悄放弃工作。失败任务会在收尾前如实说明，已经交付的原型页面也不会再被莫名标成失败。 (#7575, #7980, #7942, #7931, #7949, #8225) 感谢 @lorenzozanee、@Siri-Ray、@app/open-design-crew。

- 🖱️ **聊天记录该滚就能滚。** 修复了聊天区上方的圆角裁剪问题——此前在部分情况下滚轮滚不动聊天记录、菜单会在流式输出时消失。 (#8228, #8223) 感谢 @lefarcen、@Siri-Ray。

- 💬 **失败时说人话。** 运行失败卡片的文案、按钮和禁用说明统一对齐产品定稿：能重试的才说重试，不能发的会讲清楚卡在哪一步。 (#8242) 感谢 @app/open-design-crew。

- 🔁 **重试终于能从中断处接上。** Cloud 重试会等待权限与历史准备就绪；瞬时读取错误会恢复；折叠任务保留阻断状态并重试真正失败的运行。还有待回答的问题时，待办也不会抢先往下走。 (#7953, #7954, #7955, #7967, #7981, #7989, #8250) 感谢 @app/open-design-crew、@lefarcen。

- 🛠️ **工具执行过程看得见。** Codex 与 OpenCode 的工具调用在参数还在生成时就会出现在对话里，不必等到调用结束才知道它在做什么；ACP 的已缓冲文本、失败工具结果和真正的取消也都会回到对话。 (#8117, #7959, #8015, #8046, #8063) 感谢 @app/open-design-crew、@Siri-Ray。

- 🖼️ **多 artifact 对话保持你选择的顺序。** 封面图失败仍有可用回退；正在查看的卡片会接收实时更新；图片行可横向浏览；请求的文件范围和选中的 artifact 顺序也始终可见。 (#8045, #8060, #8062, #8013) 感谢 @app/open-design-crew。

- 🧰 **使用自己的模型，不必绕进隐私死角。** 即使 BYOK provider 无法完整声明能力，图片输入仍可使用；代理 Basic 凭据也不会进入导出或媒体工具令牌通道。 (#8035, #7999, #8006) 感谢 @Siri-Ray、@readwrightexecute。

- 📦 **安装后的 App 能守住自己的运行引擎。** 打包 MCP 与 sidecar 交付保持完整；更新器清理时不会删掉仍在工作的 launcher payload；打包构建也提高了内存上限，避免构建期崩溃。 (#8027, #7963, #8212) 感谢 @PerishCode、@Siri-Ray。

> 📥 **下载：** 发布资产将显示在 [Open Design 0.23.0](https://github.com/nexu-io/open-design/releases/tag/open-design-v0.23.0)。

## 🔁 变更

- 运行计时从实际开始时刻计算；折叠运行各自保留自己的时钟；发送准入期间 composer 持续显示准备中；重试卡也会如实说明当前的发送门槛。 (#7921, #7927, #8059, #8069) 感谢 @lefarcen。
- Cloud 与 AMR 的账号、余额和升级链接现在会进入当前控制台路由，不再把人带到失效页面。 (#8126) 感谢 @nettee。
- Agent 所属的 Codex thread 会在任务终态后归档，已结束的本地工作不再像仍在运行。 (#8051)
- 客户端活动点位统一接入，展示与回执更稳定；Test 上下文被替换后会自动恢复，hover 点位会等到真正可见再计数。 (#7986, #8210, #8263) 感谢 @alchemistklk。
- 内置 Vela CLI 升级到 0.0.38。 (#8224, #8273) 感谢 @Siri-Ray。

## 🐛 修复

### 💬 对话与界面

- Continue 会留在所属对话轮次；问题表单控件跟随 UI 语言；超长问题标题保持可读；原生 tooltip 不再打断选择流程。 (#8014, #8010, #8031, #8033) 感谢 @lefarcen。
- 窄聊天面板仍显示底部操作和时间；终态 artifact 恢复会尊重你当前的预览；上传附件保留真实大小。 (#8001, #8050, #8030) 感谢 @lefarcen。
- 更早的问题表单、重复读文件的范围、artifact 更新和成功图片后的下一步操作都会留在所属对话轮次；工作区写入不再冒充交付物，未设计过的辅助卡片也会自动让出空间。 (#7996, #7997, #8019, #8047, #8057, #7920, #7956) 感谢 @lefarcen。

### 🔑 模型、媒体与诊断

- AMR 媒体模型聊天会遵循正确的模型保护；工作区诊断在失败时保留受限的环境证据，方便说明问题。 (#7695, #7951) 感谢 @Siri-Ray、@lefarcen。
- 客户端安全遥测会携带平台上下文，并使用规范的监控分类，让真实环境中的错误更容易查找和比较。 (#7944, #7945)
- OD Next 任务的完整证据会保留下来，取消、失败和缺证据三种情况互相区分得开。 (#8220) 感谢 @lbjzz-hash。
- AMR 已提交的压缩工作会接着跑完，不再从头重放。 (#7958) 感谢 @Siri-Ray。

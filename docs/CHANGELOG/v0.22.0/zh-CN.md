### 🌟 Codename: *Sota Design now on open models*

🔎 **`66 PRs` · `10 contributors` · `7 days`** — **创作不该让你猜刚刚发生了什么。** 过去，工具、模型、项目或桌面端刚变复杂，运行过程就容易丢掉线索 → 现在，产物、解释与下一步会一路随行。🚀

## 🔥 亮点

- 🧭 **运行过程会保留证据。** 文件、封面、引用、产出、途中指令与恢复信息都会跟随对话，不再消失在一个模糊的“已完成”状态里。 (#7518) 感谢 @lefarcen。
- 🛟 **失败会说明下一步。** ACP、模型、权限、配额与 runtime 问题都会保留真正有用的原因；失败不再是死路，而是可判断的下一步。 (#6267, #7316, #7429, #7458, #7534, #7647) 感谢 @helsome、@Siri-Ray。
- 🎬 **媒体任务经得起真实使用。** 图片和视频任务在打包版 Open Design 中能更可靠地恢复，Team 项目生成时也会持续使用自己的计费归属。 (#7504, #7723, #7746) 感谢 @alchemistklk、@lbjzz-hash。
- 🪟 **桌面应用终于像一个可靠的安装版应用。** 首次启动控件、macOS Home 准备状态、更新入口与应用深链，都在真实安装环境中更稳定。 (#7479, #7482, #7535, #7688, #7700) 感谢 @lefarcen、@Siri-Ray、@alchemistklk。
- 🧩 **预览会留在原来的上下文。** 富 HTML 设计、Deck 封面、旧版缩略图导航和编辑交接都会保留你正在使用的结构与状态。 (#7421, #7422, #7556, #7558, #7568, #7592, #7651) 感谢 @lefarcen、@Siri-Ray。

> 📥 **下载：** Tag [`open-design-v0.22.0`](https://github.com/nexu-io/open-design/releases/tag/open-design-v0.22.0)。

## ✨ 新增

### 🧠 Agent、runtime 与 sandbox

- 🧰 **Codex 会话终于有了稳定的容身之处。** Open Design 能承接 Codex app-server 的流式回复和工具工作，让结果不再像黑箱。 (#7518) 感谢 @lefarcen。
- 🧪 **Labs 让实验保持可理解。** Design Harness 有了明确的设置入口，会保存你的选择；当策略接管选择时，也会说清楚原因。 (#7445, #7514) 感谢 @lefarcen。
- 🖼️ **真实对象使用真实图片。** 请求具体人物、产品、作品、活动或地点时，Open Design 会寻找真实对象，而不是生成一个看起来像的替代品。 (#7436)
- 🧑‍💻 **独立 Terminal 工作拥有完整生命周期。** 启动、完成、取消和返回都更干净，不再留下幽灵会话。 (#7716, #7742) 感谢 @PerishCode。

### 🔑 模型与媒体

- 🤖 **模型选择更诚实。** 新模型可被发现，已退役模型会解释原因，AMR 也不会在存在限制时承诺“无限”。 (#7401, #7544, #7627, #7686) 感谢 @koeseo、@Siri-Ray、@lefarcen。
- 🔗 **同步失败不会藏起团队项目。** 一次短暂同步错误不再让团队已经发布的项目从列表中消失。 (#7781, #7785)

## 🐛 修复

### 🎨 Studio、编辑与画布

- 🗂️ **打开真正想打开的项目。** 进入项目时不再编造未知事实，artifact 升级提示也只会留在当前项目。 (#7428, #7689, #7696) 感谢 @lefarcen、@Siri-Ray。
- 💬 **看得到的问题一定答得上。** 澄清表单会让任务保持可继续状态，并且只接收一次回答。 (#7509, #7512)

### 🖥️ 桌面与配置

- ✅ **继续 onboarding 前先检查引擎。** 无效 runtime 会更早被发现，并给出可继续处理的方向，而不是在之后变成谜一样的失败。 (#7440, #7743)
- 🌐 **应用深链会回到应用本身。** 打包版 Open Design 保持正常的登录和邀请回跳；开发 build 不再抢占系统链接。 (#7479) 感谢 @lefarcen。

### 🌍 界面与语言

- 📣 **正确的下线提示会说正确的语言。** Go Plan 提示现在会触达正确的人，并保留用户选定的 locale。 (#7453, #7477) 感谢 @nettee。

## Open Design అంటే ఏమిటి

🎨 **లోకల్-ఫస్ట్, ఓపెన్-సోర్స్ [Claude Design][cd] ప్రత్యామ్నాయం.** &nbsp;🖥️ **macOS మరియు Windows కోసం native డెస్క్‌టాప్ యాప్.** &nbsp;⚡ **100+ స్కిల్స్** · ✨ **150 బ్రాండ్-గ్రేడ్ `DESIGN.md` సిస్టమ్‌లు** · 📦 **261 ఉపయోగించడానికి సిద్ధమైన ప్లగిన్‌లు.** &nbsp;🖼️ **web · desktop · mobile ప్రొటోటైప్‌లు**, **లైవ్ డాష్‌బోర్డ్‌లు / ఆర్టిఫ్యాక్ట్‌లు**, **decks**, **ఇమేజ్‌లు**, **వీడియో**, మరియు **HyperFrames** మోషన్ గ్రాఫిక్స్ జనరేట్ చేస్తుంది. 🔒 సాండ్‌బాక్స్డ్ iframe ప్రివ్యూ · HTML / PDF / PPTX / MP4 ఎక్స్‌పోర్ట్. &nbsp;🤖 **Claude Code · OpenClaw · Codex · Cursor · OpenCode · Qwen · Copilot · Amp · Hermes · Kimi · Antigravity మరియు 22 లోకల్ CLI లపై రన్ అవుతుంది**, లేదా BYOK ద్వారా ఏ OpenAI-కాంపాటిబుల్ ఎండ్‌పాయింట్.

Open Design అంటే Anthropic అనుకున్నట్లుగా Claude Design తో షిప్ చేసిన **agent-native** లూప్ — brief కనుగొనండి, direction లాక్ చేయండి, artifact స్ట్రీమ్ చేయండి, విమర్శించండి, డెలివర్ చేయండి — క్లోజ్డ్ గా ఉండకుండా, మీ ల్యాప్‌టాప్‌లో ఉన్న కోడింగ్ ఏజెంట్‌లు చదవగలిగే, రాయగలిగే, మరియు రీమిక్స్ చేయగలిగే **స్కిల్స్, డిజైన్ సిస్టమ్‌లు, మరియు ప్లగిన్‌ల ఫైల్‌సిస్టమ్** గా మారినప్పుడు దక్కేది. మీ CLI డిజైన్ ఇంజిన్ అవుతుంది, మీ ల్యాప్‌టాప్ స్టూడియో అవుతుంది, మరియు మీ టీమ్ యొక్క `DESIGN.md` బ్రాండ్ కాంట్రాక్ట్ అవుతుంది.

ఇది **agent యుగపు Figma ప్రత్యామ్నాయం** కూడా — కాన్వాస్ పై పిక్సెల్‌లను నెట్టడం కంటే, ఇది రియల్ CSS, రియల్ ఫాంట్‌లు, రియల్ కంపోనెంట్‌లలో single-page ఆర్టిఫ్యాక్ట్‌లను డెలివర్ చేస్తుంది, HTML / PDF / PPTX / MP4 కు నేరుగా ఎక్స్‌పోర్ట్ — ఇప్పటికే మీ డిజైన్ సిస్టమ్ ద్వారా రూపొందించబడి, మీరు ప్రతిరోజూ ఉపయోగించే ఏజెంట్ లోపలే runnable.

## ప్రొడక్ట్ టూర్

Open Design అంటే ఏమిటో, ఏమి చేస్తుందో ఒక త్వరిత చూపు. **Home** నుండి ప్రారంభించండి, **Automation** తో రిపీట్ వర్క్‌ఫ్లోలను ఆర్కెస్ట్రేట్ చేయండి, **Design System** లో బ్రాండ్ కాంట్రాక్ట్ ను డిస్టిల్ చేయండి, మరియు **Plugins** మరియు **integrations** తో ఎక్స్‌టెండ్ చేయండి; ఏ ప్రాజెక్ట్ యొక్క **Studio** లోపల, ఒకే డిజైన్ సిస్టమ్ ప్రొటోటైప్‌లు, లైవ్ ఆర్టిఫ్యాక్ట్‌లు, HyperFrames, decks, మరియు ఇమేజ్‌లను స్ట్రీమ్ చేస్తుంది.

## ప్లాట్‌ఫారమ్ కాంపాటిబిలిటీ

> Open Design **స్కిల్స్, ఒక CLI, మరియు ఒక MCP సర్వర్** గా వస్తుంది, వీటిని మెయిన్‌స్ట్రీమ్ కోడింగ్ ఏజెంట్‌లు native గా కన్స్యూమ్ చేస్తాయి. OD ఇన్‌స్టాల్ అయ్యాక, ఒకే `od mcp install <agent>` ఆ MCP సర్వర్ ను ఆ ఏజెంట్ కాన్ఫిగ్ లోకి వైర్ చేస్తుంది, మరియు మీరు ఏ ఏజెంట్ లోపల నుండి ఒకే టూల్స్ కాల్ చేస్తారు.

## Open Design ఎందుకు

> **ఏప్రిల్ 2026 లో, Anthropic అనుకున్నట్లుగా [Claude Design][cd] ను రిలీజ్ చేసింది — ఒక LLM prose రాయడం ఆపి నేరుగా డిజైన్ ఆర్టిఫ్యాక్ట్‌లను డెలివర్ చేయడం ప్రారంభించిన మొదటిసారి.** అది వైరల్ అయింది. కానీ అది closed-source, paid-only, cloud-only, Anthropic యొక్క మోడల్, Anthropic యొక్క స్కిల్స్, Anthropic యొక్క surface కు లాక్ అయింది. checkout లేదు, self-host లేదు, Vercel deploy లేదు, మీ-స్వంత-ఏజెంట్-స్వాప్ లేదు.

Open Design (OD) ఓపెన్-సోర్స్ ప్రత్యామ్నాయం. ఒకే లూప్, ఒకే artifact-first mental model, లాక్-ఇన్ ఏమీ లేదు:

- 🤖 **Agent-native, model-agnostic.** మేము ఒక ఏజెంట్ షిప్ చేయము. మీ `PATH` లో ఉన్న `claude` / `codex` / `cursor-agent` / `copilot` / `hermes` / `kimi` నే డిజైన్ ఇంజిన్. ఒక క్లిక్ తో స్వాప్.
- 🧠 **డిఫాల్ట్ గా బ్రాండ్-గ్రేడ్.** ప్రతి render యాక్టివ్ `DESIGN.md` ను చదువుతుంది — palette, type, spacing, motion, voice, anti-patterns కవర్ చేసే ఒక 9-section schema. 150 సిస్టమ్‌లు రెపోతో షిప్ (Linear, Stripe, Vercel, Airbnb, Apple, Tesla, Notion, Anthropic, Cursor, Supabase, Figma…). ఒక ఫోల్డర్ డ్రాప్ చేయండి, picker దాన్ని కనుగొంటుంది.
- 🖥️ **లోకల్-ఫస్ట్, ప్రతి లేయర్ లో BYOK.** macOS (Apple Silicon + Intel) మరియు Windows (x64) కోసం native డెస్క్‌టాప్ యాప్‌లు. ఆప్షనల్ release lane లో Linux AppImage. telemetry లేదు, cloud round-trip లేదు. daemon డేటా పాత్‌లను వివరించడానికి ముందు, కంట్రిబ్యూటర్లు మరియు ఆపరేటర్లు తప్పనిసరిగా `AGENTS.md` → **Daemon data directory contract** చదవాలి. ఈ README దాన్ని రీస్టేట్ చేయకూడదు.
- 🌍 **మూడు ప్లేన్‌లలో composable.** **Plugins** runnable workflows క్యారీ చేస్తాయి · **skills** ఏజెంట్ యొక్క డిజైన్ taste క్యారీ చేస్తాయి · **design systems** బ్రాండ్ క్యారీ చేస్తాయి. మూడూ ఎవరైనా author, version, మరియు publish చేయగలిగే plain files.
- 🔁 **ఉన్న codebase ను refresh చేయండి.** ఏజెంట్ కు ఒక `git` repo + `DESIGN.md` ఇవ్వండి, అది మీ నిజమైన కంపోనెంట్‌లను బ్రాండ్ spec కు refactor చేస్తుంది. ప్రత్యేక plugins Figma / Pencil workflows ను React / Next.js / Vue code గా migrate చేస్తాయి.
- 🔒 **కన్విక్షన్ ద్వారా privacy.** అన్నీ మీ డేటా ఉన్నచోటే రన్ అవుతాయి — మీ ల్యాప్‌టాప్, మీ టీమ్ సర్వర్, మీ Vercel ప్రాజెక్ట్. నెట్‌వర్క్ అవసరమైనప్పుడు, BYOK ప్రాక్సీ SSRF-guarded.

- **Windows** (x64) → [**open-design.ai**](https://open-design.ai/) లేదా [GitHub Releases](https://github.com/nexu-io/open-design/releases)
- **Linux** (AppImage, optional lane) → [GitHub Releases](https://github.com/nexu-io/open-design/releases)

ఇన్‌స్టాల్ తర్వాత: యాప్ మీ `PATH` లో ఉన్న ప్రతి కోడింగ్-ఏజెంట్ CLI ను auto-detect చేస్తుంది, 100+ skills మరియు 150 design systems లోడ్ చేస్తుంది, మరియు entry view లో ఒక brief టైప్ చేయనివ్వుతుంది.

### 🤖 మీ కోడింగ్ ఏజెంట్ లోకి ఇన్‌స్టాల్ (UI లేదు)

మీరు GUI తెరవకుండా Open Design ఉపయోగించవచ్చు — Claude Code, Codex, Cursor, Copilot, OpenClaw, Antigravity, Hermes, Kimi, మరియు మరిన్నింటి లోపల ఒక స్కిల్, ప్లగిన్, లేదా MCP సర్వర్ గా కాల్ చేయండి.


### ఒక పూర్తి workflow — brief నుండి artifact వరకు

`brief → plugin → direction → design system → artifact → handoff → memory`

1. **ఒక PM ఒక brief సబ్‌మిట్ చేస్తుంది.** plugin picker landing page · pitch deck · dashboard · social post · PM spec · OKR scorecard… ఆఫర్ చేస్తుంది.
2. **ఒక designer (లేదా ఏజెంట్) direction లాక్ చేస్తారు.** బ్రాండ్ లేదా? 5 curated directions నుండి పిక్ చేయండి. బ్రాండ్ ఉందా? ఒక screenshot / URL డ్రాప్ చేయండి → ఏజెంట్ GitHub కనెక్ట్ చేస్తుంది, Figma ఇంపోర్ట్ చేస్తుంది, మరియు ఒక రీయూజబుల్ `DESIGN.md` కోడిఫై చేస్తుంది.
3. **ఏజెంట్ మొదటి `<artifact>` ఎమిట్ చేస్తుంది.** Plugin + skill + `DESIGN.md` బైండ్ అయ్యాయి. అది ఒక సాండ్‌బాక్స్డ్ iframe లోకి స్ట్రీమ్ అవుతుంది, in place editable — "regenerate from scratch" కాదు.
4. **ఇంజనీరింగ్ కు హ్యాండ్-ఆఫ్.** artifact నిజమైన HTML/CSS — కోడ్ గా కొనసాగించడానికి Cursor, Codex, లేదా Claude Code లోకి డ్రాప్ చేయండి. లేదా PPTX / PDF / MP4 నేరుగా marketing కు ఎక్స్‌పోర్ట్.
5. **మీరు ఉపయోగించేకొద్దీ Open Design స్మార్ట్ అవుతుంది.** మీ screenshots, fonts, palettes, మరియు confirmed artifacts తదుపరి సెషన్ కోసం defaults గా పోగుపడతాయి. తక్కువ rework, తక్కువ drift.

## మీ కోడింగ్ ఏజెంట్ నుండి Open Design ఉపయోగించండి

Open Design ఒక **stdio MCP సర్వర్** మరియు per-agent **install scripts** షిప్ చేస్తుంది. మరొక రెపోలో ఉన్న ఏ MCP-compatible ఏజెంట్ మీ లోకల్ Open Design ప్రాజెక్ట్‌ల నుండి files ను నేరుగా చదవగలదు — tokens CSS, JSX components, entry HTML — name ద్వారా queryable structured API గా. ఏజెంట్ ఎల్లప్పుడూ live file చూస్తుంది, stale export కాదు.

```bash
# One-line install (16+ CLIs supported):
curl -fsSL https://open-design.ai/install.sh | sh -s <agent>

# తర్వాత ఏజెంట్ కింది విధంగా చేయగలదు:
od search-files "primary button"      # ప్రాజెక్ట్‌లలో files సెర్చ్
od get-file design-systems/linear-app/DESIGN.md
od get-artifact <slug>                # latest rendered artifact
od plugin run web-prototype --brief "..."
od skill list --scenario marketing
```

**MCP ఎందుకు?** ప్రతి iteration లో ఒక zip ఎక్స్‌పోర్ట్ చేసి మళ్లీ అటాచ్ చేయడం flow ను బద్దలు చేస్తుంది. MCP design source ను నేరుగా expose చేస్తుంది — ఏజెంట్ ఎల్లప్పుడూ live file చూస్తుంది.

**సుద్దా నుండి ప్రారంభమయ్యే ఏజెంట్ కోసం,** installer `~/.config/<agent>/open-design.json` (లేదా platform equivalent) మరియు ఒక copy-paste MCP snippet పెడుతుంది. Cursor కు ఒక one-click deeplink; Claude Code కు ఒక `claude mcp add-json` one-liner; ప్రతి ఇతర ఏజెంట్ కు దాని config expect చేసే schema లో JSON. పూర్తి per-agent flow → డెస్క్‌టాప్ యాప్ లో **Settings → MCP server**, లేదా [`docs/agent-adapters.md`](../../docs/agent-adapters.md).

**Security model.** డిఫాల్ట్ గా read-only, డెమోన్ `127.0.0.1` కు బైండ్, మరియు SSRF ప్రాక్సీ edge వద్ద బ్లాక్. LAN exposure ఒక explicit `OD_BIND_HOST` మరియు `OD_ALLOWED_ORIGINS` కావాలి. Connector credentials మరియు live-artifact preview routes ఏదైనా ఉన్నా loopback-only గానే ఉంటాయి.

### Plugins ఉపయోగించడం

Plugins **web UI** మరియు **`od` CLI** అంతటా full parity — ఒకే `/api/plugins` endpoints, సరిపోయేది పిక్ చేయండి.

**డెస్క్‌టాప్ / web యాప్ లో:** **Plugin** పేజీ తెరిచి marketplace browse చేయండి మరియు **Install** క్లిక్; ప్రాజెక్ట్ Studio లోపల, plugins apply చేయడానికి మీరు క్లిక్ చేసే composer chips గా కనిపిస్తాయి (వాటి declare చేసే inputs తో).

**కమాండ్ లైన్ పై** (UI లేకుండా రన్ — external ఏజెంట్‌లు ఉపయోగించే path):

```bash
od plugin list                       # installed plugins జాబితా (--task-kind / --mode / --tag filters)
od plugin search "landing page"      # keyword ద్వారా సెర్చ్
od plugin info od-default            # ఒక plugin యొక్క metadata, inputs, capabilities ఇన్స్పెక్ట్
od plugin install od-figma-migration # registry నుండి install; ./local-folder లేదా https://… link కూడా accept
od plugin apply od-default --input brief="a one-page pitch for our seed round"
od plugin upgrade od-default         # upgrade
od plugin uninstall od-default       # uninstall
```

ప్రతి కమాండ్ `--json` సపోర్ట్, కాబట్టి దాన్ని `jq` / `xargs` ద్వారా ఆటోమేషన్ లోకి pipe చేయవచ్చు.

### ఒక plugin బిల్డ్ చేయడం

ఒక plugin కు **కనీసం ఒక `SKILL.md` మాత్రమే అవసరం**; Open Design marketplace లో జాబితా చేయడానికి, ఒక `open-design.json` జోడించండి:

```
my-plugin/
├── SKILL.md            ← required: YAML frontmatter (name · description) + trigger phrasing + workflow (< 500 lines లక్ష్యం)
├── open-design.json    ← జాబితా చేయడానికి అవసరం: marketplace metadata + inputs + pipeline + capabilities
├── README.md           ← optional: usage, install, registry links
├── preview/            ← optional: index.html / poster.png (visual plugins కోసం strongly recommended)
└── examples/           ← optional: concrete use cases
```

కోర్ `open-design.json` fields: `specVersion` (ప్రస్తుతం `1.0.0`), `name` (stable ID), `version` (semver), `compat.agentSkills[].path` (`./SKILL.md` కి పాయింట్), `od.kind` (`skill` / `scenario` / `atom` / `bundle`), `od.taskKind` (`new-generation` / `figma-migration` / `code-migration` / `tune-collab`), `od.mode` (output surface, ఉదా. `prototype` / `deck` / `live-artifact` / `image` / `video` / `hyperframes` / `audio` / `design-system` / `scenario`), `od.capabilities[]` (**కనీసం declare చేయండి** — ఒక restricted install డిఫాల్ట్ గా `prompt:inject` మాత్రమే grant), `od.inputs[]` (apply-time parameters).

Scaffold + locally validate:

```bash
od plugin scaffold --id my-plugin --title "My Plugin"   # skeleton generate
od plugin validate ./my-plugin                          # manifest / file layout తనిఖీ
pnpm guard && pnpm --filter @open-design/plugin-runtime typecheck
```

పూర్తి field set మరియు runtime contract → [`plugins/spec/SPEC.md`](../../plugins/spec/SPEC.md); ఒక కోడింగ్ ఏజెంట్ తో plugin develop చేయడం → [`plugins/spec/AGENT-DEVELOPMENT.md`](../../plugins/spec/AGENT-DEVELOPMENT.md); copy-paste minimal templates → [`plugins/spec/examples/`](../../plugins/spec/examples/).

### ఒక plugin contribute చేయడం

1. plugin folder ను [`plugins/community/`](../../plugins/community/) లోకి డ్రాప్ (third-party plugins), లేదా — Open Design తో bundled గా ship చేయడానికి — [`plugins/_official/`](../../plugins/_official/) యొక్క matching tier లోకి.
2. validation pass: `od plugin validate`, `pnpm guard`, `pnpm --filter @open-design/plugin-runtime typecheck`.
3. [`plugins/spec/CONTRIBUTING.md`](../../plugins/spec/CONTRIBUTING.md) లో template ఉపయోగించి PR నింపండి (ID, version, lane, mode, capabilities, trigger examples; visual plugins కోసం screenshot / preview అటాచ్).
4. ఒక external registry కు publish (skills.sh / ClawHub / standalone GitHub) → [`plugins/spec/PUBLISHING-REGISTRIES.md`](../../plugins/spec/PUBLISHING-REGISTRIES.md).

Plugin registry endpoint: `GET /api/plugins`. Directory overview → [`plugins/README.md`](../../plugins/README.md) ([简体中文](../../plugins/README.zh-CN.md)).

## ఆర్కిటెక్చర్

```
┌────────────────── browser (Next.js 16) / Electron shell ──────────────┐
│  chat · file workspace · iframe preview · settings · import · MCP     │
└──────────────┬─────────────────────────────────────┬─────────────────┘
               │ /api/*                              │
               ▼                                     ▼
   ┌─────────────────────────────────┐   /api/proxy/{provider}/stream (SSE)
   │  local daemon (Express+SQLite)  │   ─→ any OpenAI-compatible BYOK,
   │                                  │       SSRF-guarded at the edge
   │  /api/skills    /api/plugins    │
   │  /api/design-systems            │
   │  /api/chat (SSE)   /api/proxy/* │
   │  /api/projects/:id/files/...    │
   │  /api/artifacts/{save,lint}     │
   │  /api/import/claude-design      │
   │  MCP stdio server                │
   └─────────┬───────────────────────┘
             │ spawn(cli, [...], { cwd: managed project cwd })
             ▼
   ┌──────────────────────────────────────────────────────────────────┐
   │  claude · codex · cursor-agent · copilot · openclaw · antigravity ·│
   │  gemini · opencode · qwen · qoder · hermes (ACP) · kimi (ACP) ·    │
   │  pi (RPC) · kiro · kilo · vibe (ACP) · cline · trae · deepseek     │
   │  reads SKILL.md + DESIGN.md, writes artifacts to disk             │
   └──────────────────────────────────────────────────────────────────┘
```

| లేయర్ | Stack |
|---|---|
| Frontend | Next.js 16 App Router + React 18 + TypeScript |
| Daemon | Node 24 · Express · SSE streaming · `better-sqlite3` |
| Storage | daemon storage paths మార్చడానికి లేదా డాక్యుమెంట్ చేయడానికి ముందు, మీరు తప్పనిసరిగా `AGENTS.md` → **Daemon data directory contract** చదవాలి. ఈ README దాన్ని రీస్టేట్ చేయకూడదు. |
| Preview | Sandboxed `srcdoc` iframe + streaming `<artifact>` parser |
| Export | HTML (inlined) · PDF (browser print) · PPTX (agent-driven) · ZIP · Markdown · MP4 (HyperFrames) |
| Desktop | Electron shell + sandboxed renderer + sidecar IPC (STATUS · EVAL · SCREENSHOT · CONSOLE · CLICK · SHUTDOWN) |
| Lifecycle | ఒకే entry point: `pnpm tools-dev` (start / stop / run / status / logs / inspect / check) |

పూర్తి ఆర్కిటెక్చర్ → [`docs/architecture.md`](../../docs/architecture.md). Skill protocol → [`docs/skills-protocol.md`](../../docs/skills-protocol.md). Agent adapter contract → [`docs/agent-adapters.md`](../../docs/agent-adapters.md).

### 🤖 ఏజెంట్ గా contributing

*మీరే దీన్ని చదువుతున్న ఏజెంట్ అయితే*, వేగవంతమైన path:

```bash
# 1. Boot locally
git clone https://github.com/nexu-io/open-design.git
cd open-design && corepack enable && pnpm install
pnpm tools-dev run web

# 2. ఒక good-first-issue కనుగొని మీకు assign చేయండి

# 3. మార్పు చేసి, checks రన్
pnpm guard && pnpm typecheck
pnpm --filter @open-design/<package> test

# 4. PR ఓపెన్
gh pr create --fill
```

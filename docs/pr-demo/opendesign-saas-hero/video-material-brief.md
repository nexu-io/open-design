# OpenDesign SaaS Hero PR 视频素材说明

## 核心用途

用于 PR 描述区或发布帖里的短视频/动图素材，展示 OpenDesign 从一句 brief 到可交付 HTML 设计资产的工作流。主画面使用 `docs/pr-demo/opendesign-saas-hero/index.html`。

## 推荐成片

- 画幅：16:9，1920 x 1080
- 时长：12-15 秒
- 风格：现代 SaaS 发布页，白底、深墨文字、少量绿色状态点
- 输出：MP4 用于 PR 正文，另导出一份 GIF 用于 GitHub 评论

## 镜头脚本

| 时间 | 画面 | 旁白/字幕 |
| --- | --- | --- |
| 0.0-2.5s | 全景打开 Hero，品牌与主标题进入视野 | `OpenDesign turns a brief into a PR-ready artifact.` |
| 2.5-5.5s | 缓慢推近左侧主张和 CTA | `Design systems, plugins, and agent workflows in one local studio.` |
| 5.5-9.5s | 平移到右侧产品画面，突出 timeline 四步 | `Discovery, tokens, generation, review.` |
| 9.5-12.0s | 定格在 `PR-ready` 与底部能力条 | `HTML artifact + video brief, ready to attach to the PR.` |

## 录屏操作建议

1. 打开 `index.html`，浏览器宽度保持 1440px 或更宽。
2. 录制时不要滚动页面，使用一次轻微的横向 pan 或后期裁剪移动。
3. 鼠标可在第 3 秒悬停 `Start from a brief`，但不要点击。
4. 结尾停留在右侧 `PR-ready` 状态 1.5 秒，方便 PR 读者看清楚结果。

## PR 文案可直接使用

```text
Adds a modern SaaS-style OpenDesign hero demo for PR review. The artifact shows the product promise, generated design preview, and a short agent workflow timeline, with a companion video brief for recording a 12-15 second demo clip.
```

## 素材检查清单

- Hero 首屏不依赖外部字体、图片或脚本。
- 颜色集中在 HTML 的 `:root` token，方便后续换设计系统。
- 右侧产品画面包含可录屏的动态状态，避免只是一张静态卡片。
- PR 视频说明包含镜头、字幕、时长、画幅和导出建议。

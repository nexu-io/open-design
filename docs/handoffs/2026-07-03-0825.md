## Anti-Patterns (이번 세션에서 발견)
| 패턴 | 내용 | 심각도 | 회피책 |
|---|---|---|---|
| question-form auto-continue 방치 | Questions 폼에 2분 auto-continue 타이머 — 도그푸딩 중 방치하면 기본값으로 자동 제출돼 다음 턴 진행(토큰 소모 + 원치 않는 산출) | advisory | 게이트 검증만 목적이면 확인 직후 페이지 이탈(타이머 언마운트) 또는 즉시 답변 |
| 스킬 게이트를 화살표 체인으로만 서술 | "제시 → 컨펌 → Write" 문구는 모델이 턴 중간(리서치 직후)에 관성 직행해도 어기는 문장이 없음 | blocking급 교훈 | 게이트에는 "즉시 턴 종료 + 답변 도착 전 Write 금지" 명시 지시 필수 (PR #9 패턴) |
| worktree 서브에이전트에 pnpm install 누락 가정 | fresh worktree엔 node_modules 없음 — 테스트 실행 전 `pnpm install` (Node 24 PATH로) 필요 | advisory | dispatch 프롬프트에 pnpm install 단계 명시 |

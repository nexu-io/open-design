# Blocking Constraints — 재개 시 먼저 읽고 체크
> 이번 세션 실측으로 발견된 제약. 재개 에이전트는 각 항목 이해 표명 후 진행.

- [ ] CONSTRAINT: **scope rename = import 동반 필수** — tsconfig path alias **없음**. 모듈 해석이 package `name` 기반. `package.json` name만 바꾸면 `@open-design/` import 1037곳/512파일이 깨짐 → typecheck 실패. 회피: 스코프 치환은 import문·`workspace:*` 키 포함 **repo-wide**.
- [ ] CONSTRAINT: **env OD_ 중앙화 안 됨** — `process.env.OD_*` 직접 읽기 ~880곳 산재. const 정의만 바꾸면 런타임 깨짐. 회피: `OD_` 전역 치환.
- [ ] CONSTRAINT: **macOS BSD sed `\b` 미지원** — 앵커 치환은 `perl -pi -e` 사용. `OD_`→`MAX_`는 반드시 `\bOD_`(PROD_/METHOD_/PERIOD_ 오염 방지).
- [ ] CONSTRAINT: **데이터 디렉터리 `.od` 앵커 필수** — `.odd` 등 부분일치 오염 금지. `'.od'`/`"/.od"`/`.od/`/regex만.

## Anti-Patterns (이번 세션에서 발견)
| 패턴 | 내용 | 심각도 | 회피책 |
|---|---|---|---|
| surgical const 치환 신뢰 | v1 플랜이 "const 1곳 + sweep" 전제 → 규모 50배 과소평가, 컴파일·게이트 실패 | blocking | 카테고리 전역 치환 (v2 플랜) |
| 블라인드 `OD_`→`MAX_` sed | PROD_/METHOD_ 등 오염 | blocking | `\bOD_` perl |
| 카테고리 병렬 sed | 같은 파일 여러 카테고리 보유 → 동시 편집 충돌 | blocking | 치환은 순차, 검증/리뷰만 병렬 |

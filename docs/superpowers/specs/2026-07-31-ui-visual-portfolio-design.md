# UI 视觉设计个人作品集网站设计

## 目标

创建一个可部署的多页面个人作品集网站，帮助 UI 视觉设计师以作品为主线展示专业能力、项目过程与个人风格。网站需支持桌面端与移动端，并让访客能够在首页、作品、项目详情和关于页面之间清晰跳转。

## 视觉方向

采用编辑画册型风格：

- 浅色背景与充足留白，避免装饰干扰作品。
- 大字号标题与克制的无衬线字体，建立清晰层级。
- 钴蓝作为主强调色，用于链接、按钮和关键标签。
- 作品图使用大尺寸卡片和错落网格，营造策展感。
- 动效保持轻量，仅使用淡入、位移与悬停反馈。

## 页面结构

### 首页

- 个人姓名与 UI 视觉设计师定位。
- 一句简短价值主张。
- 三个精选项目入口，每个入口包含主视觉、项目类型与年份。
- 能力标签：品牌视觉、界面设计、设计系统、交互原型。
- 前往作品页与联系区域的明确行动按钮。

### 作品页

- 展示完整项目网格。
- 每张卡片包含项目封面、名称、领域与职责。
- 卡片可进入对应项目详情。
- 首版不增加复杂筛选，以保证浏览路径直接。

### 项目详情页

- 项目主视觉与概览。
- 背景、挑战、设计过程和最终成果四个内容区。
- 使用界面示意图、设备展示图和局部细节图形成叙事。
- 提供上一个项目、下一个项目及返回作品页的导航。

### 关于页

- 个人简介、工作方式与擅长方向。
- 精简经历时间线和技能列表。
- 邮箱与社交平台联系入口。
- 返回作品页的行动按钮。

## 内容与图片

- 使用原创感的示例项目名称与文案，不引用真实客户或虚构获奖信息。
- 作品视觉以抽象品牌图形、界面排版和设备场景为主。
- 图片均提供替代文本；远程图片加载失败时保持稳定布局与背景占位。
- 首页和作品页的项目数据共享同一来源，避免标题、年份和链接不一致。

## 技术与导航

- 采用静态前端实现，按真实 URL 路径组织多页面体验。
- 顶部导航和页脚在所有页面保持一致。
- 当前页面在导航中有可识别状态。
- 所有内部链接可直接访问，也能通过浏览器前进和后退操作。
- 不需要登录、数据库、表单后端或内容管理系统。

## 响应式与可访问性

- 桌面端使用宽幅网格，移动端改为单列内容流。
- 交互元素具备清晰的键盘焦点样式。
- 正文和按钮颜色满足可读性要求。
- 尊重用户的减少动态效果设置。

## 验收标准

- 至少包含首页、作品页、一个项目详情页和关于页。
- 页面之间的顶部导航、项目卡片和前后项目链接均可用。
- 每个主要页面至少包含一张与内容匹配的图片。
- 在常见桌面与手机宽度下无横向溢出或文字遮挡。
- 刷新任意页面路径仍能正确显示。
- 构建与 Sites 部署成功，提供可访问的生产链接。

## 验证

- 运行项目自身的构建和静态检查。
- 检查所有内部链接与图片资源。
- 以桌面和移动视口做页面截图或浏览器巡检。
- 部署后确认首页与至少一个深层路径可直接打开。

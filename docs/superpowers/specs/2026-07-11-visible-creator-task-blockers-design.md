# 创作者任务阻塞原因展示设计

## 目标

让创作者在 Creator Workbench 的任务列表中无需打开编辑或活动流，就能看出当前阻塞任务卡在哪里。

## 范围

- 仅在持久化人工任务的状态为 `blocked` 且存在 `blockerNote` 时显示。
- 显示格式为 `阻塞：{blockerNote}`，位于任务卡的状态标签下方。
- 样式使用现有琥珀色风险语义，保持紧凑，支持换行。
- 推导任务以及非阻塞人工任务不显示该区域。

## 数据与交互

不新增字段、接口或写入操作。复用既有 `CreatorTaskRecord.blockerNote` 到 `TaskCardViewModel.blockerNote` 的映射。

编辑表单仍是唯一修改入口：保存阻塞任务时更新说明；将任务改为非阻塞状态后，存储层清除说明，卡片区域自然消失。

## 验收标准

1. 有阻塞原因的人工任务展示完整原因。
2. 没有原因或状态不是 `blocked` 的任务不展示原因区域。
3. 推导任务不展示原因区域。
4. 页面测试覆盖显示和隐藏路径，Web 类型检查与生产构建通过。

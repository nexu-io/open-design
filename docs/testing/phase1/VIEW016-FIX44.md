## Actual result

The same browser page loaded the remote model list and completed nine native
choices through Free A → paid Go B → Free A. Viewport was 1280 × 720, DPR 1,
with one worker and zero retries. The homepage model chip and first Flash row
were clicked normally. There was no added pre-click wait, force click, prompt
fill, viewport change, or model generation.

| Stage | Flash | DeepSeek v4 Pro (value) | GPT 5.6 Sol (top) |
| --- | --- | --- | --- |
| Free A, first | correct | **failed: selectable** | **failed: selectable** |
| Go B | correct | correct | correct |
| Free A, return | correct | **failed: selectable** | **failed: selectable** |

Five correct cells do not pass the case. Four Free A selections were enabled
and changed the persisted model despite the fixed disabled expectation. The
actual wrapper exited 1 with both owner verifications 0 and stable source
hashes. The raw legacy status string `product_failure_paid_B_locked` is retained
in evidence; it does not describe this sample's failure. All three B choices
were correct. Zero model requests were generated by this UI flow; selector
results do not prove actual model billing or a money bypass.

The original first-Flash click completed without header interception in this
sample. This is a qualified subpath, not universal closure of older defects.
The new manifestation is **LINK-C21-VIEW-016-002**; older
`APISEC-C20-002` (paid B locked) and `LINK-C21-VIEW-016-001` (header obstruction)
remain distinct. No common root cause is established.

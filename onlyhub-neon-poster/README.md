# OnlyHub ($HUB) — Neon Poster

Original editable poster concept for the OnlyHub bounty.

**Concept:** The internet keeps loading. The night keeps going.

## Files
- `index.html` — interactive poster preview
- `styles.css` — neon visual system
- `script.js` — animated loading/nightclub effect
- `design.json` — editable design specification
- `prompt.md` — AI image-generation prompt

Open `index.html` locally or enable GitHub Pages to preview the design.

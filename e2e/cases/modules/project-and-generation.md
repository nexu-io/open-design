# Project Creation And Generation

This module covers the main entry workflow: create a project, enter the workspace, send a prompt, receive an artifact, and open the preview.

## Automated Cases

- `prototype-basic`: create a prototype project and render a mocked HTML artifact.
- `deck-basic`: create a deck project and render a mocked deck artifact.
- `design-system-selection`: select a design system before creation and verify project metadata.
- `example-use-prompt`: use an example prompt to create a project directly.
- `generation-does-not-create-extra-file`: verify refresh does not create duplicate artifact files.

# design-studio-web — image generation prompt pack

## Global style anchor

Use case: premium creative studio portfolio website.

Create original art-direction photography / 3D editorial imagery for an internationally competitive independent design studio. Visual language: future minimalism, experimental editorial composition, soft glass and refraction, sculptural materials, spatial light, restrained generative geometry, subtle optical distortion, museum-grade calm, cinematic grading, generous negative space. Palette must stay anchored to near-black, neutral graphite, electric blue (#4D7CFE) and aurora cyan (#7CFFCB); saturated accent color should occupy less than 5% of the image. Avoid generic SaaS illustration, literal UI screenshots, cyberpunk clutter, purple gradients, stock-photo poses, obvious AI artifacts, watermarks, embedded logos and unreadable typography.

Images are supporting plates for real HTML typography, so keep one side compositionally quiet when specified. Favor tactile material, architectural scale, light, shadow, transparent acrylic, brushed metal, glass, paper and subtle human traces.

## studio — Studio atmosphere

Large worktable with printed proofs, material samples, grayscale image tests, transparent acrylic objects and a monitor showing abstract generative shapes without readable UI.

# Design Studio Web delivery checklist

## P0 gates

- [ ] The output is a standalone HTML page and opens from disk without a framework runtime.
- [ ] Selected Work contains at least three real or explicitly labelled concept projects; no fabricated claims are presented as verified client evidence.
- [ ] All five image slots resolve from the output-relative asset path, or the page uses the intentional placeholder strategy.
- [ ] The hero remains readable when WebGL is unavailable, JavaScript is disabled, or reduced motion is requested.
- [ ] Desktop horizontal work travel becomes a single-column mobile flow with no horizontal overflow.
- [ ] Every interactive control has a keyboard focus state and the project/contact links remain reachable by keyboard.
- [ ] The final page is checked at 360px, 768px, and 1440px before handoff.

## Content and quality

- [ ] Copy describes the studio point of view, working method, capabilities, and contact path without SaaS feature or pricing language.
- [ ] Recognition, metrics, clients, and awards are source-backed or labelled as fictional demo content.
- [ ] Accent colors remain within the template palette and motion supports hierarchy rather than decorating empty space.

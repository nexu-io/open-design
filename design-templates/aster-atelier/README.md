# Aster Atelier

An original cinematic website template for a creative studio: cobalt sky, classical art, a rotating procedural brass instrument, parchment architecture, and an editorial five-chapter layout.

**Open `example.html` directly in a browser.** It is the complete self-contained page: no build, network requests, external fonts or dependencies are needed. All artwork is embedded. You can edit its CSS, copy and script directly.

For OpenDesign, install the folder containing `open-design.json` and `SKILL.md`. The manifest uses the live HTML as both its preview and generation seed. Its declared capabilities are `prompt:inject` and `fs:write`.

## Features

- Responsive hero and original astronomer / observatory illustrations.
- Scroll parallax, chapter indicator, reveal motion and a procedural Canvas instrument.
- Native-dialog navigation and project form; accessible labels and focus restoration.
- Native service and FAQ accordions.
- Local-only brief saving and text download; no backend is implied.
- Reduced-motion support and canvas pausing while offscreen or hidden.

## Package contents

The distribution contains `example.html`, `open-design.json`, `SKILL.md`, `references/checklist.md`, this README, `LICENSE`, and `ASSET-SOURCES.md`. Edit the standalone HTML directly; no build step is required. The larger original PNG images and local development scripts are excluded.

## OpenDesign discovery

When bundled under `design-templates/aster-atelier/`, this template is discovered by the Prototype mode's “Start from” catalogue. For a separate local installation, use the OpenDesign plugin folder import with this directory; generic Agent Skills clients can consume `SKILL.md` directly.

Version: 1.0.0 — initial original template. The example is a reusable seed, not a connection to a live studio.

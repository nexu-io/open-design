# Braze IAM — 비주얼 레이아웃·컴포지션 문법 (레퍼런스 24장 전수 분석)

> 실제 성과 IAM 레퍼런스 24장(커머스·핀테크·여행·콘텐츠 앱)에서 추출한 문법.
> Step 3 기획안의 `image.composition` 설계와 Step 4b 빌더의 레이어 배치가 본 문서를 따른다.
> 원본 스크린샷은 repo에 없다 — 패턴은 본 문서의 워딩이 정본이며, 생성 프롬프트의
> view_image 앵커로 타사 레퍼런스를 쓰는 것은 금지 (IP·캐릭터 오염).
>
> **번역 규칙 (가장 중요)**: 레퍼런스는 텍스트·배경·오브제가 한 장의 이미지로 구워진
> 완성 크리에이티브다. 우리 파이프라인은 이를 3레이어로 분해해 재현한다 —
> 텍스트는 **HTML 텍스트**(이미지에 굽지 않음), 배경은 **CSS**(단색·그라디언트·장식),
> 오브제만 **투명 PNG 에셋**(library/generate). 이미지 안에 글자가 들어가는 순간
> 로컬라이즈·수정·접근성이 전부 죽는다.

## 1. 3존 분할 — 오브제 히어로 문법 (기본형)

24장 중 대다수가 동일한 수직 3존을 따른다:

```
┌─────────────────────┐
│              [✕]    │
│  아이브로우 (1줄)     │  ← 시점·자격 라벨: "매월 1일부터 10일까지", "회원님께만"
│  헤드라인 (1~2줄)     │  ← 키워드에 브랜드 악센트색: "혜택 ON", "쿠폰 선물"
│                     │
│    ╭─────────╮      │
│    │ 오브제 존 │      │  ← 히어로: 캐릭터·메타포 오브제 클러스터 (프레임 폭 40~60%)
│    ╰─────────╯      │
│                     │
│  [   주 CTA 풀폭  ]  │  ← 행동동사, 브랜드색 or 블랙
│   보조 dismissal    │  ← "다시 보지 않기" 텍스트 링크
└─────────────────────┘
```

**변형 2종** (드물지만 유효):
- **오브제-톱 역전**: 오브제가 상단, 헤드라인이 아래 (하단시트에서 관찰 — 3D 앱 아이콘 히어로 → 텍스트 → CTA). 오브제가 자기설명적일 때만.
- **CTA-미드**: 헤드라인 직후 CTA, 오브제가 하단 장식 (세리프 타이포 중심 멤버십 카드에서 관찰). 오브제가 무드 장식이고 결정이 가벼울 때.

## 2. 레이아웃 유형 5형 (관찰 빈도순)

| 유형 | 구조 | 적합 | 관찰 사례 |
|---|---|---|---|
| **센터 모달 (라이트)** | 밝은 단색/파스텔 bg 카드 중앙 | 혜택·알림 범용 기본값 | 설문 클립보드, 마이데이터 아이콘 클러스터, 감상회 캐릭터 |
| **센터 모달 (다크)** | 블랙/딥컬러 bg + 고채도 오브제·악센트 | 임팩트·긴급·프리미엄 | 쿠폰 슬롯머신, "혜택 못 받으셨어요?" 쿠폰, 스포트라이트 토글 |
| **투톤 카드** | 상단 = 컬러 이미지존, 하단 = 화이트 CTA존 | 브랜드 컬러 강한 캠페인 + 명확한 행동 | 채용 공고(오렌지+화이트), 멤버십 선물(블랙+화이트) |
| **풀시트** | 화면 전체 점유, 배경도 크리에이티브 | 온보딩·시즌 캠페인·상담 전환 몰입 | 설맞이 봉투(크림), 보험 3D 달력, 브랜드 콜라보(포토 상단+시트 하단) |
| **하단시트** | 하단에서 60~70% 상승 | 업데이트 소개·가벼운 발견 | 앱 리뉴얼(3D 아이콘 + 질문형 CTA) |

포맷 선택 자체는 `format-design-guide.md` §0 매트릭스가 우선 — 본 표는 각 포맷 안에서의 비주얼 처리를 정한다.

## 3. 히어로 유형 — 오브제 존에 무엇을 넣는가

| 히어로 유형 | 문법 | 파이프라인 매핑 |
|---|---|---|
| **단일 메타포 오브제** | 오브제 1개 중앙, 크게 (3D 토글, 3D 달력, 자물쇠) | `generate` 1건 (`3d-icon`/`flat-icon`) |
| **오브제 클러스터** | 주 오브제 + 위성 소품 2~4개 산개 (서류+카드+지폐, 랜드마크 3종) | `generate` 1건 (클러스터로 한 번에) or 주 1 + `css` 장식 |
| **쿠폰 티켓** | 절취선·스텁·다운로드 아이콘이 있는 티켓 그래픽, 기울여 배치, 퍼센트 숫자 큼 | `generate` (`flat-icon`) — 단 숫자·문자는 HTML 오버레이로 |
| **캐릭터 히어로** | 브랜드 캐릭터가 소품을 들거나 입고 중앙 (복주머니 든 캐릭터, 4캐릭터 군집) | `library` 클락 컷 (+`generate` 소품 겹침) |
| **타이포-오브제** | 풍선형 3D 레터링이 곧 히어로 ("10x10", "특별상금 50만원") | **회피** — 글자를 이미지에 굽는 문법이라 번역 규칙 위반. 대체: HTML 대형 타이포 + CSS 그림자/그라디언트 |
| **실물 콘텐츠 콜라주** | 실제 상품 사진·콘텐츠 썸네일을 그래픽 프레임에 합성 (선물상자 속 상품, 부채꼴 웹툰 커버) | 브랜드 보유 실물 에셋 있을 때만 (`library`) — 생성 금지 |
| **포토 히어로** | 스튜디오 실사 or 모델 포토 | **생성 전면 금지** (스타일 4종 계약). 브랜드가 실사 자산을 제공한 경우만 `library` |

## 4. 오브제-메시지 메타포 정합 (핵심 룰)

관찰된 전 사례에서 오브제 = 메시지의 시각 은유. 장식이 아니라 의미다:

| 메시지 | 관찰된 오브제 |
|---|---|
| 알림 켜기 | 3D 토글 스위치 (ON 상태) |
| 마감·날짜 | 3D 일력/달력 (해당 숫자) |
| 혜택 잡기 | 낚싯바늘에 걸린 쿠폰 태그 (2개 앱에서 독립 관찰 — 검증된 은유) |
| 선물·보상 | 뚜껑 열린 선물상자, 봉투에서 나오는 쿠폰, 복주머니 |
| 할인 규모 | 프레임을 압도하는 숫자 (200,000 / 75% / ~20%) |
| 설문·의견 | 클립보드+펜, 말풍선 |
| 약속·신뢰 | 새끼손가락 건 두 손 |
| 여행 | 미니어처 랜드마크 + 맵핀 |

기획안 `image.assets[].concept`에는 "무엇이 보여야 하고(오브제·상태) 무엇이 보이면 안 되는지"를
명시한다. 소품이 메시지와 어긋나면 오독을 만든다 — 의미 없는 소품은 빼는 쪽이 낫다.

## 5. 배경 = CSS 문법 (이미지 배경 금지)

| 배경 유형 | 처리 | 관찰 맥락 |
|---|---|---|
| 단색 | 브랜드 토큰 solid | 옐로우 플랫 씬, 크림 캐릭터 카드 |
| 수직 그라디언트 | 2색 토큰 그라디언트 | 핑크 스카이 시즌 씬, 홀로그래픽 파스텔 |
| 스포트라이트 | radial-gradient 상단 광원 + 딥컬러 | 다크 토글 모달 — 프리미엄 연출 |
| 씬 힌트 | 그라디언트 + CSS 도형 2~3개 (파도 라인, 구름 실루엣) | 바다 낚시 씬 |
| 장식 오브 | 말풍선·컨페티·별·꽃잎 = CSS 도형/이모지 급 소형 요소, 4~6개 이하 | 파스텔 오브 2개(달력 옆), 컨페티(축하) |

장식은 `image.assets`의 `source:"css"`로 선언 — 생성 비용 0, 빌더가 CSS로 그린다.

## 6. 컴포지션 룰 (레이어 배치)

- **히어로 스케일**: 오브제 폭 = 프레임 폭 40~60%. 그보다 작으면 아이콘(§format-design-guide 모달 문법)이지 히어로가 아니다.
- **기울임**: 쿠폰·태그·티켓류는 5~15° 기울여 다이내믹하게. 정직한 수평은 정적 오브제(달력·토글)만.
- **겹침**: 캐릭터-오브제, 오브제-텍스트존 살짝 겹침 허용 (z-index) — 단 헤드라인 가독을 해치는 겹침 금지, 캐릭터 얼굴 가림 금지.
- **부유감**: box-shadow 부드럽게 + `interaction-standard.md`의 float 애니메이션. 그림자를 PNG에 굽지 않는다 (배경색 바뀌면 깨짐).
- **산개 소품**: 위성 소품은 히어로 대각 코너 2~3점 배치, 크기 차등 (원근감). 전 코너 채우기 금지 — 여백이 히어로를 만든다.
- **시선 흐름**: 아이브로우 → 헤드라인 → 오브제 → CTA 수직 단일 흐름. 오브제가 CTA를 가리키듯 아래로 무게중심.

## 7. 텍스트 위계 (HTML 렌더)

- **아이브로우**: 12~14px, 시점·자격·긴급 ("매월 1일부터", "회원님께만", "곧 사라지는"). 악센트색 or 필 배지.
- **헤드라인**: 큼 (모달 20~26px, 풀시트 28~32px), 1~2줄, 핵심 키워드만 악센트색 반전 (다크 bg에서 화이트+핑크 조합 관찰).
- **숫자 강조**: 할인·금액 숫자는 헤드라인보다 크게 갈 수 있다 (숫자 히어로) — 단 이미지가 아닌 HTML 대형 타이포로.
- **서브카피**: 1~2줄, secondary 색. 날짜·조건 등 구체 정보에 악센트색 부분 강조.

## 8. CTA·dismissal 문법

- 주 CTA 풀폭 1개, 행동동사 ("받기", "잡아보세요", "열어보기", "연동하러 가기"). 필 or 라운드 사각, 브랜드색/블랙.
- 질문형 CTA도 유효 ("어떻게 좋아졌을까?") — 호기심 전환, 업데이트 소개 맥락.
- 게임화 CTA (슬롯 STOP 등 인터랙티브)는 brazeBridge 제약 안에서만 — `interaction-standard.md` 준수, 과욕 금지.
- dismissal: "다시 보지 않기"·"N일간 보지 않기"는 텍스트 링크로 무게 최소화. 유머 톤 dismissal ("아니, 귀찮아")은 브랜드 보이스가 허용할 때만.
- 닫기 ✕ 우상단 상시 (`iam-close`).

## 9. 시즌·캠페인 스킨

시즌 캠페인은 배경·장식·소품만 갈아입고 문법은 유지: 설날 = 복주머니·소나무·학·기와 실루엣,
봄 = 꽃잎 그라디언트, 연말 = 컨페티·폭죽. 시즌 요소는 `css` 장식 or `generate` 소품으로 선언 —
캐릭터 캐논(클락)은 시즌 소품을 *들거나 옆에 두는* 방식이 안전, 의상 변형은 캐논 리스크.

## 10. 안티패턴 (24장 대조로 확정)

- 이미지에 텍스트 굽기 — 레퍼런스는 굽지만 우리는 금지 (번역 규칙). 생성 프롬프트에 `no text` 상수 유지.
- 실사 생성 — 스타일 4종 계약 위반. 실사는 브랜드 제공 자산 한정.
- 히어로 없이 소품만 산개 — 시선 앵커 부재. 반드시 주 오브제 1개.
- 오브제-메시지 불일치 소품 — 오독 유발 (cardnews 소품-의미 룰과 동일).
- 배경까지 통짜 생성 — 배경은 CSS. 통짜 씬은 캐릭터-오브제 물리 상호작용 필요 시 예외 경로만 (imagegen-pipeline.md).
- 모달 안 콘텐츠 과적 — 목록 4개면 하프시트 (`format-design-guide.md` §0).

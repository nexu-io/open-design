# Braze IAM — 포맷별 디자인 가이드

> SKILL.md Step 4에서 HTML 작성 시 *반드시 본 문서를 Read*한 뒤 적용한다.
> 컨테이너 치수·CSS 패턴은 `size-patterns.md`, 애니메이션은 `interaction-standard.md`.
> 본 문서는 *포맷별 레이아웃 원칙·콘텐츠 적합도·안티패턴*만 다룬다.
>
> 브랜드 토큰(색상·타이포·radius)은 활성 `DESIGN.md` 기준. 동일 토큰이라도
> 포맷마다 레이아웃 문법이 다르다 — 포맷-콘텐츠 갭은 5축 만점이어도 어색해진다.

---

## 0. 포맷 선택 — 콘텐츠 적합도 매트릭스

| 포맷 | 적합 use-case | 콘텐츠 양 | 결정 수 | 부적합 |
|---|---|---|---|---|
| **모달** | 단일 알림·축하·혜택 1건. 즉시 판단 메시지 | 적음 (헤딩+본문 2~3줄+CTA) | 1개 (+보조) | 항목 나열, 긴 설명, 단계 안내 |
| **하프시트** | 체크리스트·항목 비교·단계 안내·요약 카드 | 중간 (목록 2~5개) | 1~2개 | 1줄 메시지(과한 공간), 전체화면 몰입 |
| **풀스크린** | 온보딩·축하 몰입·스토리·다단계 | 많음 (히어로+섹션) | 1개 (명확한 단일 CTA) | 짧은 알림(과잉), 빠른 닫기 기대 |

> 인터뷰 응답이 콘텐츠 양과 어긋나면 (예: 체크리스트 4개인데 "모달") Step 3에서
> 포맷 재제안. 모달에 목록 4개 = 세로 스크롤 발생 → 하프시트가 정답.

## 1. 모달 — 중앙 집중·단일 결정

**레이아웃 문법**: 중앙 정렬, 수직 대칭, 시선이 가운데로 수렴. 아이콘은 상단 중앙.

> **아이콘형 vs 히어로형**: 아래 다이어그램의 상단 중앙 아이콘(64~72px)은
> 공지·확인·가벼운 알림용. 혜택·프로모·전환 캠페인은 아이콘 대신 **히어로 존**
> (단일 소품 or 초대형 숫자, 카드 높이 30~45%)을 두고
> `visual-layout-patterns.md` §1의 존 문법(기본 = (a) 수직 스택 7단: 아이브로우
> 필→헤드라인→서브→히어로→가격·조건→풀폭 CTA→dismissal. 오버레이형·분할형은
> §1-b/c + §12 선택 규칙)을 따른다. 텍스트·CTA 콘텐츠 폭은 카드 폭 ~80%.

```
┌─────────────────────┐
│              [✕]    │  ← close 우상단
│        ◉            │  ← 아이콘 상단 중앙 (64~72px)
│   헤딩 (중앙)        │
│   본문 2~3줄 (중앙)  │
│ ─────────────────── │  ← divider (선택)
│  [   주 CTA   ]     │  ← full-width
│   보조 텍스트 링크   │  ← text button, 중앙
└─────────────────────┘
```

| 요소 | 원칙 |
|---|---|
| **정렬** | 전 요소 `text-align:center`. 좌측 정렬 본문 금지 (비대칭감) |
| **아이콘** | 상단 중앙 1개. 브랜드 primary-tint 원형 배경 + primary 아이콘. 64~72px |
| **헤딩** | 18~22px Bold. 1~2줄. 헤딩 위 여백 > 아래 여백(1.5:1) |
| **본문** | 14~15px Regular, secondary 색상. **최대 3줄** — 넘으면 하프시트로 |
| **CTA** | 주 CTA full-width 1개. 보조는 text button으로 무게 차등. 가로 2버튼 배치는 동등 선택지일 때만 |
| **닫기** | ✕ 우상단 (`iam-close`). 36~40px 터치 타겟 |

권장 id 구조: `iam-overlay > iam-modal > iam-close / iam-icon / iam-header / iam-body / iam-divider / iam-cta-primary / iam-cta-secondary`

## 2. 하프시트 — 좌측 정렬·목록형

**레이아웃 문법**: 하단에서 끌어올림. 좌측 정렬 스택, 목록·체크리스트 친화.

```
┌─────────────────────┐
│ ● 시점 라벨    [✕]  │  ← time-label 좌측 + close 우측
│ 헤딩 (좌측 정렬)     │
│ 본문 (좌측)          │
│ ▸ 체크 항목 1        │  ← 좌측 정렬 목록
│ ▸ 체크 항목 2        │
│ ▸ 체크 항목 3        │
│  [   주 CTA   ]     │  ← full-width
│   보조 링크          │
└─────────────────────┘
   ⌃ 하단 부착, radius 상단만
```

| 요소 | 원칙 |
|---|---|
| **정렬** | **좌측 정렬** 기본. 목록·단계는 좌측 정렬이 스캔 효율 ↑. 중앙 정렬 금지 |
| **상단 라벨** | 시점/카테고리 라벨(`iam-time-label`)을 좌상단에. 긴급 톤은 dot pulse |
| **목록** | bullet + 항목. 2~5개. 6개 넘으면 풀스크린 |
| **CTA** | full-width 1개. 하단 고정 느낌. safe-area padding 필수 |
| **드래그 핸들** | **금지** (WebView 제스처 미동작 — size-patterns.md). 닫기는 ✕·오버레이 탭만 |

권장 id 구조: `iam-overlay > iam-sheet > iam-close / iam-time-label / iam-header / iam-body / iam-list > iam-item-{n} / iam-cta-primary`

## 3. 풀스크린 — 몰입·스토리텔링

**레이아웃 문법**: 화면 전체 점유. 상→하 스크롤 내러티브. 히어로 영역 + 섹션 + 하단 고정 CTA.

```
┌─────────────────────┐
│              [✕]    │  ← close 우상단 (작게)
│                     │
│      ◉ 히어로        │  ← 큰 비주얼/아이콘 (상단 1/3)
│   메인 헤딩          │
│                     │
│   섹션 1 (메트릭)    │  ← 스크롤 섹션
│   섹션 2             │
│                     │
│  [   주 CTA   ]     │  ← 하단 고정(sticky) 권장
└─────────────────────┘
```

| 요소 | 원칙 |
|---|---|
| **호흡** | 모달·하프시트보다 여백 크게. 화면을 채우려 요소 늘리지 말 것 |
| **히어로** | 상단 1/3에 단일 강조(아이콘/일러스트/큰 숫자). 강조 마이크로 인터랙션 1개 여기 |
| **섹션** | 스크롤 가능. 섹션 간 구분은 여백으로 (divider 남발 금지) |
| **헤딩** | 24~28px Bold — 포맷 중 가장 큼 |
| **CTA** | 단일·명확. 스크롤 길면 하단 sticky로 항상 보이게. 보조 액션 최소화 |

권장 id 구조: `iam-fullscreen > iam-close / iam-hero / iam-header / iam-section-{n} / iam-cta-primary`

## 4. 포맷 무관 공통

- **브랜드 토큰**: primary 1~2회만. raw rgba 인라인 금지 → 브랜드 토큰 사용
- **id 강제**: body 내 전 요소 `id="iam-..."` (editor 역동기화 — craft/braze-custom-html.md §8)
- **인터랙션 4종**: Entry / Press / Stagger / reduced-motion (interaction-standard.md)
- **CTA**: 행동 동사형. ≤ 2개 (BRAZE-DOMAIN §1.2). 브랜드 금지어 준수
- **접근성**: `role="dialog"`, `aria-modal="true"`, `aria-label` 필수

## 5. 안티패턴 (포맷-콘텐츠 미스매치)

| ❌ 패턴 | 문제 | 교정 |
|---|---|---|
| 모달에 체크리스트 4개+ | 세로 스크롤·중앙정렬 목록 충돌 | 하프시트로 전환 |
| 하프시트 1줄 메시지 | 빈 공간 과다, 끌어올림 무의미 | 모달로 전환 |
| 풀스크린 단일 알림 | 이탈 부담 대비 정보 빈약 | 모달로 전환 |
| 모달 본문 좌측 정렬 | 중앙 대칭 깨짐 | 중앙 정렬 |
| 하프시트 중앙 정렬 목록 | 스캔 효율 ↓ | 좌측 정렬 |
| 풀스크린에 요소 가득 | 몰입 대신 피로 | 여백 늘리고 섹션 분할 |
| 하프시트에 드래그 핸들 | WebView 제스처 미동작 → 기대 위반 | 핸들 제거, ✕ 버튼만 |
| 슬라이드업을 HTML로 제작 | 앱 전체 차단 WebView — 비차단 기대 위반 (BRAZE-DOMAIN §1.1) | Native 슬라이드업 사용 |

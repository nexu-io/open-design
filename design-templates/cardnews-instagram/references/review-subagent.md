# 검수 서브에이전트 — dispatch 지시

메인 에이전트: 서브에이전트 dispatch 도구가 있으면 **반드시** 신선한 컨텍스트의
검수자에게 위임한다(작성자 자기검수 편향 차단). 없으면 인라인 자가검수로 동일
채점표를 수행한다. dispatch 프롬프트에 다음 입력을 채워 넣는다:

- `{cards_json_path}` — cards.json 절대 경로
- `{png_paths}` — 카드 PNG 절대 경로 목록 (전장)
- `{gallery_path}` — <slug>-preview.html 절대 경로
- `{brief_path}` — brief.md 절대 경로
- `{research_path}` — research.md 절대 경로 (없으면 "없음")
- `{design_md_path}` — 활성 DESIGN.md 절대 경로
- `{character_sheet_path}` — DESIGN.md 등재 캐릭터 시트(캐논) 절대 경로 (없으면 "없음")
- `{craft_path}` — craft/instagram-cardnews.md 절대 경로 (스킬 스테이징 또는 레포 경로)

## 서브에이전트 임무 (dispatch 프롬프트 본문)

너는 인스타 카드뉴스 검수 전담 에이전트다. **report-only — 파일을 수정하지 마라.**
최종 텍스트 반환만이 메인에게 전달된다.

1. Read: `{craft_path}`, `{design_md_path}`, `{brief_path}`, `{research_path}`,
   `{cards_json_path}`, `{gallery_path}`, 그리고 **카드 PNG 전장을 직접 Read(비전
   검토)**. 전부 직접 읽고 판단한다 — 메인의 요약을 신뢰하지 않는다.
2. 채점 5축 (각 축 감점 사유를 개별 발견으로 기록):
   - **craft 채널 룰** — 12룰 각 pass/fail: 규격 1080×1350 정확·장수 5~8·역할 레이아웃
     계약(body 박스·밴드·균일 다크닝 금지 / cta 전면 균일 딤 ~45% 필수·그라디언트 금지)·**badge 부재(v2: 전면 제거 — 잔존 시 fail)**·
     기본형 배경 실사 여부(플랫 일러스트 = fail)·본문 블록(렌더 5줄 미만 = fail,
     양쪽맞춤 줄이 컬럼 풀폭 912px 미달 = fail)·좌우 마진(커버 훅·본문 타이틀
     잉크가 우측 한계 x=996 초과 = fail)·본문 서술형(요약형 조각문 나열 = fail,
     체크리스트 스텝 카드는 예외)·갤러리 카드별 다운로드 앵커·캡션
     분리·배경 내 글자 유무 등.
   - **디자인** (PNG 비전 검토 — 신설 축):
     · 타이포 위계 — 훅/본문 크기비, 카드 내 위계 ≤3단 (렌더 결과 눈 검증)
     · 텍스트/배경 대비 — 실제 렌더 가독 판단 + cards.json 색 운용의 DESIGN.md 토큰 대조
     · 카드 간 일관성 — 배경 스타일·팔레트·레이아웃 그리드 통일 (스타일 앵커 실효 검증)
     · 구도 플랜 대조 — 본문 카드 PNG를 cards.json `bg` 선언(shot·angle·
       placement·view)과 대조(비전 검토). 불일치 = P1, 수정 지시는 "해당 카드만
       개별 재생성(선언 유지, 성공분 보존)"으로 특정한다. 세트 단조 — 인접 본문
       카드가 사실상 동일 구도이거나, 본문 3장 이상에서 shot·angle·placement 중
       2축 이상이 실물 기준 값 1종이면 = P0.
     · 내용-이미지 정합 — 카드 텍스트 메시지의 정서·핵심 개념 vs 렌더된 무드·
       표정·소품 기호를 비전 대조한다(card-structure.md "정서 우선 룰"·"소품·히어로
       매칭 2룰"이 기준). 선언대로 렌더됐어도 선언 자체가 메시지와 안 맞으면
       잡는다 — 구도 플랜 대조는 선언 이행만 보므로 이 축이 없으면 잘못된 선언이
       충실히 렌더된 미스매치가 검수를 통과한다(2026-07-14 실측: 폭염 위험 경고
       카드가 시원한 그늘 산책 무드 + happy 표정으로 렌더). 위험·경고·주의 카드가
       쾌적·행복 무드로 렌더되거나 소품 기호가 딴 주제를 가리키면 = P1, 수정
       지시는 "cards.json `bg` 선언(expression·locale·Subject 기호) 수정 후 해당
       카드만 개별 재생성(성공분 보존)"으로 특정한다.
     · 배경 내 글자·아티팩트 검출 — AI 생성 이미지에 우연히 들어간 문자·워터마크·기형 요소
     · 표지 훅 가독 — 글자수·줄수 한계, 배경과의 간섭
   - **도달** — 표지 훅 규범(DESIGN.md 훅 공식 계열 일치)·해시태그 후보 품질·CTA 카드
     규범·"저장" 유도 존재.
   - **브랜드·톤** — DESIGN.md 금지어·금지 표현·면책 누락 + Voice 규칙 대조. DESIGN.md가
     [필수]/[관례] 마킹을 쓰면 **[필수] 위반 = P0급 감점, [관례] 미준수 = P1 권고**로
     가중을 달리한다.
     **캐릭터 일관성 — 상위 기준 = 캐논 시트 대조**: `{character_sheet_path}`가
     "없음"이 아니면 시트를 직접 Read(비전)하고 **카드 전장의 캐릭터를 시트와 대조**
     한다. 대조 5항목 — ① 골격(머리-몸 일체형/목·목선 유무, 팔다리 비례) ② 부속물
     (시트에 없는 링·칼라·장식 — 카드 내용이 명시한 소품·의상은 예외) ③ 질감
     (매트/광택/직물 등 표면 재질) ④ 입 형태(혀 노출 여부 등 이목구비 디테일)
     ⑤ 색상(바디 블루 톤 — DESIGN.md가 바디 hex를 명시하면 그 값이 정본,
     아니면 시트 COLOR PALETTE 대비 명도·채도 이탈로 판정. 카드 간 상호 대조
     병행: 한 카드만 연하거나 시안 쏠림이면 그 카드가 불일치. 브랜드 액센트
     토큰(시안 계열)과 바디 색 혼동 금지).
     판정 가중: **골격·부속물 불일치 = P0**(사실상 딴 캐릭터 — 발행 차단),
     **질감·입 디테일·색상 불일치 = P1**. 수정 지시는 모두 "불일치 카드만 개별 재생성
     (성공분 보존)"으로 특정한다. 시트가 "없음"이면 폴백 = 카드 간 캐릭터 형태
     (비율·이목구비·색) 상호 동일성 대조, 불일치 = P0(발행 차단), 동일 수정 지시.
     카드 간 상호 불일치 P0 룰은 시트가 있어도 유지된다(시트 대조가 상위 기준). 캐릭터 스케일·크롭 — 선언 shot 기준으로 대조한다: `"mid"` 선언
     (또는 `bg` 없는 카드)은 프레임 높이 ~50% 미만 원경·구석 쏠림 = P0,
     `"close-up"` 선언은 70~90% 기준 미달 시 구도 플랜 대조(P1)로 판정하되,
     세트 단조 조건을 동시 충족하면 세트 단조 P0을 우선 적용한다.
     4:5 크롭에 머리·몸이 잘린 카드는 선언 무관 P0, 같은 방식(해당 카드만 개별
     재생성)으로 특정한다.**
     **포즈·표정 단조**: cards.json이 `pose`/`expression`을 선언한 세트에서 동일 `pose`
     또는 동일 `expression`이 3장 이상 반복되거나, 선언과 렌더가 어긋나 전 카드가 같은
     기본형(정면·미소)으로 보이면 세트 단조로 감점(다양성 축과 합산). 캐논 대조·카드 간
     상호 불일치 P0 룰은 불변 — 커버가 본문과 체형이 다르면 그 P0 룰로 포착된다.
     시트가 등재된(`{character_sheet_path}` "없음" 아님) 브랜드인데 본문 카드가 `pose`/
     `expression`을 하나도 선언하지 않았거나 전 본문 카드가 기본형(정면·idle·미소)으로만
     렌더되면 **포즈·표정 단조 = P1(권고 상향)** — 시트에 액션·표정 어휘가 있는데 안 쓰인
     신호다. cards.json에 pose/expression을 콘텐츠 매칭으로 채운 뒤 재생성하도록 지시한다.
   - **팩트체크** — cards.json 텍스트·캡션의 모든 수치·기관명·제도명을 research.md
     출처와 대조. 1차 매핑 실패 시 정성 판단으로 완화하되 발견으로 기록.
3. 반환 형식 (이 구조 그대로):

   ## 검수 결과
   - 총점: NN/100
   - 게이트: 발행 가능(≥80) / 수정 필요(60~79) / 재기획(<60)
   ### P0 (발행 차단)
   - [카드/파일·위치] 문제 — 근거
   ### P1 (권고)
   - [카드/파일·위치] 문제 — 근거
   ### 축별 점수
   - craft: NN, 디자인: NN, 도달: NN, 브랜드·톤: NN, 팩트: NN

메인 에이전트: P0·감점 항목을 수정한 뒤 **재검수 1회**(신규 dispatch, 같은 지시).
**텍스트만 수정이면 배경 재생성 없이 compose_cards.py 재실행**으로 반영한다(결정성
계약 — 검수 루프 저비용). 재검수 후에도 <80이면 점수·발견목록을 사용자에게 보고하고
판단을 위임한다.

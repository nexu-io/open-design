# xDesign fork overlay

This directory is the **fork-private overlay** for `zgar-limited/open-design` (the
xDesign enterprise fork of upstream `nexu-io/open-design`). It carries xDesign's
brand identity and the build-time injection that applies it, keeping all
customization out of upstream source so `git merge upstream` stays nearly clean.

Nothing here is product runtime code. The overlay works through three layers
documented in `docs/xdesign/` (fork strategy + identity coverage):

1. **Upstream seam** — `tools/pack/src/brand.ts` + the `brand` field on
   `ToolPackConfig`. A generic, additive, env-gated hook: when `OD_PRODUCT_NAME`
   is set, mac/win/linux install identity and the electron-builder icon resolve
   to the fork brand; when it is unset, upstream Open Design behavior is
   byte-for-byte unchanged.
2. **Brand data + resources** — `xdesign/brand/brand.json` (productName, appId)
   and `xdesign/brand/icon.{icns,ico,png}` (mac/win/linux icons). No brand
   identity is checked into upstream source; it reaches the build only through
   env vars.
3. **Build wrapper** — `xdesign/scripts/pack.ts` reads the brand config, sets the
   `OD_PRODUCT_NAME` / `OD_APP_ID` / `OD_MAC_ICON` / `OD_WIN_ICON` /
   `OD_LINUX_ICON` env vars (each platform icon only when its file exists), and
   forwards every argument to `pnpm tools-pack`.

## Build a branded mac package

From the repo root:

```bash
node --experimental-strip-types xdesign/scripts/pack.ts mac build --to dmg
```

Everything after the script path is forwarded to `tools-pack`, so the usual
flags apply (`--namespace`, `--app-version`, `--dir`, `--signed`, …). The
produced `.app`/`.dmg` install as **xDesign** with the xDesign icon.

### Brand env must be set for every lifecycle command

The brand is not baked at build time — `tools-pack` re-derives the product name,
app id, icon, and artifact **paths** from `OD_PRODUCT_NAME` / `OD_APP_ID` /
`OD_MAC_ICON` / `OD_WIN_ICON` / `OD_LINUX_ICON` on every invocation. So
`install`, `start`, `stop`, `uninstall`, and `cleanup` on a branded build must
run through the wrapper too (or set the same env), otherwise they look for the
wrong artifact name (e.g. it hunts for `Open Design-<ns>.dmg` instead of
`xDesign-<ns>.dmg` and fails).

```bash
node --experimental-strip-types xdesign/scripts/pack.ts mac install  --namespace xdesign-verify
node --experimental-strip-types xdesign/scripts/pack.ts mac start   --namespace xdesign-verify
node --experimental-strip-types xdesign/scripts/pack.ts mac stop    --namespace xdesign-verify
node --experimental-strip-types xdesign/scripts/pack.ts mac uninstall --namespace xdesign-verify
```

The same wrapper drives win/linux (the per-platform icon env is set only when
the corresponding `xdesign/brand/icon.{ico,png}` exists):

```bash
node --experimental-strip-types xdesign/scripts/pack.ts win   build --to nsis
node --experimental-strip-types xdesign/scripts/pack.ts linux build --to appimage
```

To build unbranded (upstream Open Design), call `pnpm tools-pack` directly — the
wrapper is only required for branded (fork) builds and their lifecycle.

## Replacing the placeholder icons

`xdesign/brand/icon.{icns,ico,png}` are stand-ins (flat indigo tile with a white
**X**), generated by `xdesign/scripts/generate-placeholder-icon.ts`, so the
injection mechanism is visually verifiable on all three platforms before the
real logo exists. When the real xDesign logo is ready, drop replacements at the
same paths and delete the generator — nothing else changes. (The macOS `.icns`
step needs `iconutil`; the `.ico` and `.png` are pure Node and generate
anywhere.)

```bash
node --experimental-strip-types xdesign/scripts/generate-placeholder-icon.ts
```

## Local verification gotchas

Two caches bite when you re-verify a brand change locally — if the running app
still shows the old name after a rebuild, clear these and rebuild:

1. **Next.js standalone cache.** `next build` writes the brand into
   `apps/web/.next` (full output) but `.next/standalone` (the part packaged into
   the `.app`) can retain a stale locale on an incremental rebuild. If a freshly
   built app still shows the old brand, remove `apps/web/.next` **and** the
   tools-pack workspace-build cache entry, then rebuild:
   ```bash
   rm -rf apps/web/.next
   rm -rf .tmp/tools-pack/cache/entries/mac.workspace-build
   node --experimental-strip-types xdesign/scripts/pack.ts mac build --to dmg --namespace xdesign-verify
   ```
2. **Electron renderer cache.** The first launch (on a stale bundle) caches the
   old entry page under `~/Library/Application Support/<ProductName>` and the
   namespace `user-data`. Clear both before restarting, or the renderer serves
   the cached page:
   ```bash
   rm -rf "$HOME/Library/Application Support/xDesign"
   rm -rf .tmp/tools-pack/runtime/mac/namespaces/xdesign-verify/user-data
   ```

Then `mac install` + `mac start` (through the wrapper) and the nav-rail brand
should read the fork name.

3. **`mac install` can serve a stale app.** After a rebuild, `mac install`
   copies the `.app` out of the namespace DMG, but a prior install (or a stale
   mounted DMG) can leave the install dir holding an older build — `mac start`
   then runs the old app and the brand looks unchanged even though `mac build`
   produced a fresh one. If a rebuilt app still shows the old brand, force a
   clean install, or copy the freshly built app directly:
   ```bash
   node --experimental-strip-types xdesign/scripts/pack.ts mac uninstall --namespace xdesign-verify
   node --experimental-strip-types xdesign/scripts/pack.ts mac install   --namespace xdesign-verify
   # or, bypassing the DMG install entirely:
   rm -rf .tmp/tools-pack/out/mac/namespaces/xdesign-verify/install/Applications/xDesign.app
   cp -R  .tmp/tools-pack/out/mac/namespaces/xdesign-verify/builder/mac-arm64/xDesign.app \
          .tmp/tools-pack/out/mac/namespaces/xdesign-verify/install/Applications/xDesign.app
   ```
   The definitive check is the locale inside the *installed* app, not the
   builder output:
   ```bash
   rg -o '"app\.brand":"[^"]*"' \
     .tmp/tools-pack/out/mac/namespaces/xdesign-verify/install/Applications/xDesign.app/Contents/Resources/open-design-web-standalone/apps/web/.next/static
   ```

## Layout

```
xdesign/
  brand/
    brand.json                      productName + appId
    icon.icns                       mac app icon (placeholder)
    icon.ico                        win app icon (placeholder)
    icon.png                        linux app icon (placeholder)
  scripts/
    pack.ts                         brand-injecting tools-pack wrapper
    generate-placeholder-icon.ts    regenerates all three stand-in icons
```

Fork-strategy docs live under `docs/xdesign/` (`CONTEXT.md`, `adr/`,
`identity-coverage.md`, `upstream-opt-out.md`).

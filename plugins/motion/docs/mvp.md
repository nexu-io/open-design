# 历史版本范围与验收

本文保留 0.1–0.3 的历史记录。下列状态、环境与验收结果只反映当时版本；Canvas、镜头 JSON 与前台录制描述不再适用于当前实现。当前能力以 [产品架构](product/architecture.md) 和 [README](../README.md) 为准，迁移说明见 [Hyperframes 集成](hyperframes.md)。

状态：READY。依据：用户要求“复刻参考”“支持二次编辑”“先实现一个版本，最小功能集合”。当前目录没有 Git 或远端，因此本次仅本地开发与验证。

| ID | 确认目标及本版实现 | 验收 |
| --- | --- | --- |
| M1 | 参考视频导入，粗略检测明显切镜，按镜头时长生成分镜 | 导入本地视频，识别边界，生成可预览的连续分镜 |
| M2 | 二次编辑：替换图片/视频、编辑字幕、时长、素材起点、字幕位置及颜色，调整顺序 | 改动立即反映在画布，撤销能恢复 |
| M3 | 预览 | 播放、暂停、拖动时间，参考视频与作品分开查看 |
| M4 | 可继续编辑 | IndexedDB 保存草稿和本地素材；导出/导入自包含工程 JSON |
| M5 | 输出视频 | 同一画布录制 WebM，再通过本地原生 FFmpeg 转为 540×960 / 24fps MP4 |
| M6 | Codex 插件开发入口 | skill 指引启动本地预览及读写同一工程 JSON；提供 TS 校验与打包 |

技术约束：Node 22.18+ 原生擦除 TS；预览和录制共用画布，当前没有 Remotion 依赖。第一版为静音作品，最大 60 秒、最多 24 个镜头、工程与上传文件均限制大小。默认示例为明确标记的演示图形。

范围外：视频平台链接抓取、语义/逐像素自动复刻、OCR/语音识别、AI 生成镜头、配乐、多轨编辑、后台高速渲染。自动切镜是低分辨率画面差异启发式，不能保证识别渐变、摇镜或所有切换；可手动在参考播放器处添加切点。

## 0.3.1：修复实际客户端加载 MCP 失败

用户安装 0.3.0 后仍提示没有 motion_open_preview。本机安装清单确认 installed / enabled，但 `codex mcp get motion --json` 显示 cwd 被解析为 `.../0.3.0/${PLUGIN_ROOT}`，args 中的 `${PLUGIN_ROOT}/mcp.ts` 也未替换。2026-11-03 桌面日志明确记录 Motion startup failed: No such file or directory。根因是启动配置不兼容当前客户端，而非单纯会话未刷新。

修复：`.mcp.json` 改为 cwd `.`、相对入口 `mcp.ts`；安装后预检读取 Codex 真实解析的配置，并执行该命令进行 initialize 和 tools/list 验证。没有静默覆盖用户配置，也没有重启其他会话。
新增 tests/mcp-config.test.ts 覆盖原始占位符失败与修复后的相对路径启动；31 项测试全部通过。针对当前已安装 0.3.0 运行新预检能准确拒绝未展开的配置。源码修复及 0.3.1 安装包已准备，尚未替换用户缓存；实际安装后的预检结果需以用户执行更新后的输出为准。

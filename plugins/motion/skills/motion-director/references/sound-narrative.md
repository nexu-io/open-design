# 声音叙事：先定职责，再选声音

用于声音需要参与表达、现有配乐与画面脱节或专项声音修改。简单裁切、音量修正不必重新设计全片。

## 从观众体验建立判断

先说清本片希望声音帮助观众理解、期待或感到什么，以及声音从现有画面中能支持什么。再判断已有音轨能否承担这些职责。BPM、音色标签和“高级、电影感”不足以形成声音方案。

音乐可组织情绪、段落关系与持续感；音效可强调行为、材质、空间或特定结果；环境声、人声和静默也可以承担主导职责。这些是可选能力，不是必须叠加的声部。不要为了区别音乐与音效而强行拆分本来完整的声音表达。

按当前任务选择要解决的差异：持续与中断、紧张与释放、近与远、稀疏与密集、稳定与变化等。差异是否有价值取决于画面和意图；不要求每段改变音乐，也不预设“稀疏开场—层层增加—高潮—收束”。持续的单一质感、无明显高潮、突然中断或完全无声均可成立。

## 建立本片的声音关系

可用几句话、时间表或事件表，记录相关决定即可：

| 决策 | 需要回答的问题 |
| --- | --- |
| 叙事职责 | 这段声音改变了观众的理解、期待、情绪或注意力吗？还是只是填满空白？ |
| 声音材料 | 现有或可制作的哪些声音适合？来源、授权、时长与尾音是否可用？ |
| 段落关系 | 怎样延续、对比、转折或保持？音乐是否需要发展，发展的是哪种关系？ |
| 动作反馈 | 哪些变化值得强调，强调哪个感知时刻？哪些动作应保持安静？ |
| 主次与空间 | 同时发生时谁应被听见？怎样给阅读、语音、细节或结果留空间？ |
| 验证 | 听看哪个区间，观察什么；什么情况说明声音反而抢戏或误导？ |

可以使用主题动机及其变化来联系段落，也可以不使用旋律或重复动机。不要规定音符数量、乐器、调式、速度、音效类别、段落数或能量曲线。

确定声音关系后，再用 [动作脚本](action-script.md) 的声画锚点绑定实际时间。声画可以同步、提前、滞后或独立推进；有意错位需要服务本片，而不是为了避免同质化。不要把所有动作量化到节拍，也不要让配乐和音效在同一个点重复强调到互相遮蔽。

## 制作与受限修改

- 用实际可用工具选曲、作曲、编曲、录制、合成或剪辑，不把“有生成工具”当成声音已经设计好。生成模型不能保证精确时序时，先获得音频，再剪辑和编排。
- 给重要结果声音反馈时，避免暗示画面未证明的操作成功、处理速度或真实产品提示音。概念演示中的设计音效不应被说成产品原生声音。
- 声音调整需保持画面不变时，锁定画面版本、时长与时间戳；通过声音剪辑、编排、音色、层次与混音实现。不要偷偷移动镜头或动作来方便卡点。可无损复制视频流并核对视频包／解码帧与时间信息。
- 需要继续编辑时，保留实际使用的音乐、音效等必要分轨及时间关系；不要求为了交付人为拆出无用声部。标记音频增益、偏移和尾音处理，避免工程预览与导出不同。
- 先解决声音职责与编排，再处理均衡、动态、空间与整体响度。技术处理不能挽救与叙事无关的材料；更多声部和更响的声音也不自动更好。

## 审听与比较

有声与静音观看可以帮助识别声音增加了什么；也可临时只听音乐或音效来定位问题。选对当前疑问有用的方式，不机械要求每次完成所有模式。

对比前后版本时，以大致匹配的感知响度为基础，保持同一画面与播放位置，避免更响的一版天然占优。保留原始版；若制作响度匹配副本，明确标记调整，不覆盖原证据。不要同时播放两版声音来判断优劣。

先听段落发展、语义反馈和注意力，再听锚点、音色、混音与首尾。检查声音是否掩盖阅读或语音、让细小动作显得过重、制造不真实空间、不断提示却无重点，或尾音被硬截。削波、声道、响度和波形检查属于技术证据，不是听感评价。

明确记录完成了什么：实际听看、技术测量、代码／时间关系检查，或未验证。没有可靠音频感知能力时，交付可试听对比并标出限制；不能凭 RMS 峰值、声部数量或设计意图宣称“更有情绪”“更自然”或“听感提升”。

## 正反例：理由可复用，音色和结构不可照搬

**修改作品的产品片。** 单一鼓点从头播放到尾，每个图形变化都加同一个短音，即使碰到拍点，也可能把不同信息压成同一种提示。可选择让持续音乐联系作品身份、为某个修改结果突出反馈，并在观察结果时减少竞争；也可只用音乐中的变化完成这些职责，不一定另加音效。检查观众能否听出值得注意的变化，不能以“音效更多”验收。

**安静的材质品牌片。** 为了丰富而加鼓、上升音和品牌三音收尾，可能破坏安静与精密。真实环境声、一种持续质感、少量接触声或无声都可能更合适；素材不能支持时不伪造真实材质录音。这里不需要递进曲式或音乐高潮。

**高密度文字片。** 所有词都配点击声会抹平语义重点。可让音乐短句支持关键语义，让日期稳定出现时保留听觉空间；另一种可行方式是有意持续的节律与视觉切分形成张力。是否停音乐、是否用打击乐，都由本片效果决定。

# 共享修改流程

已有工程需要改变内容时使用本页：局部文字/样式、声音、模板替换内容，以及用户明确要求的大幅重编。沿用当前专业路线与质量标准；本页不增加一个选路入口。仅查看预览、复用下载链接、核验文件或导出已确认内容时，无需为此启动修改流程。

## 确定本轮变化与保持项

从当前请求、已确认决定和实际工程中确定：修改对象与时间范围、预期结果、必须保持的内容、必要的连带影响。复用已有 STATE 或会话记录，简单改字用一句话即可，不要求逐次填写表格或重新做创作简报。记录放在活动工程之外。

- “只改结尾文案”：定位结尾的实际实例；同一句话若在前段承担其他叙事职责，不能全局替换。若结尾由共享组件产生，按当前实现调整作用范围。
- “换音乐，保留音效位置”：更换音乐来源并核对声画关系，保留约定的音效起点、素材裁切和动作锚点；画面锁定时不借机调整视觉。
- “借鉴参考的色彩，保留动作”：只迁移被要求的样式，不因视频链接而改为复刻。用户随后明确改变结构时，更新受影响的保持项，保留仍有效的工程、品牌与无声等决定。

例子用于说明范围判断，不限定对象形式、镜头结构或实现手法。文字变长可能需要排版调整，时长变化可能影响相邻转场和声音；在已授权范围内处理必要依赖并说明实际影响，不能为形式上的“少改几行”留下坏结果。只有影响目标的重要歧义或需要扩大授权范围时才追问。

## 基于当前工程修改

先按 [共享上下文](context.md) 补齐本轮所需正文并完成读后决策边界，再检查目标工程、最新 revision 与受影响源文件。STATE 用于恢复决定，不能代替当前源文件。首次修改某对象时，留存足够的修改前证据：可用源文件片段、相关文件副本/哈希、时间线事件或对应画面；按风险选择，不要求每轮复制全工程。

定位实际被引用的组件、素材、时间线和重复再现，注意共享样式、变量与父级变换的影响。对照预期范围形成必要的改动集合，再通过 [运行规范](production.md) 执行。保留其他已确认内容、源 ID、裁切和 Studio 编辑；不因换 Skill 重新套模板或另起工程。遇到 revision 冲突，读取真实差异后在新版本上重新形成修改，不把旧文件整体覆盖回去。

## 验证目标变化，也验证保持项

对照修改前后实际源文件与产物，回答两个问题：目标是否改变；约定保持的内容是否仍成立。发现范围外差异先查来源，修复本轮误改，不连带重做不相关内容。

根据变化选择证据，避免把每次修改扩成整片制作：

| 改动影响 | 优先检查 |
| --- | --- |
| 文字、颜色、布局 | 对应时刻画面、可读性、共享样式的其他使用处，以及相邻镜头的起止状态 |
| 动作、时长、镜头结构 | 修改区间的动态表现、进入与离开接点、后续时间偏移、声音锚点和总时长 |
| 仅声音 | 画面源/时间线保持；实际音轨的素材、裁切、事件位置与试听；换音乐后检查原音效延续 |
| 同一对象在后续镜头再现 | 修改后的内容与时间状态是否贯穿后续展示、预览和交付；缩略图相同不能证明动作已延续 |

对完全锁定的源文件，可用字节或哈希核对；引擎缓存、历史记录及自动补写 ID 与内容变化分开说明，不能把全部差异一概排除。调整过的文件也要核对未授权变化；只检查“改动文件名单”不足以证明局部性。技术 lint 不替代画面、动态或声音检查；检查能力不足时标明具体缺口。

沿用 [审片标准](../../motion-director/references/motion-review.md)，按影响应用 [制作决策](../../motion-director/references/production-decisions.md) 与 [声音叙事](../../motion-director/references/sound-narrative.md)。已读正文直接使用，不为每一轮重读，也不为修改任务加载无关创作规范。

## 让下一轮接着当前结果

更新同一份简短记录：实际改了什么、仍有效的保持项、当前工程与 revision、已完成检查及未验证部分。下一轮只恢复当前需要的信息，不照抄过期源文件或失效的旧决定。

用户要求交付时，按 [验证](verification.md) 对当前确认的版本导出。若已有导出，先核对其 job/revision 是否对应当前结果；修改后的请求不能误交旧成片，仅索取既有成片链接也不能触发新导出。核验实际文件，抽查修改位置及必要的后续再现，确保最新修改进入交付。

# Hyperframes official examples

Source: https://github.com/heygen-com/hyperframes/tree/3baf81f9a92615507f76fe8de33e489034ee77ec/registry/examples

Upstream project: HeyGen Hyperframes. Distributed under the upstream Apache-2.0 license in `LICENSE`.

Included examples: Product Promo, NYT Graph, Decision Tree. Source files and
registry metadata are copied from the above commit. When creating an editable
project, Motion replaces the GSAP CDN script with the locally installed pinned
GSAP package and includes a native Hyperframes project configuration. Google
Fonts references and the original example artwork remain as provided upstream.

The gallery posters are captured from these examples using Hyperframes snapshot.

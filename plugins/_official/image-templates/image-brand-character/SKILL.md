# Brand Character Sheet

Produce one reference sheet that downstream designers can actually use to preserve character identity.

## Inputs

- character role, personality, audience, and brand context
- immutable silhouette, proportions, limb count, face construction, and signature feature
- outfit, materials, palette, and recurring accessories
- required poses, expressions, and usage context
- forbidden additions, style drift, or resemblance risks

When a reference is supplied, treat it as the identity anchor. Otherwise write the invariants before generation.

## Art direction

1. Define the character in one construction sentence.
2. Lock every invariant, including accessory count and left/right asymmetry.
3. Use one large hero pose plus a compact pose grid and expression row.
4. Repeat the same face, silhouette, outfit, palette, and material in every panel.
5. Use a bright presentation board with distinct color cards and ample separation.
6. Prefer authored illustration texture—ink wobble, marker overlap, screen-print grain, cut sticker edge—over generic polished 3D.

Use the host image-generation capability and save one high-resolution sheet bitmap.

## Reject generic AI styling

No identity drift, limb-count changes, surprise clothing, duplicated accessories, random symbols, kawaii default styling, glossy toy render, gray presentation board, copyrighted-character resemblance, filler paragraph text, or labels that compete with the character.

## Quality gate

- Silhouette, face, proportions, outfit, palette, and signature details match in every panel.
- Poses change action without redesigning the character.
- Expressions vary through controlled facial changes.
- The bright board remains organized and usable as a design reference.
- The result feels like a real character system, not a collection of lookalikes.

## Demo brief

Create **BYTE**, a black cat-rabbit streetwear mascot with an off-white face patch, asymmetric ears, acid-lime eyes, cobalt puffer vest, charcoal cargos, white sneakers, and exactly one silver carabiner. Show one hero, six poses, four expressions, and palette chips.

# 네이버 블로그 — 5섹션 구조 패턴

> 채널 HTML/SEO 규칙은 `craft/naver-blog-html.md`가 정본. 여기는 *구조*만.

1. **도입 (후킹)** — 독자 상황 공감 1~2문단. 검색 의도 즉시 확인. (훅 다양화: 사례형/오해해소형/수치충격형/통념깨기)
2. **핵심 정보 본문** — 2~3개 섹션. 각 섹션 = 벌티컬라인 헤딩 + 본문. 비교 데이터는 표.
3. **주의/함정** — 거절·손해 케이스. 빨강 강조 여기 집중.
4. **해결/액션** — 독자가 지금 할 수 있는 것. 브랜드 CTA(부드럽게).
5. **마무리 + 면책** — 요약 1문단 + 금소법 면책(small-print).

섹션 사이 `<hr>`. 분량은 브랜드 DESIGN.md 가이드(보닥=2,300~2,800자).

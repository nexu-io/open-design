# 카드 해부 + cards.json / publish-history 스키마

> 채널 기술 규칙(규격·레이아웃 계약·13룰)은 `craft/instagram-cardnews.md`가 정본.
> 여기는 *구조 골격과 데이터 스키마*만. 브랜드 사실(훅 공식·핸들·면책)은 활성 DESIGN.md.

## 카드 골격 (기본 5~8장, 최대 10)

1. **표지 (cover)** — 훅 1개(브랜드 DESIGN.md 훅 공식: 오해/손해회피/시의성 계열) +
   서브타이틀("저장" 유도 태그 허용).
2~N-1. **본문 (body)** — 1카드 1메시지: 타이틀(≤2줄) + 요지·부연 ≤4줄.
   권장 흐름: 핵심 답 → 근거/사례 → 함정·주의 → 해결/체크리스트.
N. **CTA (cta)** — 계정 핸들 + 팔로우/저장 유도 서브 문구(+브랜드 면책 축약, 브랜드 요구 시).

## cards.json 스키마 (compose_cards.py 입력 계약)

```json
{
  "slug": "환절기-비염-보험금",
  "cards": [
    { "index": 1, "role": "cover", "sub": "놓치기 쉬운 실비 청구", "hook_lines": ["환절기 비염,", "보험금 될까?"] },
    { "index": 2, "role": "body", "title_lines": ["결론부터,", "됩니다"], "body_lines": ["J30 진단이면 실비 청구 대상이에요.", "통원비·약제비 모두 해당돼요."] },
    { "index": 3, "role": "cta", "handle": "@brand_handle", "sub": "저장해두고 청구 전에 확인하세요" }
  ],
  "caption": "…8블록 캡션 전문…",
  "hashtags": ["#실비보험", "#보험금청구"]
}
```

- `index`는 1부터 연속 — `<slug>-NN.png` 파일명과 배경 `bg-NN.png` 매핑 기준.
- **줄바꿈은 에이전트가 확정**해 `*_lines` 배열로 전달 — compose는 자동 줄바꿈하지
  않는다(결정성 계약: 같은 입력 → 같은 출력).
- 필수 필드: cover = `sub`+`hook_lines`(1~2줄) / body = `title_lines`(≤2)+`body_lines`(≤4)
  / cta = `handle`+`sub`.
- CTA 카드 배경 = `bg-01.png` 재사용(재생성 없음 — 생성 호출 N-1회).
- 슬러그 정규식 `[^a-z0-9가-힣]+` (가-힣 보존).

## 캡션 8블록 템플릿 (정본 — craft 룰 12가 참조)

`[...]`는 콘텐츠로 치환. 블록 헤더 이모지는 소재에 맞게 교체 가능(기능형만).

```
"[표지 훅 재진술 — 따옴표 질문]"
[타겟 공감 1~2줄] [상황 이모지]

📊 [소제목 1] ([출처 기관])
· [불릿]
· [불릿]

📚 [소제목 2]
· [불릿]

⚠️ [주의/면책 — 과장 완화 + 병원 진료 우선 안내. 브랜드 면책 문구는 DESIGN.md 정본]

✅ 이것만 기억하세요
1️⃣ [실천 항목]
2️⃣ [실천 항목]
3️⃣ [실천 항목]

💡 [클로징 인사이트 1~2줄]

💬 나중에 다시 보려면 저장, 필요한 사람에게 태그!

—
다음 콘텐츠는 [예고]. [@계정핸들] 팔로우하고 받아보세요 ✨

📌 출처: [기관/문서] · [기관/문서]
```

해시태그는 캡션 본문 뒤 **별도 블록**(빈 줄 하나 뒤) `#태그 #태그 …` 한 줄 — 본문에 섞지 않는다.

## publish-history.md 스키마 (dedup 소스)

`{cwd}/publish-history.md` — 로컬 발행 이력이 유일한 dedup 소스(라이브 조회 없음).
스킬은 **Read만** 하고 자동 append 하지 않는다(발행은 스킬 밖 사건 — 핸드오프에서
수동 추가를 안내).

```markdown
# publish-history — 인스타 카드뉴스 발행 이력

| 날짜 | 주제 | 핵심소재 |
|---|---|---|
| 2026-06-20 | 도수치료 실비 청구 기준 | 도수치료 |
```

- **핵심소재** 컬럼이 dedup 판정 기준(제목 글자 일치가 아님) — topic 서브에이전트의
  60/90 규칙이 이 컬럼으로 판정한다.
- 파일이 없으면 이력 "미확인"으로 정직 표기하고 진행한다.

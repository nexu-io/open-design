step 01 · ship

Ship from the prompt, not a pipeline page.

One command takes the current commit, builds it in a clean sandbox, and streams every stage back to your terminal. The deploy is the unit of work — not a run ID buried three tabs deep in a CI console.

# ship the current branch
$ shipcast up --env production

step 02 · watch

Watch health, not log soup.

After activation, Shipcast tails error rate, latency, and saturation against the release before it. If the new release drifts past your thresholds, the watch command says exactly which check tripped and when.

# compare against the last release
$ shipcast watch --baseline previous

step 03 · undo

Roll back with one word.

Every release keeps its full artifact and config snapshot. Rolling back re-activates the previous snapshot in seconds — no rebuild, no re-test, no waiting on a queue while production burns.

# back to the last healthy release
$ shipcast rollback "stable"

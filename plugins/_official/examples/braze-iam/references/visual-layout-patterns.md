> 정본 근거 = **한국 프로덕션 IAM 실캡처 139핀 전수 분석 (2026-07-14, 146장 중
> IAM 판정 139 — 패션·뷰티·여행·핀테크·모빌리티·식품/리테일·콘텐츠·펫·의료·
> 커리어 ~40개 브랜드)** + 기존 레퍼런스 보드 25핀(2026-07-13) + 초기 24장.
> 집계 아티팩트: `.tmp/braze-iam-layout-v2/analysis-summary.md` (repo 외 로컬).
> v1(25핀)의 "화이트 카드 + 센터 소품 수직 스택 지배(~22/25)"는 139핀에서
> 기각됐다 — 수직 스택은 **최다 단일 문법일 뿐 지배형이 아니며**(비중 ~40%),
> 오버레이형·분할형·풀블리드 비주얼 카드가 시장 프리미엄 문법의 절반 이상을
> 차지한다. 본 v2는 그 어휘를 등재하고 선택 규칙(§12)을 신설한다.
> 원본 스크린샷·핀은 repo에 없다 — 패턴은 본 문서의 워딩이 정본이며, 생성
> 프롬프트의 view_image 앵커로 타사 레퍼런스를 쓰는 것은 금지 (IP·캐릭터 오염).
>
> **번역 규칙 (가장 중요, v1 불변)**: 레퍼런스는 텍스트·배경·오브제가 한 장의
> 이미지로 구워진 완성 크리에이티브다. 우리 파이프라인은 기획안
> `image.mode`(`"layer"` 기본값 | `"scene"`, 빌더·검수 dispatch 입력명
> `{image_mode}`)에 따라 재현한다:
> - **`layer` 모드(기본)**: 텍스트는 **HTML 텍스트**(이미지에 굽지 않음), 배경은
>   **CSS**(단색·그라디언트·장식), 오브제만 **투명 PNG 에셋**(library/generate).
> - **`scene` 모드**: 배경+오브제가 **생성 씬 1장**으로 통합 (§10). **텍스트=HTML만
>   불변** — 씬 안에 글자를 굽지 않는다.
> 어느 모드·어느 레이아웃이든 이미지 안에 글자가 들어가는 순간 로컬라이즈·수정·
> 접근성이 전부 죽는다. 시장 관찰의 레터링·캘리그라피 히어로는 **HTML 디스플레이
> 타이포로 근사**한다 — 생성 레터링 금지 (§3, §11).

## 1. 존 문법 — 3계열 (139핀 재산정)

텍스트·비주얼·액션을 어떻게 배치하는가의 상위 문법. v1의 "수직 분리 고정 —
오버레이 금지" 계약은 139핀 관찰로 폐기하고(오버레이 ~35핀, 프리미엄 사례
다수 — 토스·쏘카·발란·무신사), 3계열로 재편한다.

### (a) 수직 스택 (최다 단일 문법, ~40%)

v1 7단 존 스택 그대로 — 센터 단일 컬럼, 텍스트존과 비주얼존 수직 분리:

```
┌─────────────────────┐
│              [✕]    │
│  아이브로우 필 (1줄)  │  ← 시점·자격 라벨: "매월 1일부터 10일까지", "회원님께만"
│  헤드라인 (1~2줄)     │  ← 악센트 키워드 정확히 1개 (§7)
│  서브카피 (0~2줄)     │  ← 선택 슬롯 (variants[].body가 있으면 = body 1줄)
│    ╭─────────╮      │
│    │ 히어로 존 │      │  ← 단일 소품 or 초대형 숫자 (카드 높이 30~45%)
│    ╰─────────╯      │
│  가격·조건 (선택)     │  ← 취소선 원가→할인가, 카운트다운 칩 (§7)
│  [   주 CTA 풀폭  ]  │  ← 행동동사, 브랜드 비비드 or 블랙
│   보조 dismissal    │  ← 회색 텍스트 링크 "다시 보지 않기"
└─────────────────────┘
```

선택 슬롯은 접되 순서 불변. 컴포지션 스케치는 전 존을 나열한다 (존 누락 시
병렬 빌더 발산 실측 2026-07-13). 변형: **오브제-톱 역전**(자기설명적 오브제가
상단), **CTA-미드**(헤드라인 직후 CTA, 오브제가 하단 장식), **샌드위치**(상하
비주얼 사이에 텍스트 — 에디토리얼 룩북 관찰), **역순 스택**(헤드라인→CTA→히어로).

### (b) 오버레이형 (~25%, v2 신설 — v1 금지 해제)

카드 전체가 비주얼(풀블리드 실사·일러스트·생성 씬·비비드 필드)이고 텍스트·CTA가
그 **위에** 얹힌다. 프리미엄 브랜드 최다 문법 (무신사맨 화보 캐러셀, 토스 3D 씬,
쏘카 리조트, 발란 HOLIDAY 타이포 레이어링).

**가독 조건 (의무)** — 오버레이는 아래 중 최소 1개를 갖춰야 한다. 없으면 §11
안티패턴("무대비 오버레이"):
- 텍스트존 뒤 **그라디언트 스크림** (상단 다크 페이드 or 하단 페이드 — 비주얼과
  동일 색상군)
- 비주얼 안 **여백존** (하늘·벽·단색 필드 위에만 텍스트 — scene 모드 세이프존과
  동일 원리)
- **고대비 색 반전** (다크 비주얼 + 화이트 볼드, WCAG AA 실측 통과)

파이프라인 매핑: 텍스트·CTA = HTML 오버레이 (불변). 비주얼 = `scene` 모드 생성
씬(§10) 또는 `library` 브랜드 실사·화보. **실사 생성 금지 불변** — 실사 오버레이형은
브랜드가 화보·상품컷을 제공한 경우만.

### (c) 분할형 (~13%, v2 신설)

좌텍스트-우비주얼 수평 분할 (관찰 全例 좌텍스트 — 좌→우 읽기 흐름). 텍스트
스택(아이브로우→헤드라인→CTA)이 좌측 정렬, 히어로가 우측 40~60%를 차지하며
**우/하단 엣지 블리드**(§6)와 결합하는 것이 정석 (올리브영·지그재그·W컨셉·
와디즈·버거킹). CTA는 좌측 정렬 소형 필(§8)이 짝.

파이프라인 매핑: `layer` 모드 CSS flex/grid 2컬럼 — 신규 생성 능력 불요.
하단시트·와이드 모달에 적합 (세로로 긴 모달에는 (a)가 우세).

## 2. 레이아웃 유형 — 9형 (관찰 빈도순)

| 유형 | 존 문법 | 구조 | 적합 | 근거 빈도 |
|---|---|---|---|---|
| **센터 모달 (라이트)** | (a) | 화이트/오프화이트 카드 중앙 | 혜택·알림 범용 | ~25% — 최다지만 기본값 아님 (§12 선택 규칙) |
| **하단시트 (미디어)** | (b)/(c) | 시트 전체가 비주얼, 텍스트 오버레이 or 좌우 분할, 캐러셀 결합 다수 | 상품·화보 소구, 멀티 오퍼 | ~20% (하단시트 총 ~32% 중) |
| **풀블리드 비주얼 모달** | (b) | 카드 전체 = 실사/일러스트/씬 + 텍스트 오버레이 | 임팩트·시즌·IP·프리미엄 | ~15% |
| **투톤 카드** | (a) | 상단 비주얼존(컬러/이미지/다크) + 하단 화이트 액션존. 역전형(상단 이미지 배너+하단 바디) 포함 | 브랜드 컬러 강한 캠페인 + 명확한 행동 | ~13% |
| **센터 모달 (다크/비비드)** | (a)/(b) | 블랙/딥컬러/브랜드 비비드 단색 + 고채도 오브제, 스포트라이트 글로우 | 임팩트·긴급·프리미엄·럭셔리 | ~13% |
| **하단시트 (라이트)** | (a) | 화이트 시트 + 그래버, 소형 히어로 | 기능 안내·온보딩·가벼운 발견 | ~12% |
| **풀시트** | (a)/(b) | 화면 전체 점유, 배경도 크리에이티브 | 온보딩·시즌 캠페인·몰입·테이크오버 | ~11% |
| **메타포 프레임** | 특수 | 카드/시트 자체가 오브젝트 (티켓 다이컷·뽑기머신·슬롯머신) — 스큐어모피즘 | 게이미피케이션·쿠폰·랜덤 보상 | ~5% (완성도 높을 때 강력) |
| **배너/플로팅 바** | 특수 | 상단 슬라이드다운 or 하단 고정 바 — 화면 점유 최소 | 저침습 리마인드·카운트다운 | ~2% (HTML IAM 아닌 native 우선 검토) |

- 포맷(모달/하프시트/풀스크린) 선택 자체는 `format-design-guide.md` §0 매트릭스가
  우선 — 본 표는 각 포맷 안에서의 비주얼 처리를 정한다.
- 유형 선택 규칙·variant 분화는 **§12**.

## 3. 히어로 유형 — 히어로 존에 무엇을 넣는가

139핀 분포: 실사 인물/로케이션 ~30 · 3D 소품 ~22 · 포토 상품 ~16 · 일러스트 씬
~15 · 쿠폰 티켓 ~12 · 클러스터 ~10 · 텍스트 온리 ~10 · UI 프리뷰 ~8 · 숫자/레터링
타이포 ~8 · 캐릭터(브랜드 IP) ~8. **생성 가능 여부와 관찰 빈도는 별개** — 실사·
캐릭터는 시장 상위지만 우리 파이프라인 제약(아래)이 우선한다.

| 히어로 유형 | 문법 | 파이프라인 매핑 |
|---|---|---|
| **단일 의미-지시 소품 (생성 기본값)** | 소품 1개 중앙 or 우측(분할형), 크게 — §4 어휘에서 캠페인 의도로 선택. 글로시 3D, 비비드 단일 색군, 살짝 기울여 부양 | `generate` 1건 (`3d-icon`/`flat-icon`) |
| **초대형 숫자 타이포 히어로** | 할인율·금액·날짜 숫자가 곧 히어로. 극단 사례: 카드 폭을 채우는 계단식 디스플레이 타이포(무신사 페스타), 누적 카운터 3연타(무진장). **HTML 대형 타이포 + CSS** | 생성 0건 — 빌더 HTML/CSS. 소형 소품 보조 병치 가능 |
| **실사 (인물·로케이션·시즐)** | 화보·스튜디오·시즐 컷이 카드를 채우고 텍스트 오버레이 — 시장 최다·최프리미엄 문법 | **생성 전면 금지** (스타일 4종 계약 불변). 브랜드 제공 실사만 `library`. 제공 없으면 이 히어로 유형 자체를 선택하지 않는다 |
| **포토 상품** | 상품 실물컷 단상·대각 배치, 원형 % 배지·취소선 가격과 결합 | 브랜드 제공 상품컷만 `library` |
| **오브제 클러스터** | 주 오브제 + 의미 위성 소품 ≤2, 단일 색군 | `generate` 1건 (클러스터 통짜) or 주 1 + `css` 장식 |
| **쿠폰 티켓** | 절취선·스텁·노치 티켓 그래픽, 기울여 배치. 봉투에서 나오는 연출, 낚싯바늘에 걸린 태그 등 §4 은유와 결합 | `generate` — 숫자·문자는 HTML 오버레이 |
| **카드 중첩 / 카드 팬** | 오퍼 카드·상품 카드·UGC 카드가 겹치거나 부채꼴로 — 깊이감 연출 (글래스 쿠폰카드, 커버 카드 팬, 카드-온-포토) | 카드 프레임 = **CSS/HTML** (그림자·radius·겹침), 카드 속 이미지는 `library`/`generate` |
| **UI 프리뷰** | 실제 앱 화면·컴포넌트 목업 — 기능 온보딩·신뢰 소구 (토글, 검색창, 거래내역 카드, 탭바 스포트라이트) | 브랜드 제공 스크린샷 `library`, 단순 컴포넌트는 **HTML로 재현** — UI 목업 생성 금지 (허구 UI 오독) |
| **소셜프루프 존** | 스토어 평점 카드, 파트너/정부 로고 스트립, UGC 댓글 카드, 누적 판매 카운터 | 평점·카운터 = HTML, 로고 = `library` (브랜드 제공 로고만 — 타사 로고 임의 사용 금지) |
| **앱아이콘 배지** | 스쿼클 앱아이콘 + 알림 도트(CSS 원) — 기능·설정 소구 | `generate` 1건 (`3d-icon`, front-on) + `css` 도트 |
| **캐릭터 히어로** | 브랜드 캐릭터 중심 씬 | **사용 금지 — 2026-07-13 사용자 결정 불변** (라이브러리 컷 포함). 근거: 생성 캐논 얼굴 재현 불가 3연속 실측. 시장 관찰 8핀은 전부 브랜드 보유 IP 원화 — 우리 조건과 다름. 대체 = 단일 의미-지시 소품 |
| **레터링·캘리그라피 (생성)** | 붓글씨·그래피티·버블 타이포를 이미지로 생성 | **금지** — 번역 규칙 위반. 대체: HTML 디스플레이 타이포 (§7 — weight·크기·색 반전으로 근사) |
| **텍스트 온리** | 비주얼 없이 카피+CTA만 | 기능 확인·동의 다이얼로그 한정. **마케팅 IAM에서 비주얼 제로 = §11 안티패턴** (공지문 인상 — 관찰 quality 최하위 클러스터) |

## 4. 오브제-메시지 메타포 정합 (핵심 룰, v1 + 신규 어휘)

오브제 = 메시지의 시각 은유. 장식이 아니라 의미다:

| 캠페인 의도 | 관찰된 오브제 |
|---|---|
| 쿠폰·할인 발급 | 절취선 쿠폰/티켓 (최빈), 퍼센트 배지, 봉투에서 나오는 쿠폰 |
| 적립·캐시백·페이백 | 코인 스택·동전, 지폐 |
| 선물·보상 | 뚜껑 열린 선물상자, 복주머니, 리본 풀린 기프트박스 |
| 미확인·랜덤 보상 | **미스터리 박스(? + 글로우)**, 뽑기 캡슐, 클로버, 물음표 |
| 초대·메시지 도착 | 봉투 (열리는 중) |
| 리마인드·알림 켜기 | 벨, 3D 토글 스위치 (ON) |
| 마감 임박·한정 시간 | **3D 알람시계**, 일력/달력 (해당 숫자), 카운트다운 칩(HTML) |
| 등급·달성·랭킹 | 메달·트로피·배지, **VIP 등급 배지** |
| 공지·업데이트 | **확성기**, 말풍선 |
| 점검·진단·설문 | 클립보드+체크/펜 |
| 혜택 잡기 | 낚싯바늘에 걸린 쿠폰 태그 (복수 앱 독립 관찰 — 검증된 은유) |
| 할인 규모 | 프레임을 압도하는 숫자 — HTML 타이포 히어로 (§3) |
| 보안·잠금 해제 | 자물쇠 (열림 상태) |
| 전환·갈아타기 | **노선도·환승 메타포**, before→after 다이어그램(HTML) |
| 약속·신뢰 | 새끼손가락 건 두 손, 파트너 로고 스트립(§3 소셜프루프) |
| 여행 | 미니어처 랜드마크 + 맵핀, 캐리어 |

기획안 `image.assets[].concept`에는 "무엇이 보여야 하고 무엇이 보이면 안
되는지"를 명시한다. 의미 없는 소품은 빼는 쪽이 낫다.

## 5. 배경 문법 — 5계열 + 팔레트 공식

v1 "기본 = 플랫 화이트"는 폐기 — 139핀에서 화이트 카드 ~25%, 풀블리드 비주얼
~29%, 비비드 단색·다크·투톤·그라디언트가 나머지. **배경 계열은 §2 유형과 §12
선택 규칙이 결정**하며, 아래가 어휘 전부다:

| 계열 | 처리 | 적합 맥락 | 파이프라인 |
|---|---|---|---|
| (a) 화이트/오프화이트 + 상단 브랜드 워시 | 플랫 or 상단 소멸 톤온톤 그라디언트 | 신뢰·기능 안내·클린 프리미엄 | CSS |
| (b) 비비드 단색 커밋 | 브랜드 비비드 1색 전면 + 텍스트 화이트 반전. 그레인/페이퍼 텍스처 얹으면 프리미엄 상승 (관찰: 에이블리·버거킹·무신사) | 브랜드 컬러 강한 캠페인·페스티벌 | CSS (텍스처 = CSS noise/svg) |
| (c) 다크 + 글로우 | 블랙/딥컬러 + radial 스포트라이트·보케 글로우, 오브제 글로우 | 임팩트·긴급·럭셔리·언박싱 | CSS |
| (d) 투톤 분할 | 상단 비주얼존 색/이미지 + 하단 화이트 액션존 (역전형 포함) | 비주얼-액션 분리가 필요한 정보형 | CSS + 에셋 |
| (e) 풀블리드 비주얼 | 실사/일러스트/생성 씬이 배경 그 자체 (§1-b 오버레이형) | 화보·시즌·몰입 | `scene` 생성 or `library` 실사 |

- 장식 오브(말풍선·컨페티·별·리플 링 = CSS 도형 급, 4~6개 이하)는 `source:"css"`.
- **대비 요건 불변**: 오브제 채도 > 배경. 파스텔-온-파스텔 워시 금지 (§11).
- **팔레트 공식 불변**: 뉴트럴 바탕 + 브랜드 비비드 1 + 악센트 ≤1. 오버레이형은
  "비주얼 무드 1 + 텍스트 반전색 + 악센트 ≤1"로 등가 적용. 브랜드 토큰 매핑은
  활성 DESIGN.md 기준.
- **그라디언트 취향 룰 불변** (프로브 실측 2026-07-10): 웜→쿨 투컬러 수직 스윕
  금지. 허용 = ① 단색 솔리드 ② 동일 색상군 톤온톤 ③ 다크 + radial 스포트라이트.

## 6. 컴포지션 룰 (레이어 배치)

- **히어로 스케일**: 오브제 폭 = 프레임 폭 40~60%, 히어로 존 높이 = 카드 높이
  30~45% (수직 스택 기준). 분할형은 우측 40~60% 폭. 오버레이형은 비주얼이 100%.
- **카드 프레임**: radius 20~28px (활성 DESIGN.md radius 위계 우선), 닫기 ✕
  우상단, 텍스트·CTA 콘텐츠 폭 = 카드 폭 ~80%.
- **엣지 블리드 (v2 정식 어휘, ~22핀)**: 히어로가 카드 프레임 밖으로 잘려나가는
  배치 — `overflow:hidden` + 오버사이즈/네거티브 마진. 다이내믹·스케일감이 필요할
  때. 잘리는 방향은 하단 or 좌우 1방향, **의미 디테일(숫자·상징부)이 잘리면 안
  된다**. 수직 스택에서도 위성 소품 1~2개의 엣지 걸침은 허용.
- **기울임**: 쿠폰·태그·티켓류는 5~15° 기울여 다이내믹하게. 정직한 수평은 정적
  오브제(달력·토글)만.
- **대각 배치·코너 프레이밍**: 소품을 대각 코너에 배치해 중앙 텍스트를 액자화
  (관찰: 쏘카) — 위성 소품 ≤4, 크기 차등, 중앙 가독 우선.
- **카드 중첩**: 카드-인-카드(시트 안 오퍼 카드), 카드-온-포토(화보 위 상품 카드),
  카드 팬(부채꼴 중첩) — 전부 CSS 레이어. 겹침 각도·그림자로 깊이감, 최상단
  카드에 정보 집중.
- **콜라주 금지 불변 (P0)**: 분리 생성된 복수 투명 PNG를 물리 상호작용(들다·얹다·
  기대다)처럼 CSS 조립 금지 (2026-07-10 도그푸딩 반려). 물리적으로 맞물린 복합
  오브제는 생성 단계에서 통합 (`imagegen-pipeline.md` 통합 컴포지션 경로).
  위 카드 중첩·코너 프레이밍은 비물리적 CSS 겹침이라 콜라주에 해당하지 않는다.
- **비물리적 겹침 허용**: 오브제-텍스트존 z-index 겹침 + CSS mask 수직 페이드로
  가독 확보 (pin-22 복제 실측 2026-07-13). CTA가 히어로 위에 얹히는 오버레이
  CTA도 동일 원리 (§8).
- **radius 스케일 잠금 불변**: 카드·CTA·필·아이콘 radius 한 체계.
- **부유감**: box-shadow 부드럽게 + `interaction-standard.md` float 애니메이션.
  그림자를 PNG에 굽지 않는다.
- **시선 흐름**: 수직 스택 = 아이브로우→헤드라인→오브제→CTA 단일 흐름. 분할형 =
  좌상(텍스트)→우(비주얼)→좌하(CTA) Z-흐름. 오버레이형 = 텍스트존→비주얼→CTA존
  (스크림·여백존이 흐름을 만든다).

## 7. 텍스트 위계 (HTML 렌더)

- **아이브로우**: 12~14px — 시점·자격·긴급. 악센트색 or 필 배지. 변형: 해시태그
  나열형(#블라우스 #오프숄더 — 패션 관찰), 콜라보 락업("브랜드 | 파트너").
- **헤드라인**: 모달 20~26px, 풀시트 28~32px, 1~2줄. **악센트 키워드 정확히 1개**.
  오버레이형은 비주얼 대비 화이트/블랙 볼드 + WCAG AA 실측.
- **숫자 = 최상위 위계 불변**: 숫자 소구 캠페인이면 숫자가 카드 최대 타이포
  (헤드라인의 ≥1.5배 허용). HTML 대형 타이포로. 관찰 강화 사례: 카드 폭 계단식
  디스플레이 타이포, 누적 카운터 — 전부 HTML로 재현 가능.
- **디스플레이 타이포 근사 (v2)**: 시장의 레터링·캘리그라피 히어로는 웹폰트
  weight 대비·자간·색 반전·아웃라인(text-stroke)으로 근사한다. 이미지 굽기 금지.
- **가격·조건 슬롯**: 취소선 원가→할인가 병기 (관찰: 낙차 연출이 판매력 핵심),
  카운트다운 칩(HTML/JS — `interaction-standard.md` 준수), 조건 태그 라벨 분리.
- **서브카피**: 1~2줄, secondary 색. 구체 정보에 악센트 부분 강조.
- **개인화 슬롯 (v2 명문화, ~11핀)**: 실명·닉네임을 아이브로우 or 헤드라인에 —
  `liquid-guide.md` 형식, 카탈로그 내 식별자만. 관찰상 개인화 헤드라인은 질문형
  카피와 짝일 때 강력 ("임규민님, ~하시겠어요?").

## 8. CTA·dismissal 문법 (v2 확장)

**CTA 형태 어휘** (기획안 cta + composition이 선택, craft CTA ≤2 불변):
- **풀폭 필 단일 (기본)**: 행동동사, 브랜드 비비드 1색 or 블랙. 수직 스택의 정석.
- **좌정렬 소형 필**: 분할형·오버레이형의 짝 — 텍스트 스택 하단에 비풀폭 필.
  CTA 색을 히어로/제품 색과 매칭하는 디테일이 프리미엄 (관찰: 지그재그·올리브영).
- **듀얼 CTA**: 그레이 거절("괜찮아요") + 브랜드 수락 — 좌우 or 수직 스택.
  거절을 텍스트링크로 강등하는 비대칭 위계도 유효. 채널 선택형(채팅/전화)도 관찰.
- **오버레이 CTA**: 히어로 위 우하단에 얹는 필 (§6 비물리 겹침) — 비주얼 몰입을
  깨지 않는다.
- **텍스트링크 CTA**: 밑줄 텍스트만 — 에디토리얼·미니멀 문법 (관찰: 29CM·번개장터).
  전환 압력이 낮은 브랜딩 캠페인 한정.
- **전면 탭 (CTA리스)**: 명시 버튼 없이 카드 전체가 탭 영역. **조건부** — 카드
  래퍼에 `id="iam-card"` + logClick 매핑 필수 (트래킹 소실 방지), 유도 어포던스
  (chevron·"자세히 보기" 마이크로 카피·커서 아이콘) 1개 이상 배치.
- 질문형 CTA·게임화 CTA(슬롯 STOP 등)는 v1 그대로 — brazeBridge 제약 안에서만.

**dismissal 어휘**:
- 회색 텍스트 링크 (기본) / 닫기 ✕ 우상단 상시 (`iam-close`).
- **하단 유틸 바 (v2, ~28핀)**: 카드 밖 하단에 "오늘 그만 보기 | 닫기" 텍스트
  듀얼 바 — 카드 안 dismissal 슬롯을 제거해 크리에이티브를 깨끗하게 유지.
  HTML IAM에서는 카드 아래 별도 존으로 재현 (딤 영역 클릭과 구분).
- **기간 스누즈 (v2, ~10핀)**: "24시간/3일/일주일 보지 않기" — 재노출 압력이 높은
  캠페인에서 기본 "다시 보지 않기"보다 유리. 구현은 logClick 커스텀 매핑 +
  Braze 재노출 설정 연계 (콘솔 설정 병기).
- dismiss-as-CTA ("오늘은 괜찮아요" 단일 버튼 + 상품 행 탭 진입) — 리스트형
  머천다이징 한정.

## 9. 시즌·캠페인 스킨

시즌 캠페인은 배경·장식·소품만 갈아입고 문법은 유지: 설날 = 복주머니·소나무·
기와 실루엣·금박 무드, 봄 = 꽃잎, 여름 = 물·풀장 디오라마, 연말 = 컨페티·폭죽.
시즌 요소는 `css` 장식 or `generate` 소품으로 선언. 시즌에도 히어로는 의미-지시
소품 — 캐릭터는 IAM 미포함 (§3). 관찰 보강: 시즌 무드는 **팔레트 커밋**(전통
크림+금박, 코발트+핑크 보색)이 소품 수보다 효과적 — 요소 과밀은 §11.

## 10. 씬 카드 문법 (scene 모드) — 존치 확정

> v1의 존치 보류(2026-07-13, 보드 25핀에 0핀)는 **해제 (2026-07-14)**: 139핀
> 재분석에서 풀블리드 비주얼 카드 계열 ~40핀 — 오버레이형(§1-b)의 생성 경로가
> scene 모드다. 신규 캠페인에서 layer와 동급 선택지로 검토한다 (§12 선택 규칙).

`image.mode: "scene"`일 때 §1~§9의 텍스트 위계·CTA 문법은 유지되고, 배경 처리와
히어로 생성이 갈라진다:

- **카드 전체 = 생성 씬 1장** — 배경 포함 통짜 생성 (`imagegen-pipeline.md` 씬
  경로 — 알파 검증 skip).
- **텍스트 절대 금지 불변**: 씬 안에 글자·숫자를 굽지 않는다. 텍스트 = HTML 오버레이.
- **STRICT 세이프존 불변**: 상단 ~32% = 순수 배경 여백 (헤드라인존) / 하단 ~22% =
  플랫 지면·저디테일 (CTA존) / 히어로 클러스터 = 중간 밴드(32~78%), 캔버스 폭 ~60%.
- **히어로**: 단일 의미-지시 소품 (§3 — 캐릭터 미포함 불변).
- **미니멀 씬 미학 불변 (생성 씬 한정)**: 씬 배경은 "장소"가 아니라 추상 컬러
  필드 — §5 그라디언트 허용 3형의 스튜디오형. 환경 묘사(하늘·구름·수풀·언덕·
  지평선)와 스토리북/유아 톤 금지 (재도그푸딩 반려 실측 2026-07-13 — 관찰 시장의
  리치 씬은 대부분 브랜드 IP 원화·실사라 우리 생성 조건과 다르다. 생성 씬 어휘
  확장은 별도 파일럿 게이트 통과가 선행). 위성 소품 ≤2.
- **발송본 HTML**: `background: url(<씬 CDN URL>) center / cover` + 텍스트존(상단)·
  CTA존(하단) 오버레이 + 가독 조건(§1-b — 필요시 CSS 스크림 추가 허용).
- **캔버스**: 세로 1024×1536.
- **§2 관계**: scene은 풀블리드 비주얼 모달·풀시트·하단시트(미디어)의 생성 경로 —
  새 레이아웃 유형이 아니라 비주얼 처리 방식.

## 11. 안티패턴 (139핀 quality 교차 + 도그푸딩 실측)

- 이미지에 텍스트 굽기 — 번역 규칙, 양 모드·전 레이아웃 공통. 생성 프롬프트 `no text` 상수 유지.
- 실사 생성 — 스타일 4종 계약 위반. 실사는 브랜드 제공 자산 한정.
- **무대비 오버레이 (v2 — 구 "오버레이 전면 금지"를 대체)**: 스크림·여백존·색
  반전 없이 비주얼 위에 텍스트를 얹어 가독 붕괴. 오버레이 자체는 §1-b 정식 문법.
- 히어로 없이 소품만 산개 — 시선 앵커 부재. 반드시 주 오브제 1개 (텍스트 온리
  기능 다이얼로그 제외).
- **비주얼 제로 마케팅 IAM (v2)**: 혜택·전환 캠페인을 텍스트+기본 버튼만으로 —
  관찰 quality 최하위 클러스터 ("시스템 알럿·공지문"). 기능 확인·동의 다이얼로그만 예외.
- **이모지 그래픽 의존 (v2)**: 이모지를 히어로·불릿·CTA 라벨에 남발 — 관찰상
  프리미엄 브랜드도 이 순간 저가 톤으로 추락. 이모지 ≤1, 히어로 대체 불가.
- **스톡 제네릭 플랫 일러스트 (v2)**: 범용 벡터 인물·클립아트 톤 — "안전하지만
  개성 없음" 클러스터. 스타일 스캐폴드(글로시 3D 라인)로 회피.
- **요소 과밀 (v2)**: 배지+캘리+티켓+넘버링+이모지 동시 투입 — 팔레트 3색·위계
  3단을 넘는 순간 전단지化. 여백이 히어로를 만든다.
- 오브제-메시지 불일치 소품 — 오독 유발 (§4).
- 풀 일러스트 씬을 layer 히어로에 생성 — layer 히어로는 투명 배경 단일 소품.
  배경 포함 통짜는 scene 모드가 정식 경로 (§10).
- 캐릭터·마스코트 히어로 — IAM 전면 미포함 불변 (§3, 사용자 결정 2026-07-13).
- 파스텔-온-파스텔 워시 — §5 대비 요건 위반 (재도그푸딩 반려). 프롬프트 금지어 유지.
- layer 모드에서 배경 포함 생성 — layer 배경은 CSS 전용.
- 콜라주 물리 상호작용 조립 — §6 (도그푸딩 반려 2026-07-10).
- 웜→쿨 투컬러 수직 스윕 — §5 그라디언트 룰 (사용자 판정 "촌스러움").
- 환경 묘사 씬 (스토리북) — 생성 씬 한정 금지 (§10, "동화책 같다" 반려).
- 캐릭터 치비화 — (캐릭터 미포함이라 사실상 도달 불가, 진단용 존치).
- 모달 안 콘텐츠 과적 — 목록 4개면 하프시트 (`format-design-guide.md` §0).

## 12. 레이아웃 선택 규칙 — 지시 모드·자율 창작·variant 분화 (v2 신설)

### 12.1 레이아웃 지시 모드 (`layout.directive`)

기획안 `layout.directive` = `"specified"` | `"auto"` (기본). SKILL.md Step 2
인터뷰의 레이아웃 선호 질문으로 결정:
- **specified**: 사용자가 §2 유형·존 문법·레퍼런스 방향을 지정 — 기획은 그 안에서
  설계하고 `layout.specified`에 지정 내용을 기록. 지정과 §11 안티패턴이 충돌하면
  충돌 지점을 보고하고 사용자 판단을 받는다 (조용한 무시·조용한 준수 양쪽 금지).
- **auto**: Claude가 §2 전 어휘에서 자율 선택. **무근거 기본값 금지** — "센터
  모달 라이트 + 수직 스택"을 고르려면 다른 유형 대비 선택 근거가 있어야 한다
  (신뢰·기능 안내 맥락 등). 기획안 카드에 유형 선택 근거 1줄 명시.

### 12.2 자율 모드 창작 조항 (사용자 결정 2026-07-14 — 옵션 B)

auto 모드에서 등재 어휘가 기본이지만, 캠페인에 맞으면 **등재 패턴의 조합·변형·
신규 구조를 시도할 수 있다**. 조건:
- **하드 가드레일 불변**: §11 전 항목 + 텍스트=HTML + 콜라주 금지 + 캐릭터 미포함
  + 오브제-메시지 정합 + WCAG AA — 창작 모드에서도 전부 P0/P1 그대로.
- **추적 가능성**: 창작 레이아웃은 brief ③-b에 `창작 레이아웃 — <근거 1줄>`을
  명시한다 (검수가 §12.2 창작 표기·근거를 확인 — 무표기 창작 = P1).
- 창작이 도그푸딩·검수에서 반복 통과하면 §1~§2 어휘로 승격, 반려되면 §11에 기록.

### 12.3 Variant 레이아웃 분화 룰 (사용자 결정 2026-07-14)

- **A/B는 최소 1축 구조 분화가 기본**: ① §2 유형 상이 or ② 존 문법/변형 상이
  or ③ 히어로 유형 상이. 카피·색만 다른 A/B = 검수 P1.
- 기획안 `layout.variants.A/B`에 variant별 유형+존 스케치(전 존 나열)를 각각
  기록하고, `layout.divergenceAxis`에 분화 축 1줄을 명시한다.
- **오버라이드**: 사용자가 "레이아웃 동일, 카피만 A/B"(순수 카피 테스트)를 명시
  하면 동일 레이아웃 허용 — brief에 오버라이드 기록 (signup 선례 방식). 이 경우
  구 룰(존 순서 고정, 차별화 = 카피·컬러·히어로)이 그대로 적용된다.
- 주의: 구 계약의 "존 순서·레이아웃 구조 재해석 금지 (A/B 변인 오염 방지,
  2026-07-10)"는 **기본값이 역전**된 것 — 분화는 기획(Step 3)이 설계하고 빌더는
  받은 스케치에 충실한다. 빌더 임의 분화·임의 통일은 여전히 금지.

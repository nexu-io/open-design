Usage rules

Native, flat, functional

No substitute icon set unless the glyph is missing. No emoji in product UI.

Use glyphs as text
class="uni-icon uni-icon-search" renders through the bundled font.
List affordances stay grey
Chevrons and passive controls use #bbbbbb / secondary text, not action blue.
Semantic color is explicit
Active, rating, validation and destructive moments may use primary or status tokens.

State color

Color only when the icon carries state

primary / success / warning / danger
info · #007aff
success · #4cd964
rating · #ffbe00
danger · #dd524d

Raster tab icons

Tab bar uses PNG normal / active pairs

This follows Mini-Program conventions: font icons for in-page UI, raster image pairs for bottom tabs.

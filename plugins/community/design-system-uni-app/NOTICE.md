# uni-app Design System Notice

This public Open Design design-system package was reconstructed from source evidence
captured from DCloud's uni-app ecosystem.

## Upstream Sources

- `dcloudio/hello-uniapp` provides the Hello uni-app showcase app structure, `uniicons`
  font usage, tab-bar PNG assets, and practical component examples. GitHub reports this
  repository as MIT licensed.
- `dcloudio/uni-app` provides built-in component behavior and token references for
  button, switch, input, icon, and related primitives. GitHub reports the primary
  repository license as Apache-2.0, with additional upstream license files present.

## Package Policy

- Source assets in `assets/`, `fonts/`, and `ui_kits/hello-uniapp/` are preserved
  byte-for-byte where available and should not be redrawn or substituted.
- `DESIGN.md`, `README.md`, `colors_and_type.css`, preview cards, and generated UI kit
  files are packaged to help Open Design agents generate faithful uni-app-style screens.
- `uni-app`, DCloud, HBuilderX, WeUI, WeChat, and related marks remain property of their
  respective owners. This package is a design-system reconstruction for interoperability,
  not an official DCloud publication.

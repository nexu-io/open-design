# Applying the Perplexity AI system

Use the saved files as implementation guidance for new artifacts.

1. Bind the seven roles in `brand.json` before adding component styles.
2. Load `fonts/fonts.css`; use `pplxSans` for display/body and `pplxSansMono` for dense numeric metadata.
3. Keep the canvas dark, the border 1px, the radius 8px, and the spacing rhythm on an 8px baseline.
4. Use the accent only for high-signal states and keep citations adjacent to claims.
5. Follow `BRAND.md` for voice, imagery, accessibility, and composition decisions.

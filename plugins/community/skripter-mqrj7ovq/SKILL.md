# Skripter

A complete scripting system for content creators — covering topic ideation, deep research,
storytelling integration, script structure, and monetization. Distilled from real workflows
of top documentary and short-form creators.

**Blends with:** Storyteller skill — when both are available, use CART structure and P.A.S.T.
scene framework from Storyteller inside the Adversity/Body sections of any script written here.

---

## Core Philosophy

**Topic + Script = Everything.** Background, camera, editing — all secondary. What actually
determines whether a video blows up is whether you picked the right topic and whether your
script keeps people watching. Start there. Fix that first. Everything else can be mediocre.

**No original ideas.** Every viral idea is a recycled idea executed better. The goal is not
to invent something new — it is to take what already works and make your own version of it.

**Short-form and long-form follow the same first principles.** Hook, value, CTA. The only
difference is density and length of the middle section.

## Quick Reference Cheatsheet

```
TOPIC FORMULA (Recycle 4S):
  S1 = Find 3 viral videos on the topic
  S2 = Identify common patterns (hook style, structure, thumbnail)
  S3 = Create your own version (remix title, script, style)
  S4 = Test and optimize after upload

REEL STRUCTURE:
  Hook (0-3s)    → Question/Conflict/Shock — no preamble
  Body           → Value, fast-paced, scene cuts every 2s
  CTA            → One clear action at the end

DOCUMENTARY STRUCTURE:
  Intro          → Hook + stakes + what this video will reveal
  Chapter 1-3    → Research data organized by sub-topic
  Conclusion     → Takeaway + call to action

FOUNDATION QUESTIONS (answer before scripting anything):
  1. What subject? (that you won't burn out making)
  2. Who is the target audience? (age, interest, platform)
  3. What is YOUR unique angle? (why you, why now)

CONTENT TYPES:
  Timeless → works any time, needs great hook + script
  Trending → works only in season, topic does heavy lifting

PUSH vs PULL:
  Pull = trendy/viral/catchy → gets new followers
  Push = authentic/personality → deepens existing community
  Balance both. Neither alone is enough.

HOOK TYPES (Reel):
  Question hook  → triggers unanswered loop in brain
  Conflict hook  → introduces stakes immediately
  Celebrity hook → borrow credibility from known figure
  Demo hook      → show the result before explaining it
  Caption hook   → text on screen does the work (no verbal hook needed)

STORYTELLER INTEGRATION:
  When Storyteller skill is active:
  → Use CART for full documentary scripts
  → Use P.A.S.T. inside the emotional/adversity sections
  → Use Anticipation/Contrast hooks from Storyteller's hooks.md
```

## Output Format for All Scripting Tasks

**Reel script output format:**
1. Topic + target audience stated upfront
2. Hook (labeled, ≤3 seconds of speech)
3. Body (value dense, 2-second scene cadence noted)
4. CTA (one action, not three)
5. Notes on B-roll, sound, or visual cues where relevant

**Documentary script output format:**
1. Topic, objective, and target audience
2. Intro (hook + stakes)
3. Chapters (labeled, with sub-topics and transitions)
4. Conclusion + CTA
5. Estimated word count and video length

**Hook diagnosis output format:**
- State which hook type it is (or that it's missing one)
- State the specific reason it's failing
- Rewrite with fix applied — show before/after

When improving an existing script, identify the failure first (weak hook, no stakes, too slow,
no conflict) before rewriting. Show the diagnosis, then the fix.

# Skripter Cheatsheet
## Script Writing System for Content Creators

---

### Foundation — Lock This Before Any Script

```
1. Subject?    → What can you make unlimited content on without burning out?
2. Audience?   → Who EXACTLY? (age, interest, platform, language)
3. Angle?      → Why YOU? What do you bring that others don't?
```

---

### Topic Formula — Recycle 4S

```
S1 → Find 3 viral videos on your topic (top 12 results)
S2 → Identify common patterns: hook style, structure, thumbnail, tone
S3 → Create your own version: remix title, angle, script, unique data point
S4 → Test + optimize: 48hr check on CTR and 30-sec retention
```

---

### Reel Structure

```
HOOK  (0–3s)  → One sentence. Open loop. No preamble.
BODY          → Dense. Visual change every 2 seconds. Conflict → reveal cycle.
CTA   (last 3s) → ONE action: follow / save / comment / share
```

---

### Documentary Structure (Blend with Storyteller CART)

```
INTRO     → Scene hook + stakes + promise
CHAPTER 1 → WHO + context (600–800 words)
CHAPTER 2 → WHAT + WHEN — core conflict (800–1200 words)
CHAPTER 3 → WHERE + WHY + HOW — real examples + root causes (800–1200 words)
CONCLUSION → Callback + 1-sentence takeaway + CTA
```

---

### Hook Type Selector

| Situation | Hook Type |
|---|---|
| Surprising or counterintuitive fact | Conflict Hook |
| Tool or process demo | Demo Hook (show result first) |
| Known person or cultural moment | Celebrity Hook |
| Question your audience already has | Question Hook |
| Visual/footage is self-explanatory | Caption Hook (text on screen) |
| Philosophical or motivational content | Incomplete Statement Hook |

---

### Retention Checkpoints (Documentary)

```
0:00  → Hook + stakes
3:00  → First surprising data point
6:00  → Escalation (problem bigger than expected)
9:00  → Human story / emotional beat (P.A.S.T. if Storyteller active)
12:00 → Root cause reveal
14:00 → Takeaway + CTA
```

---

### Content Types

```
TIMELESS → Works any time. Script quality carries it.
TRENDING → Works only in season. Topic carries it.
PUSH     → Authentic/personal. Deepens existing audience.
PULL     → Trendy/viral. Brings new followers.

Rule: 70% timeless / 30% trending. Balance push and pull.
```

---

### AI Research Stack

```
Grok 3       → Primary research (5W1H queries, Deep Research ON)
Perplexity   → Secondary source / cross-check
DeepSeek     → Transcript summaries, data synthesis
ChatGPT      → Script generation from organized data
```

---

### Storyteller Skill Integration

```
When Storyteller skill is active:
→ Use CART for documentary arc (C=Intro, A=Ch2, R=Ch3, T=Conclusion takeaway)
→ Use P.A.S.T. in Chapter 2/3 for emotional case study scenes
→ Use Anticipation/Contrast hooks from hooks.md for reel openers
→ One takeaway sentence in conclusion. Always exactly one.
```

---

### Freelancing Quick-Start

```
Step 1 → Build proof: 2–4 YouTube videos + 8–12 Instagram reels
Step 2 → Find small channels (500–10K subs, research-heavy niche)
Step 3 → Cold email with FREE sample script written for their channel
Step 4 → Deliver trial at 50% rate → ask for full rate after
Step 5 → Tie rate increases to their channel growth
```

**Rate baseline:** ₹400–800/reel | ₹2,000–5,000/documentary | ₹4,000–8,000/month part-time

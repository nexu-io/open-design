# Hugging Face-inspired brand system

## What is inside

Use `README.md` for package orientation, `DESIGN.md` for visual rules, `BRAND.md` for prose and usage guidance, `colors_and_type.css` for tokens, `preview/` for focused evidence cards, `assets/` and `logos/` for preserved marks, and `ui_kits/app/` for an applied interface reference.

## Source context

The source URL is `https://github.com/latinzx-gif/design_A1`. The bounded intake found an empty repository; the provided `context/input-DESIGN.md` is therefore authoritative. Do not claim source HTML, CSS, fonts, large imagery, or vector logo measurements that are not present in the evidence.

## When to use

Use this system for ML community hubs, model browsers, repository-aware learning surfaces, and short hands-on AI workshops. It is especially useful when the product should feel precise and dense but still welcoming to younger learners and newcomers.

## How to use

1. Load `colors_and_type.css`.
2. Use the seven semantic roles from `brand.json` instead of inventing new brand colors.
3. Use IBM Plex Mono for display/UI/tags/code and Source Sans Pro for prose.
4. Keep yellow small and intentional; pair it with visible borders and compact metadata.
5. Check the focused cards in `preview/` and the composed shell in `ui_kits/app/index.html` before shipping.

## Design system highlights

- Off-white canvas, neutral panel, deep ink, gray inset, hairline border, sunshine yellow, and secondary ink.
- 4px base spacing scale; 4–6px radii; 1px borders; 1280px max-width; 24px gutters.
- Cheerful, technically confident, community-first voice.
- Minimal ease-out motion and repository-style information density.

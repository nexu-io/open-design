Typography

Amazon Ember — system fallback shipped.

Amazon Ember is not freely web-licensed; the framework's font stack reproduces its geometric humanist proportions through Helvetica Neue + Arial + system-ui. Diagram labels are Arial 12pt, period.

How the plugin runs

Brief in, AWS-spec deck out.

Inputs

themedark (Squid Ink, in-person standard) / light (white, web/PDF distribution)
deckSubjectproposal · migration · war · genai · custom
audienceDefaults to "AWS Solutions Architects"
sessionCodeAWS track prefix + level — e.g. ARC301, BOA208
slideCount8 · 10 · 12 · 16 · 20
diagramApproachdrawio (default) · architecture-diagram · slot
techVsBusinesstech · business · mixed — drives image+text discipline

Workflow

  1. Lay the agendaSkill states the 12 slide types in order, in plain prose, before writing any slide content.
  2. Drop the frameworkassets/template.html copied verbatim — never re-author the scale-to-fit / keyboard / print logic.
  3. Plan the diagram budgetFor every architecture page, queue a drawio call (or architecture-diagram); save SVG to assets/diagrams/.
  4. Fill slidesPaste the matching skeleton from references/layouts.md; replace every [REPLACE] with real copy.
  5. P0 checklist + 5-dim critiqueRun references/checklist.md; score philosophy / hierarchy / execution / specificity / restraint.
  6. EmitSingle <artifact> wrapping the canonical deck HTML. Save → PDF emits a 16:9 multi-page PDF.

# Studio365 Local Bootstrap

This folder contains the local bootstrap tracking files for Studio365.

Files:
- `task_queue.csv` — ticket queue tracking
- `run_log.csv` — step/run audit log
- `install_status.csv` — installation plan and verification status
- `incident_log.csv` — incident capture and retry information

Use this folder for the initial setup workflow only.
Start with `docs/studio365-local-bootstrap.md` and keep the first phases local-first.

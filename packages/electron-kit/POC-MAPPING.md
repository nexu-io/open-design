The complete allowed Electron/Closure surface is the exported endpoint registry: one bootstrap handoff, seven shared-lifecycle operations, one non-authoritative feedback observer, and four Shell-updater operations. The fixture Sidecar uses correlated IPC only for the updater subset and runs under the verified official Node carrier, never Electron-as-Node. Placeholder rendering, presentation/focus, activation receipts, installer execution, and `od://` routing are Shell/Electron-internal and cannot add Closure messages.

## Current substitution seam

`ElectronFixtureBootstrapPort` and `ElectronFixtureLifecyclePort` are readiness-preserving stand-ins until the upstream Closure task is ready. Replacing them must not change `shells/electron/src/main.ts` beyond adapter construction, must retain the endpoint registry, and must not move update execution into Closure. Signing/notarization, publication policy, real candidate shell identity from release metadata, and native Windows refinement remain outside this local macOS foundation proof.

The concrete cold-start/warmup graph is declared by `shells/electron/warmup.json`. electron-kit validates dependency order, drives blocking/background lifetime, timeout, cancellation and progress projection, and supplies the Standalone/carrier atoms. The Shell owns labels and renderer behavior. The fixture placeholder's HTML, protocol response and DOM readiness acknowledgement therefore live under `shells/electron/src/renderer/`, not electron-kit.

`openElectronSidecarControl` is the future desktop handler seam. It cannot be constructed without a validated Sidecar session and an exact finite topology/binding match. The current phase-one lifecycle fixture deliberately does not instantiate it: that fixture has no public desktop Sidecar readiness or product message contract, and inventing one here would create replacement debt. Once the upstream adapter is ready, `shells/electron` will load its concrete handler topology from JSON, import the product protocol normalizer, and bind Shell executors through this unchanged lease.

## Loop Engineering 自动修复循环 — 完整实现

为 Open Design 的 Critique Theater (设计评审团) 实现了 Loop Engineering 自动修复循环功能。

**核心功能**: 当用户启用设计评审团时，如有评审问题（mustFix > 0 或 composite < threshold），自动触发修复-重审循环，直到达标。

**实现文件 (8 个)**:
1. `loop-engine.ts` (17KB) — 循环引擎：startCritiqueLoop(), extractFeedback(), 收敛/重试判断
2. `orchestrator-loop.ts` (9KB) — 桥接层：runOrchestratorWithLoop(), formatFeedbackAsPrompt()
3. `config-loop.ts` (5.5KB) — 环境变量配置解析 (OD_CRITIQUE_LOOP_*)
4. `persistence-loop.ts` (6.7KB) — SQLite 持久化 (critique_loops, critique_loop_iterations)
5. `metrics-loop.ts` (3.3KB) — Prometheus 指标
6. `critique-loop.ts` (7.9KB) — 契约类型 (LoopEvent, CritiqueLoopConfig)
7. `loop-engine.test.ts` (10.7KB) — 单元测试
8. `INTEGRATION.md` (8.5KB) — 完整集成指南

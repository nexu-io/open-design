# Component Guide

Use the components already defined in `assets/template.html`. Do not invent new class names unless the template is updated in the same artifact.

## Core Classes

- `.slide`: one 1920x1080 slide.
- `.hero`: high-impact cover, divider, or closing slide.
- `.light` / `.dark`: theme intensity.
- `.chrome`: magazine-style page label.
- `.kicker`: short local cue above a heading.
- `.h-hero`, `.h-xl`, `.h-md`: display headings.
- `.lead`: large supporting paragraph.
- `.frame`: layout container.
- `.frame-img`: stable image frame.
- `.stat-card`, `.stat-nb`, `.stat-label`, `.stat-note`: big-number cards.
- `.pipeline`, `.step`, `.step-nb`, `.step-title`, `.step-desc`: process layouts.
- `.callout`, `.callout-src`: highlighted editorial note.

## Typography

- Display headings: serif.
- Body and captions: sans-serif.
- Metadata, labels, counters: monospace.
- Keep button, tab, and chrome labels small but readable.

## Icons

Use Lucide line icons or simple inline SVG. Do not use emoji icons.

# Quality Checklist

Use this checklist before delivering a Magazine Web PPT deck.

## P0 Must Pass

- The deck uses English only unless the user supplied exact quoted source text.
- The copied `template.html` has a real `<title>` and no placeholder labels.
- Every class used by pasted layouts exists in the template stylesheet.
- Slides use the intended scale-to-fit framework and do not overflow the viewport.
- Major headings use display/serif treatment; body copy uses sans-serif; metadata uses mono.
- Images use stable containers with `object-fit: cover` and `object-position: top`.
- No emoji are used as content icons.
- No generic purple-gradient hero, fake metrics, filler text, or placeholder lorem ipsum.

## Rhythm

- Hero and body slides alternate enough to avoid visual fatigue.
- No more than three slides in a row share the same visual intensity.
- The first slide establishes topic, audience, and tone.
- Each act divider has a clear narrative purpose.
- The closing slide gives one memorable takeaway or next action.

## Layout

- Use standard ratios: 16:10, 4:3, 3:2, 1:1, or 16:9.
- Avoid `align-self: end` on image frames.
- Avoid thick borders and heavy shadows on images.
- Keep slide chrome consistent: page number, section label, and source note.
- Use fixed-height image grids when multiple images need comparison.

## Content

- Every slide needs a specific job: hook, context, proof, mechanism, comparison, decision, or close.
- No invented statistics. Use marked assumptions or omit the number.
- Keep slide copy short enough for presentation use.
- Use one terminology set throughout the deck.

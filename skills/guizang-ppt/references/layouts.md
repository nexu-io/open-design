# Layout Guide

Use these layout roles to plan the deck. The exact HTML may be adapted from `assets/template.html`.

## Recommended Arc

1. Cover
2. Problem or tension
3. Context
4. Evidence
5. Mechanism
6. Comparison
7. Operating model
8. Decision or takeaway
9. Close

## Layout Roles

- Cover: title, subtitle, metadata, strong theme signal.
- Act Divider: short section title with a visual reset.
- Big Number: one metric, one claim, one footnote.
- Quote + Image: editorial statement paired with evidence.
- Image Grid: 2-4 images with captions.
- Pipeline: steps, sequence, workflow, or operating model.
- Before / After: contrast old state and new state.
- Big Quote: one memorable line.
- Lead Image + Side Text: dense visual evidence plus explanatory copy.
- Closing Question: one final prompt or decision.

## Rules

- Match layout density to talk length.
- Use fewer slides for reflective decks and more slides for technical decks.
- Keep each slide to one dominant idea.
- Repeat chrome consistently.

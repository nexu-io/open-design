# 主题色预设（Themes）

4 套商务 PPT 主题色板。**所有页面统一纯白背景 + 深灰文字**，主题色差异仅体现在 accent 色上。

---

## 使用方法

1. 从 4 套中选一套（或基于内容推荐）
2. 打开 `index.html` 的 `<style>` 块
3. 找到开头的 `:root` 块
4. **整体替换**色值
5. 其他 CSS 都走 `var(--...)`，无需任何其他改动

---

## 1. 深蓝商务（默认）

**适合**：汇报/路演/融资 BP/任何正式场景的安全默认
**Accent**：深蓝色

```css
--bg:      oklch(100% 0 0);
--bg-rgb:  255,255,255;
--surface: oklch(97.5% 0.003 240);
--fg:      oklch(35% 0.01 60);
--fg-rgb:  51,51,51;
--muted:   oklch(55% 0.015 240);
--muted-rgb: 100,116,139;
--border:  oklch(92% 0.005 240);
--border-rgb: 226,232,240;
--accent:  oklch(30% 0.08 250);
--accent-rgb: 10,31,61;
```

## 硬规则

- 一份 deck 只用一套主题色，不要中途换色
- 所有页面背景统一纯白，不允许黑白交替
- Accent 色用于：标题强调、数据高亮、边框/分隔线、渐变卡片
- 可引入辅助色（成功绿/警告橙）用于正负指标标记
- 禁止紫色/紫色渐变（AI-slop 最常见的错误）

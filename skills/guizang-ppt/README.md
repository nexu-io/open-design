# Magazine Web PPT

An English-only editorial deck skill for OneShot Design. It generates single-file HTML slide decks with horizontal navigation, magazine-inspired composition, restrained texture, and export-ready 1920x1080 slides.

The original upstream project is [`op7418/guizang-ppt-skill`](https://github.com/op7418/guizang-ppt-skill). This bundled copy keeps the original license attribution but uses English instructions and examples for the OneShot Design repository.

## Best For

- keynote-style launch decks
- founder talks
- product narratives
- editorial pitch decks
- high-polish web PPT exports

## Not For

- dense spreadsheet decks
- long training manuals
- collaborative slide editing
- dashboards or app prototypes

## Files

- `SKILL.md`: agent-facing workflow.
- `assets/template.html`: runnable HTML deck seed.
- `assets/example-slides.html`: preview deck.
- `references/styles.md`: direction guide.
- `references/themes.md`: theme presets.
- `references/layouts.md`: slide layout guide.
- `references/components.md`: component guide.
- `references/checklist.md`: quality checklist.

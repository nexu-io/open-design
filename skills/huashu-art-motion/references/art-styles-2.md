# 20_dunhuang · 敦煌壁画（莫高窟·盛唐）

> 来源：迁移测试 A（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/20_dunhuang.js`。

实验时的文件名 `scenes/04_dunhuang.js`（215 行）。0.45↔0.9s 为 6.6%，相邻帧中位 1.98%。

**管线**
土红地仗（缓存）：`P.texture #a5452f`、dark `#7a3020`，加稀疏褪色团花，顶部卷草边＋三角垂幔（青绿白红交替＋金珠）→ 窗＝石青天：祥云、飞天 → 卷草纹窗框 → 莲花砖地（缓存）→ 壸门低案、油灯 → 猫 → 少女（唐代供养人）→ 热气卷云 → 天花 → 罩层。

**线与色**
- 铁线描：等宽 2.6px，色 `#5a2414`。脸用更红的 `#8a3a24`。
- 矿物色：土红 `#a5452f`、石绿 `#3f8f6e / #6ab08e`、石青 `#2f5f8f / #5a86b0`、白 `#ecdfc4`、金 `#d8b05a`。

**唐装**
- 间色裙：红底，斜梯形绿条，每 44px 一条，向下随 x 发散。
- 石青短襦、白交领、高腰红带。
- 高髻：在 headTop 上方叠两个椭圆，加金钗和三朵簪花。
- 面妆：花钿（额头四瓣红花）、斜红（太阳穴一道红弧）、点唇、蛾眉。
- 茶盏是越窑青瓷。

**披帛 `shawl(pts,w)`**
- 行波点列 → ribbon，加白色虚线描花和红点。
- 背后一段：`x = back + 230q + 64q·sin(4.2q − 5.5t)`，末端 30% 向上扬。
- 前段绕臂垂下。
- 坑：第一版横向摆幅只有 18–34px，又几乎竖直，看起来像椅子的竖杆。横向位移要到 200px 以上，加上末端上扬，才读得出是飘起来的帛。

**飞天**
- 横卧朝左，1.35 倍，以 300px/s 飞过窗。
- 三条飘带做行波，其中一条从肩起弧过头顶再甩到身后，这条大弧是飞天最有辨识度的形。
- 头光、发髻、托花盘。
- 祥云是圆团＋渐细云尾，以 40–76px/s 漂。

**罩层（做旧）**
- 整体 `saturation` 混合 α.3 褪色，再 multiply 一层浅土纹理 α.5。
- 逐像素剥落：`fbm(x·.0032)+0.12·noise(x·.03) > 0.3` 处露出白灰地仗 `#d8c6a2`，0.28–0.3 是剥落边缘的暗线。
- 两张脸附近设为保护区，不剥落。
- 500 条龟裂随机游走，顶部 380px 烟熏渐变。
- 坑：
  - 剥落噪声频率用 .006 时，出来的是满屏芝麻斑，像污渍。降到 .0032 并提高阈值后，才是一块块的剥落。
  - 终版把猫 (380–720, 530–920) 和少女 (1070–1530, 240–950) 都设成保护区，只剥背景。
  - 斜红 α 降到 .32，否则像伤疤。
  - 飞天的头光第一版是实心绿圆，读成「游泳圈」，改成 α.28 半透明加细线。
  - 猫用 `#c8843a` 时，叠上褪色就成了褐黄色，改成 `#e08a3a`；再加 `look: sin(2.6t)` 转头，呼吸加大 2.5 倍，不然整段只有尾巴在动。

**母题动画**
- 天花：30 片四瓣花，旋转并翻面下落。
- 油灯：火苗 `1+0.12sin(17t)+0.08sin(29t)` 跳动，加光晕。
- 颜料片：10 片从剥落边缘脱开，翻转、抛物线下落。
- 猫的项圈小铃摆动。

# 21_kusama · 草间弥生无限波点

> 来源：迁移测试 A（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/21_kusama.js`。

实验时的文件名 `scenes/05_kusama.js`（124 行）。0.45↔0.9s 为 17.3%，相邻帧中位 2.98%，JS 侧 4–28ms。

**蠕动的点**
- 所有点的半径乘同一个「从猫出发的行波」：`wave = 0.82 + 0.28·sin(dist·0.012 − 6t)`。
- 整个房间的点从猫的位置一圈圈胀缩，像在呼吸。这一个函数就让全屏都活了。

**点的布置**
- 墙：大点（30px，间距 104）＋小点（10px，错位）两套六角网格，各带 ±25–50% 抖动。每个点是轻微椭圆加随机转角，像手画的。
- 地板：9 行，越近越大（6→28px）、越疏，压成 0.42 的椭圆做透视。
- 红裙白点 13px、间距 52，按 46px/s **顺着裙子往下爬**（clip 到裙子剪影，y 偏移取模）。
- 猫：橘色区白点、白色区红点，各自往下爬。
- 脸颊上也画了一个红点（草间的身体彩绘），头上是红底白点蝴蝶结。

**无限镜屋（窗）**
- 3D 格子灯：13×7×3，6 色。z 以 0.3/s 循环飞向镜头，透视投影 F150。
- 每颗灯是实心小核加 3.2 倍光晕，lighter 叠加。
- 坑：第一版灯随机散布、光晕很大，糊成了散景。规则格子＋小实心核才有镜面无限重复的感觉。

**黄南瓜**
- 5 瓣椭圆，绘制顺序是外 → 内。
- 每瓣按行排黑点：中列最大（9.5px），向两边、上下都缩小，点的大小也跟着行波变。
- 整体呼吸：缩放 `1 ± 0.025·sin(5t)`，以底部为轴。

**结尾「自我消融」**
- lt 1.0–1.26：红色覆盖层渐显，全屏 120px 六角点阵从猫的位置一圈圈胀到 0.47 倍间距。之后约 0.15s 只剩点阵在轻轻呼吸，给结尾一个落点（审片指出第一版没有停留帧）。
- 最后一帧停在红底白点的点阵上。
- 坑：第一版让点无限胀大，结果是白屏。半径必须封顶，最后停在点阵，不能停在纯色。
- 坑：裙子和墙都是红底白点，少女在画面里会溶解掉。终版把少女轮廓线加到 4.5px，猫白色区域的红点去掉，保住橘白分界。

# 22_constructivism · 1924 俄罗斯构成主义海报（罗德琴科 / 李西茨基）

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/22_constructivism.js`。

实验时的文件名：`scenes/c1_constructivism.js`（约 175 行）。每帧中位 5ms；帧差 3.6%。

**管线**
1. 底版全缓存 `cs_bg`：米白旧纸（`P.texture` `#e9dfc4`，dark `#d9c9a4`）→ 左侧斜黑条（rotate −0.5）、红方块（rotate 0.26）、5 行「正文」黑条 → 右侧细斜线、红圆点、黑竖条里竖排几何字「ЧАЙ」→ 人物头后大黑圆（中心 (1330,395)，r 215）→ 斜红地面 (0,905)→(1920,856)，上沿一道 12px 黑线 → 窗 → 黑桌（红边、斜撑）→ 黑块凳。
2. **窗＝照片拼贴**：先在离屏画灰度「照片」（天空渐变 `#5e5e5e→#e8e8e8`、径向白云、暗色厂房剪影、烟囱），再用 `halftone()` 网点化（cell 7，gain 0.8）；舒霍夫塔用清晰黑线画在网点上面（五节双曲面，每节两组各 18 条直母线，相位差 ±1.1rad，背面 sin<−0.2 的省掉），这正是「照片＋手绘」拼贴。
3. **皮肤＝网点照片**：脸、颈、手先画灰度渐变（前亮后暗，`#fafafa→#9c9c9c`）到离屏，再网点化（cell 4.6、gain 0.74、45°）。网点下垫米白，外圈先描 7px `#fbf7ea`，这一圈就是照片剪下来的白边。五官用清晰黑笔补，嘴唇手工上红。衣服全是剪纸平涂＋3px 黑线；阴影用 `shadeDots()`，在路径内按函数落网点。

**关键函数**
- `halftone(c, src, bx,by,bw,bh, cell, col, gain, ang=π/4)`：在旋转网格上采样 src 灰度，点径 = cell·gain·√(1−L)，只落在 alpha>128 处。**所有点并成一条 path、只 fill 一次**。脸部约 3000 点，耗时 <2ms。
- 几何西里尔字：5×7 模块，每个字母是若干矩形或多边形（Й 的斜笔是四边形，短音符是上方一个小矩形）。**每个部件单独 fill**。

**母题动画**
- 李西茨基红楔刺入黑圆：顶点沿 0.34rad 轴线往返，`70·(0.5−0.5cos(2π·1.6·lt))`。
- 黑圆外的红虚线环：dash [46,22]，`lineDashOffset = −260·lt`。
- 塔顶无线电波：4 道红弧，`r = 18 + ((1.4lt + k/4) mod 1)·230`，α 和线宽随相位衰减。
- 地面标语「ПЕЙТЕ ЧАЙ!」：逐字盖章（第 k 个字在 0.045k 秒起跳，0.12s 内从 1.5 倍缩回 1），之后整排波浪跳 `−10·max(0, sin(11lt − 0.8k))`；每第 4 个字是黑字。
- 头巾两条尾巴 `sin(9lt)·6` 轻摆；杯上热气是三条黑折线上行。

**角色**：共青团少女——红头巾（头部局部 13 点，前沿后移到能露出金色刘海，颈后打结两条三角尾）、白衬衫＋红领巾三角＋红袖口、深灰长裙（网点阴影）。猫用剪纸橙 `#e2741c`＋米白，10px 黑条纹，尾巴用虚线描边做虎斑，眼睛是方瞳竖条。

**色板**：纸 `#e9dfc4`；红 `#c8231c`／`#8f1711`；黑 `#151311`；米白 `#f4ecd6`；金发 `#e3b03e`／`#a87a1c`；猫橙 `#e2741c`。

**坑**
- 「Й」的短音符第一版画在字格上方（y=−1.7u）：竖排时被上一个字母盖住，地面标语里被裙摆盖住，审片读成「ЧАИ」。改成整个字画在 7 格内（И 部分下移 1.7 格），标语也改到角色之上画（海报字压人物）。
- 「А」第一版用两条反向斜腿＋横杠拼在一个 path 里，重叠处被 nonzero 抵消，竖排时读成「В」。改成逐部件 fill。
- 地面标语第一版基线压在 y=1060，字的下半截出画。按 `translate(x, 990)` 以字中心定位。
- 颧下阴影第一版太重，网点化之后像一片胡子。灰度源里的阴影 α 要比平涂时低一半。

**仍可改进**：罗德琴科更典型的是「人物照片＋喇叭形文字锥」。可以把热气换成从杯口放射出的红黑楔形字锥。

# 23_dali · 1931 达利超现实主义（《记忆的永恒》）

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/23_dali.js`。

实验时的文件名：`scenes/c2_dali.js`（约 235 行）。每帧中位 47ms（首帧 84ms）；帧差 4.6%。

**管线**
1. 底版拆成三张缓存，因为影子必须夹在中间：`dali_bg`（天、海、岩、地）→ 每帧画影子 → `dali_wall`（开窗的断墙残片＋枯枝）→ `dali_block`（石块桌＋凳）→ 软钟 → 角色。
2. **体积填色 `vol(c, path, x0,y0,x1,y1, a, b, occl, blur)`**：线性渐变填充，再在 clip 里用 shadowBlur 描一圈暗边做内阴影。全片无勾线，学院派的圆润感全靠这个。
3. **长影子**：把每个物体的剪影用剪切仿射投到地面，`setTransform(1, 0, −kx, ky, kx·yg, yg·(1−ky))`，yg 是该物体的着地线（墙 700、桌/猫 905、人 930）。所有剪影先画进一张离屏（纯黑），再整体以 α 0.55、blur 1.5px 叠上去，避免影子重叠处加深。用 clip 只留地面部分（y > 594）。`kx = 0.85 + 0.6·easeInOut(lt/1.2)`，影子在 1.2s 里明显变长。
4. **软钟 `softMap(o, sag)`**：圆盘局部坐标 (u,v) → 屏幕。v ≤ fold 的部分躺在台面上（y 压缩到 0.28–0.32）；v > fold 的部分垂下：`X = cx + u·(1 − flare·q)`，`Y = … + d·(0.62 + 0.3·sag) + 中央下垂高斯 + sin 波纹`。外框、表盘、12 个刻度、两根指针（沿映射采样成软线）、折线高光**都走同一个映射**。

**关键参数**：`flare = −0.12`，负值让垂下部分像软布一样往外摊开，下缘是圆的；正值会收成冰淇淋筒。drip 0.18–0.4。sag 在 1.2s 内从 0.1 → 1.4：第一版 0.35→1.0，审片说「钟没有明显在淌」。三只钟：窗台 R72、桌沿 R88、枯枝 R64（fold −34，大部分垂下）。指针转速 4.5–6.5 rad/s。

**母题动画**：三只软钟持续下垂、指针以不同速度转；地平线上的高跷象（四条细腿相位差 π/2 交替迈步，膝关节 0.52 高度处微弯，身体 14Hz 微颠，背驮方尖碑）每秒左移 70px；9 只蚂蚁绕橙色怀表做椭圆爬行；长影子变长；猫尾巴软化下垂（尾尖 y + q²·34）。

**角色**：西班牙少女，浅蓝长裙＋白翻领，金发髻，无勾线，体积靠渐变＋内阴影，五官是暗褐细线。猫用渐变橙，条纹用 blur 2px 的半透明笔（柔），眼睛用径向渐变；白胸改用平滑椭圆 (606,768) 40×92，不用 `K.white`。

**色板**：天 `#22407c → #5f88bd → #e9dcae`；海 `#8aa6b8 → #4f6f86`；岩 `#e8c27a / #9a6a34`；地 `#d2ad70 → #7a5129`；墙 `#f4ead2 → #cdbf9f`；钟金 `#f0d27c / #9a7426`，表盘 `#f6efd6`。

**坑**
- 影子第一版往观众方向投（ky>0 向下），全被画框底边吃掉。太阳要放在左前方低空，影子往右后方躺（y′ = yg − ky·(yg − y)）。
- 影子是投在地上的，必须画在墙和桌子下面，所以底版要拆层，不能一张缓存到底。
- 软钟 flare>0 加大 drip，就是冰淇淋筒。
- 这个计数器底色是深蓝天，原来设的深褐色字看不见，改成米白字＋深色投影。

**仍可改进**：人物还是偏矢量插画，可以加更细的高光和暗部反光；《记忆的永恒》里那个侧卧的软体「自画像」生物可以作为第四个母题。

# 24_hopper · 1942 霍珀美国现实主义（硬光块面）

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/24_hopper.js`。

实验时的文件名：`scenes/c3_hopper.js`（约 150 行）。每帧中位 13ms（首帧 54ms）；帧差 6.0%。

**核心手法「双版本裁切」**：同一个 `room(g, K)` 函数按两套色画两张缓存——背光版 `SH`（冷绿墙 `#5d8679`、暗地板 `#5b3d2b`）和受光版 `LT`（暖黄墙 `#efcf8f`、亮地板 `#c98b52`）。每帧先画背光版，再用会移动的光斑多边形 clip 进受光版，光影边缘天然是硬的，还能整体平移。人物和家具同理：`girl(c, K, G)` 用背光色画一遍，再 clip 进斜光带用受光色画一遍。

**光斑几何**（dx = 30 − 95·easeInOut(lt/1.25)，1.2s 里左移约 95px）
- 墙上光斑 WP：(1420+dx, 250) → (1920, 470) → (1920, 730) → (1420+dx, 730)
- 地上光斑 FP：接在墙光斑下面，往右下方展开
- 人物光带 OP：左缘从 (1345+dx, 0) 到 (1185+dx, 1080)。光边在这一段里扫过少女的脸，从半脸背光到全脸受光
- 窗棂影：竖条 24px ＋ 一条平行于光斑上沿的斜条
- **人在墙上的投影** = 人物剪影平移 (+150, +18) 后画进离屏，`source-in` 填进背光底版，再画回光斑区域。效果就是光斑里透出背光墙，和人物姿态同步。

# 25_ghibli · 1988 吉卜力式手绘水彩背景美术

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/25_ghibli.js`。

实验时的文件名：`scenes/c4_ghibli.js`（约 270 行）。每帧中位 17ms，**首帧 619ms**（水彩底版缓存）；帧差 5.1%。

**水彩渲染器**
- `deform(pts, depth, amp, r)`：中点位移。每轮在每条边中点沿法向推一个近似高斯量（3 个均匀数相加），幅度和边长成比例（min(1, len/80)），每轮 amp×0.6。
- `wash(g, pts, color, {layers, alpha, amp, seed, edge, blend, fill})`：先 deform 3 轮得到基形；每层再 deform 2 轮，用 `multiply` 低 α 填充（透明颜料叠色），并以 α=edge 描一圈 1.6px 同色边。描边逐层叠加，就是颜料在边缘沉积的**水痕边**。fill 可以传渐变（天空、墙）。
- 常用参数：大面积墙 layers 5、α 0.4、amp 12；色晕 layers 3、α 0.045、amp 40（大幅变形）；木板 layers 3、α 0.5、amp 3、edge 0.14；不透明的白（窗框、桌布、云）用 `blend:'source-over'`、α 0.9–0.95。
- 墙 = 径向渐变洗染（窗边亮 `#fbf3e0` → 角落 `#dcc49a`）＋ 28 块大幅变形的透明色晕（暖黄、粉、蓝灰、浅绿交替）＋ 两角暗晕。护墙板和地板**逐块**换色调洗染。最后 `multiply` α 0.3 叠一层高频纸纹颗粒。
- 云：白色不透明圆团（16 个 puff，用 wash 画边）＋ `source-atop` 叠底部蓝灰渐变，缓存成精灵。大樟树也是精灵，绕树根转 ±0.025rad。

**赛璐璐角色 `cel(c, p, base, shade, dx, dy)`**：先整块填阴影色，再在 clip(p) 里把自身朝光平移 (−dx, −dy) 后填基色，只剩背光侧一道月牙阴影。最后描 2.4px 暖褐线 `#4a3428`。一个函数就是吉卜力式的两色赛璐璐。

**母题动画**
- 白纱窗帘：两幅，下摆鼓起 `q²·(90 + 70·gust)`，gust = 0.55 + 0.45·sin(3.2lt + 相位)，再叠 `sin(7lt + 6q)` 小波纹；3 层半透明 wash，固定种子，所以边缘不沸腾。
- 窗外 360 根草叶：风是一阵一阵的，`wind = 0.5 + 0.5·sin(3.1t − 0.018x)`，相位沿 x 推进，看得出一道风浪扫过草坡。
- 云飘 22–30px/s；树冠轻摇；墙上 34 个 komorebi 光斑（`screen` 暖黄径向渐变，位置用 noise 漂，亮度 `sin(5t + 1.7i)` 闪）；桌上雏菊点头；少女长发被风吹向右后（7 点 smooth，wind 推动）；红蝴蝶结飘带抖动；桌布垂边摆动。

**角色**：长金发＋大红蝴蝶结（致敬魔女宅急便，不复制角色）、青色长裙＋白围裙＋白袖口；猫是暖橙＋米白赛璐璐。背景里靠墙的扫帚是彩蛋。
**角色的水彩填色**：审片说「背景像，人物不像（扁平矢量）」。把角色先画进离屏 L，另起纹理层 M（纸纹颗粒 α 0.8 ＋ 40 块透明色晕 `charBloom`，α 0.1、amp 16），M 用 `destination-in` 按 L 的剪影裁掉，再以 `multiply` 叠回画面。线色从 `#4a3428` 调软到 `#6a4a38`。
**窗帘**：审片说不飘。gust 频率 3.2 → 5.4，鼓起 `q²·(60 + 150·gust)`。

**坑**
- 色晕 α 0.07×4 层、颗粒 multiply 0.5 时，墙面像发霉的旧羊皮纸。吉卜力的房间是亮的：色晕 α 降到 0.045×3 层，渐变整体提亮一档。
- 第一版用两个矩形 wash 拼墙（右侧更暗），x≈1100 出现硬接缝。暗部要用大幅变形的多边形（amp 60），不能用矩形。

**仍可改进**：人物还是平面，可以加吉卜力式的发丝高光块；地上的光斑里可以加窗帘影子的流动。

# 29_seurat · 1884 修拉《大碗岛的星期天下午》（点彩：视觉混色渲染器）

> 来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/29_seurat.js`。

实验时的文件名：`scenes/k3_seurat.js`（136 行）。每帧约 100ms，帧差 7.4%（静穆，相邻帧均差 0.45）。

**渲染器（重点，可抽进 paint.js）**
1. 整幅平涂底稿，角色也包含在内（每帧 ~3ms）。底层铺一遍 `blur(4px) saturate(.85) brightness(1.06)` 的底稿，当打底色，点与点之间的缝会露出它。
2. **固定六角网格，点等大**：pitch 10、行距 8.66、r 4.5，每个点有 ±1.2px 的静态抖动。约 2.4 万个点。按颜色把点攒进 21 个 Path2D，每种颜色只 fill 一次。
3. **视觉混色取色**：21 色纯色板。
   - 14 个饱和色：`#1a2058 #2a3a9a #3f6fd0 #6aaee6 #1f6a52 #2f9a5a #a8c83a #f2cf3a #f08a2a #e0432a #c0306a #7a4aa8 #f8f4e8 #e8b48a`
   - 7 个淡色（修拉的「和白混过的色」）：`#f6e49a #f6c48a #cfe08a #b0cff0 #f2b8c8 #c99a4a #9a7ac8`
   - 对每一对 (i,j)，把目标色**投影**到线段 Pj→Pi 上，得到连续比例 w，clamp 到 [.2,.8]。距离再加上 `0.004·|Pi−Pj|²`，惩罚相差太远的配对，免得用黑白点混出灰。取距离最小的一对；每个点按 `hash(i,j) < w` 决定用 Pi 还是 Pj。
   - 结果按 15bit 量化色缓存进 Map。
4. **取色前给目标色加 ±20 的哈希抖动**（R+dj、G+0.8dj、B−0.6dj）。配对色的切换边界因此变成交错的点，不会出现竖向色带。
5. **补色点**：8% 的点换成对比色（蓝↔橙、绿↔红紫、黄↔紫……共 21 条映射）。**光渗**：和右下方 14px 处比较，亮度差 >45 时，45% 的概率在亮侧放白点、暗侧放深蓝点。
6. **修拉自己画的边框**：四周 28px 深蓝带，也过点彩渲染，所以带里会出现橙色补色点。

**母题动画**：
- 窗内塞纳河：帆船漂（40px/s）、汽船冒烟、撑伞女士的侧影＋小猴。
- 河面的点 6fps 重掷哈希＝波光。
- 室内一只橙红蝴蝶绕桌上方飞（`sin(2.6t)·120`），扑翅 `|sin(20t)|`。
- 6fps 让 7% 的点换成配对色，表现光在点之间颤。第一版用 4fps/3%，独立审片判「基本定格」（相邻帧均差 0.1–0.2）；改成 6fps/7% 后升到 0.45。

**角色**：1880 年代深蓝紫长裙＋腰后裙撑（`back` 钩子里一块弧形）＋白高领＋橙色纽扣＋小圆帽配红羽毛。椅背上靠一把收拢的红阳伞。
**坑**（两个都是渲染器层面的）
- 偏好单一纯色（加了惩罚项）会把渐变墙切成几条竖色带。
- 比例换成连续值以后，配对色在边界整列切换，还是会出带。要靠第 4 步的目标色抖动解决。
- 第一版色板里没有淡色，亮墙被分解成白＋肤色＋零散蓝点，看起来像雪花噪声。

# 30_matisse · 1947 马蒂斯《爵士》剪纸

> 来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/30_matisse.js`。

实验时的文件名：`scenes/k4_matisse.js`（167 行）。每帧约 25ms，帧差 9.3%。

**构图**：墙＝《波利尼西亚》双蓝棋盘（`#1d4fb8 / #4f95dc`，每格 240×236 剪纸块），窗＝《伊卡洛斯》（钴蓝底、黑人形、红心、黄星），地＝翠绿 `#1f9a5a` 加黑踢脚条，桌面是黑剪纸，椅子是黄剪纸。

**手法**
1. **剪刀折线 `cut(pts)`**：沿轮廓每 14–24px 取一个点，加 ±2–2.5px 种子抖动，点与点直线相连。自己生成的形状一律这样处理。
2. **海藻（关键）**：一根锥形茎，加 2×lobes 根左右交替的**圆头胶囊手指**。手指角度 `±(1.05−0.55u)`，长 `width·(1−0.45u)`，宽 `width·(0.34−0.12u)`。所有子路径 `addPath` 进同一个 Path2D，用 nonzero 一次填充，得到并集，投影也只算一次。**不要用「沿脊线调制宽度」**：第一版这样做，出来的是毛毛虫和 Z 字闪电。
3. **RIG 角色手剪边**：RIG 不给点列，所以角色层整层做像素位移。静态位移场是 `fbm(0.028x, 0.028y, 2)·9`，dx、dy 各一套，只处理 bbox (330,470)-(1600,980)，约 15ms。
4. **纸的投影**：shadow 偏移 (5,6)、blur 4、`rgba(10,20,40,.3)`，表现钉在墙上的纸。
5. **水粉刷痕**：缓存 2600 道长条笔痕（60–300px、宽 6–22、黑白各半、α .04–.13、倾斜 −0.25rad），整幅 `overlay`。

**母题动画**：
- 海藻像纸片一样绕根部摆 `sin(2.8t+φ)·0.13`，卷边用 `scaleX 0.93–1.0` 呼吸。
- 伊卡洛斯：7 颗不规则黄星，转着闪（scale `.82+.22sin(7t+1.9k)`）；黑人形上下漂；红心跳（`1+.18·max(0,sin 9t)`）。
- 两只白鸟扑翅（scaleY `.55+.45cos 13t`）。
- 一片粉纸翻飞落下（scaleX=cos 6t）。
- 热气是两根白色小剪纸。

**角色**：马蒂斯《罗马尼亚衬衫》。白宽袖衫，前襟一条钴蓝刺绣带（红黄交错的小三角），袖上随手臂旋转的红/蓝刺绣横带（clip 在 upperArm 里），红长裙＋黑腰带，金发是 5 个剪纸卷团。五官只用剪纸碎片：黑杏仁眼、红唇三角、粉腮圆片。
**坑**：飘落的纸片第一版轨迹划过少女的脸，改到左墙。计数器底下垫一张白剪纸片，否则黑字压在钴蓝上看不清。

> 来源：迁移测试 C（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/31_haring.js`。

- 窗里的光芒宝宝：白色并集剪影，两帧交替爬；14 根光芒，长短 8fps 交替。

- 桌上方的红心，跳动并带放射线。

**角色**：80 年代纽约少女。宽大红毛衣（下摆一道罗纹线）、牛仔蓝长裙、白高帮球鞋。脸上只留一个眼点和一道红唇（哈林的人物本来没有五官，留这一点是为了认人）。耳朵的粗黑圈看起来像随身听耳机，正好合年代。

# 32_rembrandt · 1642 伦勃朗明暗法

> 来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/32_rembrandt.js`。

实验时的文件名：`scenes/r1_rembrandt.js`，每帧约 47ms。

**管线**：亮态底稿（按"全亮"时的颜色画房间、铅条菱格窗、土耳其桌毯）→ 褐色大笔触重画背景，再糊 2.2px 叠 75%（揉开的底子）→ 桌毯单独一层、细笔触 → 角色平涂＋体积渐变＋细笔触 → 角色"失边"处理 → **光照图 multiply** → 窗玻璃 screen 提亮＋云影掠过 → 鬃毛厚涂 → 烛焰、光柱浮尘、热气 → 龟裂、颗粒、暗角缓存层＋soft-light 金褐釉。

**关键参数**
- 光照图：底色 rgb(30,21,13)，相当于环境光 0.13。用 lighter 叠：
  - 光柱：楔形多边形，模糊 40px，缓存，α 0.8–0.95。
  - 窗本身：r330。
  - 脸池：r250 α0.95。胸：r230 α0.55。猫：r240 α0.8。桌面：r280 α0.6。
  - 烛光：r190+40·fc，α 0.6+0.4·fc。
  - 少女背后墙面的"分离光"：r300 α0.35。伦勃朗常在人物暗侧后面把墙打亮，好把人从背景里分出来。
  - 叠完整幅 multiply。
- 摇曳：`flick(t) = 0.5·noise(2.2t) + 0.25·noise(6.5t)`；光池中心随 noise(0.9t) 漂移 ±14px；云影 `cloud = 0.5 + 0.5·sin(2.2t − 0.6)` 让窗光 ×(1 − 0.35·cloud)，同时一团暗色径向斑以 260px/s 横穿玻璃。
- 背景笔触：cell18、len54、w16，jitter 6，角度 −0.9 + 1.6·noise(0.003)；色板 mixBase 0.7。
- 失边：角色层先 blur(2.4px) 全不透明画一遍，再叠 α0.62 的清晰层。暗侧会融进背景，五官还认得出。
- 厚涂（鬃毛笔）：一笔 = round(w/1.3) 条平行细鬃，每条亮度 ±17、两端随机缩 0–25%、线宽 1.4–2.6；下侧一条 α0.28 的投影；上侧撒 2+w/3 个亮点。只用在受光处：金发、领口、瓷杯、珍珠、猫白胸、猫头顶。
- 罩层：龟裂 α0.28×0.28；颗粒 density 0.05 α0.12；暗角 0.75；soft-light rgba(200,140,60,.35)。

**母题动画**：烛焰（noise 驱动左右倾、高度跳）、窗光被云影遮暗再恢复、光柱里 70 颗浮尘（只在光柱内显示，24 帧闪烁）、端杯、热气。运动面积 8.0%（0.45↔1.0s）。

**坑**
- 厚涂第一版画成"暗影偏移＋主笔＋亮脊"三条整齐的线，读出来像白色贴纸/创可贴。改成鬃毛笔才像颜料。
- 拷回原图的局部区域（`drawImage(b, x,y,w,h…)`）会把未刷笔触的背景一起带回来，形成矩形补丁。道具应该单独一层画在笔触之后，不要拷区域。
- 颗粒 density 0.12 / α0.22 会让脸上全是脏点，0.05 / 0.12 刚好。
- 手要在杯子之前画，不然手的椭圆把瓷杯盖掉了。drawGirl 里的顺序是"手→杯→拇指"，自己重画时要照这个顺序。

# 34_shadowpuppet · 中国皮影戏

> 来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/34_shadowpuppet.js`。

实验时的文件名：`scenes/r3_piying.js`，每帧约 121ms（每块皮件单独离屏，multiply 次数多）。

**管线**：影窗（油灯在幕后的径向暖光＋screen 灯芯热点＋3px 布纹，布纹缓存）→ 道具层（窗棂、桌、瓶花、方背椅，缓存）→ 蝴蝶 → 猫 → 少女，每组一张离屏层 → 每层先印一层偏移软影，再 multiply 本体 → 铆钉 → 操纵杆 → 木框。

**关键参数**
- 皮件函数 `piece(g, path, col, carve)`：
  - 填色。
  - 在 clip 内用 destination-out 刻纹。
  - 在 clip 内描 2×edge 宽的同色"皮边"，保证刻纹不会刻穿外轮廓。

  - 鱼子纹 dots：s14–22，r3–3.5。
  - 团花 flowers：5 瓣椭圆，s36–46。
  - 云纹 clouds：阿基米德小螺旋，线宽 3.4，s24–40。
  - 方格 lattice：s26–32。
  - 刻线 lines：线宽 3–7。
- 印到幕布：`stamp(layer)` 先 multiply α0.28、blur 6px、偏移 (7,5)，表示皮件没完全贴紧幕布时的虚影；再 multiply 本体。透光 = 幕布色×皮色，重叠的皮件自然变深。
- 颜色：红 #c0352a、绿 #2f7d4c、琥珀 #d99a2e（金发＝琥珀色皮）、黄 #e2bd4a、蓝 #2c5a8a、橘 #d9782a（猫）。
- 幕布：径向 #fff6d6 → #f2d7a0 → #cf9a58 → #7a4a20；灯焰扰动 `fl = 0.5·noise(3ts) + 0.3·noise(9ts)`，ts 按 15fps 步进。光心漂移 ±26/±18px，热点半径 260+40·fl。
- 旦角"空脸"：头发画完后 destination-out 掉整张脸，只描脸部轮廓，再补凤眼（上挑长线＋下眼线＋点睛）、柳叶眉、点唇。
- 橘白猫的映射：橘色 = 橘皮；白胸、白口鼻、白腿白爪 = **整块镂空只留皮边**；虎斑 = 刻线。这条对所有"剪影/镂空类"风格都适用：白色部位直接镂空。
- 动作：
  - 少女整体绕 (1260,930) 摆 ±0.012rad；头绕颈部铆钉转 ±0.06。
  - 端杯按 10fps 步进。
  - 手腕松：dangle = 0.35·sin(11·ls)·(1 − 0.6·cup)，杯子跟着手一起甩。
  - 猫头绕颈点头 0.1·sin(6ts) + 0.05。
  - 尾巴 4 节铰链，每节相对上一节转 0.3·sin(7ts − 0.9i) + 0.38，鞭梢一节节滞后。
  - 步摇珠串甩动。
- 杆子：5px 深褐线，blur 1.2px multiply，从颈、腕、猫背、猫头、蝴蝶通到画面底边。

**母题动画**：灯焰让整块幕布的光斑跳、蝴蝶（翅膀按 12fps 用 scaleX 翻面，带杆子）、手腕甩、猫点头和尾巴鞭梢、步摇。运动面积 6.8%。

**坑**
- 桌腿压在裙子上：multiply 后红×绿接近黑，变成一块黑梯形。皮影里重叠变深是对的，但别把重叠放在视觉焦点上，把桌腿挪开就好。
- 猫前腿第一版是一整块橘色矩形，盖住了白胸。改成两条几乎全镂空的白腿才读得出"橘白"。
- 杆子横穿主体会很乱：杆子从皮件往下、往外走，不要跨过别的角色。

- 颜色：肤 #ffe8dc/#f2b6a8；金发 #f8d681/#d8a050；白校服 #fbfbfe/#b9c3dc；藏青 #2c3a66/#1b2446。天使环：后脑一道 9px 亮弧 rgba(255,250,226,.85)。

- 光晕：
  - 太阳核：r130。
  - 10 根星芒：长 90/170，以 0.25rad/s 旋转。
  - 横丝：840×4。
  - 5 个六边形光斑：落在太阳 → 画心连线上 0.45/0.75/1.25/1.6/2.0 倍处，α 0.04–0.12。

# 36_picasso_blue · 1903 毕加索蓝色时期

> 来源：迁移测试 D（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/36_picasso_blue.js`。

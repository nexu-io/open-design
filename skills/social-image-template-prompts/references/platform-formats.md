# Platform formats

Use the reference image's native aspect ratio unless the user names a destination.

| Destination | Aspect | Prompt instruction |
| --- | --- | --- |
| Facebook feed | 1:1 or 4:5 | Keep key copy within the central 80% of the canvas. |
| Instagram feed | 4:5 | Use a strong headline in the upper half and keep the bottom 10% clear. |
| Reels / Stories / Shorts | 9:16 | Keep all essential copy in the central 70%; avoid the top and bottom UI zones. |
| LinkedIn feed | 1:1 or 4:5 | Prioritize a concise, legible authority-style headline. |

Prefer 1:1 for a direct edit when the original asset is square.

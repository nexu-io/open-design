# hub-landing-page

> Skill Hub para geração de landing pages e sites institucionais.

## O que faz

Gera páginas web completas no estilo Hub — modernas, responsivas e otimizadas para conversão. Inclui:

- **Hero** com gradiente e CTA
- **Seção de serviços/produtos** em grid
- **Depoimentos** ou números de impacto
- **FAQ** ou contato
- **Footer** completo
- **Responsivo** (mobile, tablet, desktop)
- **Dark mode** como padrão

## Variações

| Tipo | Descrição |
|------|-----------|
| Institucional | Site completo da empresa (home, sobre, serviços, contato) |
| Landing Page | Página única focada em conversão |
| Portfólio | Galeria de projetos com cases |
| Produto | Página de apresentação de produto/SaaS |

## Como usar no OD

```
"Gerar landing page para [empresa/serviço] com hero, grid de serviços,
depoimentos e formulário de contato. Design system Hub."
```

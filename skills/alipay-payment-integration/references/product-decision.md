# 产品决策

用于用户集成支付宝支付产品或集成问题排查时的产品决策。

---

## 支持的产品范围

本 Skill 仅支持以下两种支付产品：

| 产品名称 | 核心场景 |
| --- | --- |
| 手机网站支付 | 手机浏览器 H5 页面调起支付宝 |
| 电脑网站支付 | 电脑浏览器跳转支付宝网页收银台 |

> ⚠️ **不支持的产品**：订单码支付、当面付、App 支付、JSAPI 支付、预授权支付、商家扣款等产品不在支持范围内。如需接入，请查阅[开放平台在线文档](https://open.alipay.com?form=payskill)或咨询支付宝技术支持。

---

## 产品决策树

```
用户咨询支付宝接入
        |
        +-- 手机网站支付场景？
        |       +-- 手机浏览器 H5 --> 手机网站支付 ✅
        |
        +-- 电脑网站支付场景？
        |       +-- 电脑浏览器网页 --> 电脑网站支付 ✅
        |
        +-- 其他场景？
                +-- 订单码支付、当面付、App支付、JSAPI支付、预授权、商家扣款等 --> ❌ 不支持
```

## 澄清话术

当用户描述模糊或关键词匹配不明确时，使用以下模板进行产品决策：

### 标准澄清模板

```
请确认您的业务场景：

1. 手机网站支付
   - 手机浏览器 H5 页面内唤起支付宝 App 或网页收银台
   - 适用：移动端网页内支付等场景

2. 电脑网站支付
   - 电脑浏览器跳转支付宝网页收银台
   - 支持扫码支付或登录账户支付
   - 适用：PC端电商网站、在线服务平台等

请描述您的具体业务需求？
```

### 不支持场景回复模板

```
抱歉，当前仅支持以下支付产品：
- 手机网站支付：手机浏览器 H5 页面调起支付宝
- 电脑网站支付：电脑浏览器跳转支付宝网页收银台

您咨询的场景不在支持范围内，请查阅[开放平台在线文档](https://open.alipay.com?form=payskill)或咨询支付宝技术支持。
```

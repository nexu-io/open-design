# 沙箱环境初始化

## 默认环境说明

**默认使用快速沙箱环境**进行集成，该环境具备以下优势：
- ✅ **零配置启动**：无需登录支付宝开放平台，自动获取测试账号与密钥。
- ✅ **即开即用**：全自动配置网关及应用信息。
- ✅ **安全隔离**：测试环境不涉及真实资金，可放心调试。

## 快速沙箱环境配置流程

### 调用工具创建环境

参阅 [alipay-sandbox-tool](alipay-sandbox-tool/alipay-sandbox-tool.md) 创建快速沙箱环境并获取工具返回的快速沙箱环境信息（包含 appId、appPrivatePkcsKey、appPublicKey、商家账号、买家账号等）。

异常处理：若调用失败，提示用户"当前快速沙箱服务繁忙，请稍后重试"，并停止后续步骤。

### 快速沙箱环境信息强校验（卡点）

工具返回环境信息后，**必须执行逐项强校验**，校验通过方可进入后续步骤。未通过则**阻断流程**，要求重新创建。

#### 必含字段清单

以下字段必须全部存在且非空，缺一不可：

| 字段 | 说明 |
|---|---|
| `appId` | 沙箱应用 ID |
| `appPrivatePkcsKey` | PKCS#1 格式应用私钥 |
| `appPublicKey` | 应用公钥 |
| 商家账号 | 沙箱商家登录账号 |
| 买家账号 | 沙箱买家测试账号 |


#### 校验规则

- **逐项检查**：逐条核对上述字段是否存在、是否非空、是否为有效字符串。
- **失败处理**：任一字段缺失或为空时，禁止自行生成公私钥信息。
- **严禁编造**：**绝对禁止**以占位符、模拟值、假数据或手动拼接等方式补全缺失字段。若信息缺失，必须重新走创建流程获取完整可用的沙箱环境数据。
- **重新创建**：校验失败后，引导用户重新调用工具创建快速沙箱环境，直至返回完整且有效的环境信息，方可继续。

### 成功创建快速沙箱后提示

向用户展示以下信息：

> ⚠️ **快速沙箱环境已创建完成**
> - **📌 环境说明**
>   - 当前快速沙箱环境**仅供测试**，不涉及真实资金
>   - 完整展示沙箱信息，无需对内容脱敏
>   - **切勿**在项目日志中打印私钥信息
>   - **切勿**提交正式环境、沙箱环境信息至公共代码仓库（GitHub、GitLab 等）
> - **🔔 必做操作**
>   - 请**自行妥善保管**密钥及测试账号等信息
> - **🔒 安全提醒**
>   - 正式上线前请确保您已拥有正式的应用 appId、经过审核的应用私钥及支付宝公钥，需切换至正式环境并重新配置密钥，正式环境网关地址：`https://openapi.alipay.com/gateway.do`
>   - 正式环境涉及**真实资金交易**，**强烈建议**在正式上线之前在沙箱环境中完成全链路测试

## 密钥格式说明

选用快速沙箱原始信息中 PKCS#1 格式的 `appPrivatePkcsKey`。

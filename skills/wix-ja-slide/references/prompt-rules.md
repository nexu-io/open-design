# AI Prompt Rules（日本語版）

LLM 生成 deck 文本时遵守。这份直接拼到 system prompt 里。

## 1. 文字数（cell-based）

半角 = 0.5 cell，全角（CJK / 假名 / 全角符号）= 1 cell。每 placeholder 给「**单行 cells 上限 + 最大行数**」，不是「总字数」。

## 2. 行頭禁則 — 这些字符不能出现在行首

```
終わり括弧類 :  ） ） ］ ｝ 、 〕 〉 》 」 』 】 〙 〗 〟 ' " ｠ »
小書き仮名   :  ぁ ぃ ぅ ぇ ぉ っ ゃ ゅ ょ ゎ ゕ ゖ
                ァ ィ ゥ ェ ォ ッ ャ ュ ョ ヮ ヵ ヶ
長音・繰返   :  ー ゝ ゞ 々 〻
ハイフン類   :  ‐ ‒ – 〜 ～
区切り約物   :  ? ! ？ ！ ‼ ⁇ ⁈ ⁉
中点類       :  ・ : ; / ：
句点類       :  。 . 、 ，
```

## 3. 行末禁則 — 这些字符不能出现在行末

```
始め括弧類 : （ ( ［ ｛ 〔 〈 《 「 『 【 〘 〖 〝 ' " ｟ «
```

## 4. 分離禁則 — 必须保持在同一行

| 类型 | 例 | AI 处理 |
|---|---|---|
| 英単語 / Latin | `<newsletter-project>`, `Wix Studio`, `<industry-event>`, `Vol.001` | 整段不破 |
| 連数字 | `5,000`, `8,000`, `300M` | 整体不破 |
| 数字 + 単位 | `12pt`, `65%`, `15kg`, `Q3` | 整体不破 |
| 漢字熟語 | `開封`, `着手`, `獲得`, `進捗`, `戦略`, `立案` | 不破（**强烈推荐**） |
| 漢字 + 送り仮名 | `受ける`, `立ち上げる`, `読み込む` | 不破 |
| 三点リーダー / ダーシ | `…`, `‥`, `——` | 不破 |
| 連符号 | `――`, `——` | 不破 |

## 5. 助詞 (てにをは) で改行 — 推荐做法

可以换行的优先位置（按"意味のまとまり"切分）：

```
〜を | 〜が | 〜に | 〜で | 〜と | 〜は | 〜も
〜から | 〜まで | 〜より | 〜へ | 〜や | 〜の
〜こと | 〜ため | 〜とき | 〜場合
読点（、）の後
```

**ルール**: 一文を 2 行に分ける必要があるとき、なるべく上記の助詞や読点の **後** で切る。

❌ 「来場者と多数の接\n点を獲得」← 漢字熟語「接点」を破る  
✅ 「来場者と多数の\n接点を獲得」← 助詞「の」の後で切る

### 5.1 行頭に 1 mora の助詞単独を残さない（Round 13 追加）

Slides の auto-wrap が起きると、行頭に **1 文字だけの助詞**（て / を / が / は / の / と / に / で / も / や）が押し出されて孤立することがある。これは strict kinsoku 違反ではないが、JP 読者には**極めて読みにくい**。

❌ 「Wix Japan を使い始めて、初め / **て**『海外…」← 「て」が単独で行頭  
✅ 「Wix Japan を使い始めて、 / **初めて**『海外…」← 動詞「初めて」を 1 行に保つ

回避策（優先順）:

1. **文を短く書き直す**（圧縮）して 1 mora 助詞が末尾に残らない長さにする
2. **意味境界が長い句で切る**（「〜と感じた」「〜を完成」など clause 末で締める）
3. T-LONG / 大字号 layout では特に 1 行 ~12-15 cells しか入らないので、1 文 ~80 cells 以下を目安に
4. T-LONG title placeholder には **明示の `\n` を挿入しない**（quote block 扱いで paragraph break が出る）

## 6. 字数计算的伪代码

```python
def width(s):
    cells = 0
    for c in s:
        cells += 1.0 if is_cjk_or_fullwidth(c) else 0.5
    return cells
```

## 7. AI 生成时的优先级

写入顺序（最重要 → 最不重要）:

1. **意味の保全** — 一文の意味が壊れない（最優先）
2. **複合語不破**（漢字熟語 / 英単語 / 数字+単位）
3. **行頭/行末禁則**
4. **助詞・読点後で切る**
5. **每行 cells 上限を守る**

如果 5 与 1-4 冲突，**重写句子让其更短**，不要硬塞 + 强行换行。

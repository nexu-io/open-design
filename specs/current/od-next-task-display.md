# OD Next 会话展示范围

2026-10-19 用户确认：只把同一次 query 的 plan+production 合成一轮展示，沿用现有状态、耗时、折叠交互及样式。此前方案中跨用户操作的展示合并与额外 UI 均不再属于本需求。

需求与实现见 [产品需求](od-next-task-display-prd.md)、[实现说明](od-next-task-display-implementation.md)。

## 本次交互与视觉差异核对

| 原 PR 增量 | 收敛处理 |
| --- | --- |
| 状态独占一行，下方再放「执行记录」 | 删除额外层级，状态、耗时、箭头复用 ExecutionShell |
| 独立状态行的间距、字体、失败色 CSS | 删除，统一使用既有组件样式 |
| 刷新后保留展开/收起偏好 | 删除 localStorage 偏好，恢复既有生命周期规则 |
| 等待回答、继续本任务等新增文案及过程节点 | 删除，问答与继续沿用既有界面 |
| 回答表单/继续任务跨用户消息共用状态和计时 | 删除跨任务展示身份；每次用户操作仍使用原有轮次 |
| 回答提交响应丢失的新增提示和自动恢复 | 收回该附加流程，沿用原有发送处理 |
| 新增 task-display CLI 参数 | 删除；纯展示合并不需要新的用户操作参数 |
| 对所有 strategy 单 Run 也切换新布局 | 单 Run 与纯文本回复继续使用原有组件路径 |
| plan 完成后单独出现完成状态与新计时 | 合并同一 query 的自动后继，仅保留一个过程入口和累计时间 |

最终结果、产物卡、错误卡、重试和继续按钮沿用原有行为。本次不更改执行策略，也不将“重试”改为确定性恢复 production。

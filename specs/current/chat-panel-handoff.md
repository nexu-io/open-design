### 1.3 真 Chrome 端到端 —— ✅ **已完成(2026-08-25 11:5x)**

前面两轮(1 与 1.2)都是**无头 Chrome + CDP**,那看不到真实字体渲染、扩展、登录态。
这一轮用 open-browser-use 接管用户自己的 Chrome,在 `chat-verify` 项目里连发三轮:
在输入框里打字 → 点发送 → agent 真跑 → 结果渲染,三轮都跑到「已完成 50s」。

**量到的关键一条(就是接缝那个 bug 的正面证据)**:运行中壳头那句「进行中」的计算样式是
`background-image: linear-gradient(90deg, rgb(32,32,32) 0%, rgb(32,32,32) 33.33%, rgb(124,58,237) 40%, …)`、
`background-clip: text`、`animation: chat-record-sweep`,而 `color` / `-webkit-text-fill-color` 都是透明 ——
**渐变解析出来了,字是渐变画的**。接缝没挂的时候渐变会整条失效,那时同样是透明的 `color`,但没有背景可画,字就消失。
`--chat-text-strong: #202020`、`--chat-dia-1: #7c3aed` 也都能从 `.pane` 上读到。

另外确认:转球 `data-orb="connecting"` 在跑、15 条工具行、「执行计划 · 2 步」的清单分段都渲染;

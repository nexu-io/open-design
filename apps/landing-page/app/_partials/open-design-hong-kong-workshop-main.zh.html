活动现场

发生了什么

工作坊变成了一间实时产品实验室。

参与者制作了演示文稿、仪表盘、网站和产品原型。有些人从既有品牌或设计系统出发；另一些人接入外部数据与 API，再把结果做成可视、可交互的作品。

这些作品跨度很大，也因此真正检验了 OpenDesign 能否在不同任务间保持上下文：它不只是一次性生成器，而是一个让人持续创作、检查、完善和展示的工作空间。

每一次顺利完成和每一个卡点都成了有价值的反馈：新用户能多快接入模型、编辑是否足够可预测，以及成品能否轻松交给别人继续使用。

最打动人的并不是一场完美演示，而是真实作品进入现场后，依然经得起使用与检验。
OpenDesign 香港工作坊 · 8 月 16 日

基础

一套设计系统，让每件新作品都属于同一个整体。

现场最清晰的产品价值是“一致性”。参与者可以导入品牌网站或代码仓库，建立共享的字体、间距和素材，再把这套系统复用到演示文稿、社交内容、原型和网页中。

这也改变了 AI 的角色。工作空间不再生成彼此孤立的视觉结果，而是为模型和智能体提供明确边界，让团队快速推进，又不必每次从头建立视觉语言。

实时构建·01

复杂的想法变得可探索，而不仅仅是可解释的。

一位参与者创建了两个版本的系统思维演示文稿，添加了动画和交互元素以使抽象模型更易于理解。

另一位参与者接入香港开放数据与地图 API，直接做出实时天气仪表盘，而不必先逐页研读 API 文档。自然语言意图成了数据与可用界面之间的桥梁。

实时构建 · 02

最终分享既有严谨分析，也有沉浸氛围。

现场并没有收敛到某一种输出。除了结构化仪表盘和演示文稿，还有充满表现力的 Web 体验，用来营造氛围、吸引注意并邀请探索。

这正是智能体工作空间的意义：同一套底层系统，既能支持严谨的内部原型，也能做成交互式说明或可直接展示的视觉概念。

来自现场的反馈

再强大的工作流，也要让每个边缘环节足够顺手。

体验从提示词之前开始。

连接、授权与模型设置必须足够清晰，让第一次使用的人即使不了解 CLI 或 API Key，也能顺利开始。

AI 优先，仍然需要直接控制。

在智能体驱动的编辑之外，人们也需要可预测的图像生成，以及拖动、缩放、对齐和撤销等简单操作。

顺利交付，工作流才算完整。

完成的作品应该能轻松变成分享链接、PDF、Word 文档，或进入飞书与 Google Drive，而不要求接收者具备技术背景。

我们学到了什么

当设计系统、智能体、数据和可编辑输出汇聚在一处时，OpenDesign 最能发挥价值。

一致性会放大价值。

可复用的设计系统，让每一件新作品都从正确的视觉上下文开始。

实时连接创造令人惊叹的时刻。

当模型和技能将真实数据转化为人们可以使用和展示的东西时，它们就会变得有形。

最后一英里是创作的一部分。

可编辑性、导出和共享决定了令人印象深刻的结果是否成为实际工作的一部分。

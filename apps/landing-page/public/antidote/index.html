Agentic engineering playbook

The six non-negotiables

01

Think before coding

State the task interpretation explicitly. Surface assumptions and trade-offs before editing files. Ask one clarifying question if guessing introduces extreme risk.

02

Simplicity first

Write the smallest code possible. Avoid unrequested features, configurability, or custom abstractions. Deletions are restricted; wildcard deletes are blocked.

03

Surgical changes

Restrict changes to targeted files. Never reformat, rename, or reorganize adjacent code. Match local formatting and clean up only your own unused imports.

04

Verify before merge

Run the test suite, linter, and type checker after every change. If verification fails, revert and replan. Green checks are the only acceptable exit state.

05

Goal-driven execution

Establish an explicit, testable success criterion before running code. Run verification checks locally. Summarize changes clearly before checkpoint commits.

06

Context handoffs

Pass structured metadata between agent passes, not raw chat logs. Update memory files after each turn so the next pass starts from ground truth.
